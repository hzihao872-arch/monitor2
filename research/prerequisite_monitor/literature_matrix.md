# 隐含前置条件 Monitor：一手文献矩阵

检索日：2026-10-05。范围：固定桌面单臂、最终目标指令＋准备动作 RGB 视频的独立离线监控。以下“未见”只表示所列论文的报告实验未直接给出证据，不能解释为能力不存在。旧六段及六个已评分场景族均为开发材料。

## 检索记录与停止准则

## 当前判定

最接近本题的三条路线：① ARS/ROVER/ProcVLM/R²VLM/PRIMO R1 的事件或程序进度；② Sharma/ReKep 的关系与技能前置核验；③ CoINS 的反事实可行性判断。**CoINS 已直接研究移除障碍的必要性**，但任务是交互导航并使用 embodiment/技能尺度信息；**ProcVLM、R²VLM 与 PRIMO R1 均有目标＋本视频的推理形式**，在新测试权重和运行环境可用时应列强对照。FIERCE 的[论文](https://arxiv.org/abs/2609.18651)区分 observed progress 和 action-conditioned failure risk，但后者要求提议动作/当前策略且训练时用终局和状态，不能原样作为本题仅视频 Monitor。EQA-Decision 的[论文](https://arxiv.org/abs/2605.25813)提供步骤状态/进度问答训练和基准，进度标签部分按帧索引归一化，未构成同初态配对反事实测试。截至本轮查到的报告，尚未确认有论文完整测“固定桌面单臂、同终目标指令、仅准备视频、B+/B0/U0/H− 正反配对的逐时 Monitor”。这只是当前检索边界，不作不存在声明。

## 追加的第 4、5 轮饱和核查（2026-10-05，上机前）

第 4 轮交叉检索 arXiv、PMLR、CVF 的 `robot video progress prerequisite feasibility counterfactual manipulation`、`goal conditioned task progress monitor causal obstacle removal`、`skill precondition visual counterfactual`，找到并核对一手出处：[SORNet](https://proceedings.mlr.press/v164/yuan22a.html) 由 RGB 图像和物体规范视图学习空间关系/技能前置分类，是既有「关系＋可执行性」路线而非仅目标＋准备视频的进度器；[Sentinel](https://proceedings.mlr.press/v270/agia25a.html) 把策略动作一致性与 VLM 任务进展失败监控结合，是执行中的策略监控，额外需要策略动作流；[ICCV 2025 state-change counterfactual representation](https://openaccess.thecvf.com/content/ICCV2025/papers/Kung_What_Changed_and_What_Could_Have_Changed_State-Change_Counterfactuals_for_ICCV_2025_paper.pdf) 的主旨是用状态变化及反事实描述训练程序视频表征，尚非本任务输入下的可核查目标前置进度器。PhysV2A、Dream2Fix、FARO 需 RGB-D/动作轨迹、故障合成或接触规划，输入/输出明显不同。未见新的直接 B+/B0/U0/H− 配对 Monitor 机制；这些工作进一步限制“关系检查”“反事实描述”的新颖性说法。

第 5 轮用 `prerequisite progress robot video`、`goal-conditioned state change task progress`、`counterfactual task progress robot` 搜索相邻工作，核对 [ReLAM](https://proceedings.mlr.press/v306/tang26o.html)：从动作缺失示范学习预期关键点子目标并给分层 RL 奖励，推理/训练依赖示范与策略，不满足本题仅单条准备视频的独立 Monitor；TaKSIE、Vis2Plan、LIVE 分别是视觉子目标生成/规划或动作条件世界模型，均落在先前「显式规划/世界模型」类别。两轮发现**新论文但没有新机制类别或同输入同配对测试**，据此满足本计划的有限饱和停点；不是证明相关工作不存在。若 ARS/PRIMO R1/ProcVLM/R²VLM 在既有服务器有完整旧权重，应按原生入口列强对照；缺权重只标未运行。

下一步唯一入口：保持已冻结的两个新场景及方法不受任何新测试模型输出影响；在用户决定进入**现有**租机后先作权重/环境只读预检和旧开发单段 8B smoke，失败即停。未解决反例：ARS 原版或简单同预算直接提示可能已稳定解决本题；两种新场景虽分别阻碍取物与放置，却共享横杆视觉原型，泛化范围有限。
