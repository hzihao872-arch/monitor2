## 推荐结论
**优先检验一个机制问题：视觉变化第一次被写成文字后，错误的实体名称是否会传给后续核验和任务作用判断；延后显式命名、保留可重新解释的视觉对应，能否减少这种错误？**

这保持原研究问题：只看截至当前的RGB视频、最终目标和固定通用能力，判断已发生变化对任务的作用。它在ARS同一大问题内寻找明确的方法差异，不以“环境改变vs目标物体”或“我们场景更难”声称新的研究对象。第一批把手/盖子材料只是验证机制，不能替代完成、撤销、无变化及unknown等完整覆盖。

本轮17候选中，建议发展 **P1方法候选 + E1功能评价协议 + P8首轮诊断**，组成一条研究路线；不是三套都要开发的新系统。P1有明确但较薄的待测增量，判为PROCEED WITH CAUTION。E1、P8通过早期可研究性检查，不代表足以独立成文。

## 与ARS究竟有什么区别
ARS会根据任务提出事件，选择更合适的视觉证据，进行独立上下文核验，再修订事件及进度；它已经处理准备、部分成就、退步及撤销条件。炉灶“开—关—放锅”案例已经说明它考虑环境条件，不能说ARS只看目标物体。[ARS正文及附录](https://arxiv.org/html/2609.34484v1)

| 对比 | ARS已覆盖 | 我们要新增检验的具体问题 |
|---|---|---|
| 视觉事件与核验 | 提议、重新取证、编辑描述与时间 | 同一错误实体名进入后续核验，是否影响最终判断；哪些核验能消除它 |
| 方法 | 目标感知事件推理，已有可修订性 | 固定自动视觉候选后，暂不继承未经核实的名称，先留跨时原始对应，再形成事件和目标作用 |
| 评价 | 进度/退步、事件及下游数据利用 | 事实看对之后，任务作用是否符合评分侧受控续行所检验的功能效应 |
| 证据要求 | 公开材料未给当前细分实验 | 必须给ARS相同工具、像素与预算；没有测过不等于ARS不会 |

**不能预设ARS在该机制上失败。** 如果同样工具的ARS已经足够，应接受结果。若新方案也能改善ARS，则贡献可能是可复用的证据组织方法，而非change-first独占。

## 三个发展项
### P1：保留视觉身份，延后显式命名——主方法候选
场景：目标是把蓝块放进盒子。机械臂拉动盖上的灰色把手，入口打开；自动文字清单却把它叫作独立灰块，随后事件被写成“移走灰块”。后续核验可能沿用这一解释。这是已有开发线索对应的待测失效链，不能当成ARS必然行为。

方法：自动区域与过去帧对应先保留编号、前后原始图块、不可靠标记；随后形成变化，允许重命名；最后加入目标、局部作用及反证，再查合法前缀。共同运动只能挑战无证据的独立搬运，不能自动证明物理连接。

必须配对真正的独立灰块、松散共移物、空动作、开后又关及遮挡不可判，防止只学“灰块都是把手”。无人工框/连接关系。
最小先导：新24轨迹，2结构×3布局×4动作；ARS-style-prefix/change-first × early/delayed四格，同前端、实际观察和资源上限，另有directVLM与普通SoM/文字inventory解释对照。四格是96次流程运行，不是模型调用数。
正信号：身份和最终作用同时改善，覆盖率/真实分离召回不下降，各组方向有可复验迹象。风险：收益来自更完整命名证据、文本记忆或工具，而非时机本身。方法比较不能独立证明内部语言锚定。

### E1：受控续行的功能效应审计——评价协议候选
同目标下比较准备足够/不足/无关/新阻碍/撤销/完成。先审12配对簇的标签，评分端登记相同续行动作、成本、时域及比较起点，才考虑54前缀扩样。
作用符号与goal_done、direct_ready、partial_preparation、reversal独立标注；帮助和部分、伤害和撤销可以同时成立。另一条路线存在不自动意味着完全冗余。
只称登记动作集合内的功能效应；某次续行失败不证明没有合法路径，二元成功不证明部分帮助程度。不可见几何或不充分枚举保留unknown/范围。
正信号：有效标签上出现跨机制“事实正确、功能作用错”的稳定差别。风险：控制器偏好、物理历史不配对、标签不可由RGB辨别；这些是协议失败而非模型失败。

### P8：错误文本是否传播——最便宜的首轮诊断
预先纳入16–24新前缀，冻结自动提议和接口。相同早期自动名称在相同视觉核验中传入/隐藏，加等长中性控制；自然错名在干预和作用结果前确定。人工修复只作额外诊断上限。
先看名称接口；事件删除/时间指代等留后续单因素诊断。报告无事件、区域缺失和对应错误，避免只选可编辑成功事件。
正信号：名称传递对作用判断有可复验影响，且自然错误确实存在，能改变下一步修哪层的决策。仅有“正确事实比错误事实好”不足。P8不是P1显著性闸门；样本缺失或区间宽意味着未决。
范围：指定文本接口的因果影响，不能替代RGB端到端成绩，更不能直接推断自然错误主要由命名造成。

## 必须满足的证据与可允许主张
机制比较冻结实际像素、分辨率、裁剪及外围上下文、自动候选/对应、调用结构；系统比较允许自主取证，在共同资源上限下报告自然成本及前端开销。ARS允许同样重绑定、unknown和视觉工具。论文重建仅称ARS-style，当前不能冒称官方完整复现。

主要指标：全样本事实/作用错误、结构变化及真实分离召回、虚构搬运、各独立状态字段错误、固定覆盖率风险、成本/延迟；条件于候选可用的诊断另报。按轨迹簇配对，逐结构—布局展示；帧与检查点不作为独立样本。

| 结果 | 允许的结论 |
|---|---|
| 同一错误名称传入使判断恶化 | 指定名称接口存在因果影响；不是自然错误主因的证明 |
| delayed两种流程都获益 | 该证据组织方案有可复用收益信号，可改进ARS；不是change-first独占或时机单因果 |
| 只有change-first获益 | 信息流交互探索信号，须新材料复核 |
| 身份改善，作用不改善 | 感知收益存在，完整monitor收益不成立 |
| 同工具ARS同等/更好 | 本配置下不支持独立change-first优势 |
| E1事实正确而作用错 | 有条件的功能评价发现，尚无下游策略收益证据 |
| 候选缺失/自然错误少/区间宽 | 先导欠判别力或接口失败，不作科学否定 |
| 覆盖充分、操纵生效、公平基线持续同等 | 停止复杂化当前实现，保留原研究问题 |
