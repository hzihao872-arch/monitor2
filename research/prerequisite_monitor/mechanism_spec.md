# 可观察机制规格（设计前的科学定义）

状态：候选规范，2026-10-05；未经模型开发集比较或新盲测证实。只接收最终目标指令 `l` 与该回合准备动作的主视角 RGB 视频 `v[0:T]`。同一视频可回看/裁剪。仿真状态、分支续行、物理标签、其他方法分数、成功示范均不进入推理。

## 要求模型判断的量

`goal → candidate prerequisite → visual evidence before/after → observed relation change → counterfactual challenge → credit/unknown`。模型要解释从视频看，完成目标前所需的**可见关系条件**是否变化；这只是可检查的状态主张，不是精确预测 `C=q_action−q_control`。`C` 是冻结固定控制器/预算/扰动下的评测真值。如果有其他可行抓取/放置路线，或 2D 画面无法分辨，回答未知并说出缺的信息。

候选前置条件由目标及当前图像共同提出。例如目标“蓝块在绿托盘”：可问托盘可用放置空间是否被占、蓝块可否被夹爪接触、蓝块/托盘是否仍存在。红块颜色、模板坐标、编号、物体尺寸及“绿托盘必被红块占”均不得硬编码。问的是视频所支持的关系，不预置“抓取入口固定轨迹”的控制器知识。

最小事件结构（每个时间点的进度另列）：

```json
{
  "goal_entities": ["..."],
  "candidate_prerequisite": "...",
  "relation": "...",
  "before": "true|false|unknown",
  "after": "true|false|unknown",
  "evidence_frames": [{"t": 0, "region": "...", "supports": "..."}],
  "observed_action_effect": "...",
  "alternative_explanation": "...",
  "confidence": 0.0,
  "uncertainty_reason": "...|null",
  "status": "supported_positive|supported_zero|supported_negative|uncertain"
}
```

证据帧必须是当前视频的实际解码索引；区域可用自然语言或像素框，但不能无图编坐标。`confidence` 仅为主观校准值，不能充当 `q` 或 `C`。若 `before/after=unknown`、替代解释无法排除、证据帧不含断言对象，则 `status=uncertain`，事件进度不应被确定地正向奖励；弃答记入所有方法的覆盖率分母。

## 四个核心分支如何手算（仅为开发实例）

1. [offset 托盘接触表](../../experiments/prerequisite_probe/artifacts/unseen_offset_cell/truth/contact_sheet.png) `0001`：t0 红块在绿托盘内，蓝块在桌面；t14 红块在托盘外，蓝块位置基本保持。可见“放置区域被占”由真转假；若托盘确实只有一个可用位置，给有限准备信用。注意“托盘容量/避让路径”仍是反事实挑战，不能只凭红块离开就断言任何策略必失败/必成功。
2. 同接触表 `0002`：动作确实接触红块，t14 红块仍在托盘中。前置条件未解除，状态为 `supported_zero`；如果 t9 遮挡，应回看 t14，而不是凭动作流畅给分。
3. 同接触表 `0003/0004`：`0003` 红块在托盘外移动，托盘前后可用，归零；`0004` 红块被移入托盘，前置条件从满足变不满足，归负向。直接目标 `0005` 已将蓝块放入托盘，须正向；`0006` 静止须不变。一个全零监控器会被这些锚点淘汰。
4. [pickup gate 接触表](../../experiments/prerequisite_probe/artifacts/unseen_pickup_gate_v2/truth/contact_sheet.png) `0001/0002`：红块相对蓝块位置变化可见，但夹爪接近蓝块时的精确碰撞通道、可绕行路线未由单主视角证明。允许回答“红块较远/仍近，但可抓性 unknown”；不得照仿真成功率说 `0.85`。这会降低覆盖率，是需报告的失败模式。

## 候选机制的可证伪预测

- P（关系检查）：在托盘占位这类关系可见的开发例，前后关系对 B+/B0/U0/H− 应可分；在精确抓取通道例可能多弃答。若跨新机制只是对“红块是否在托盘”有效，它不是通用前置 Monitor。
- F（反事实续行问答）：直接问“若此时只继续做最终目标，与动作前相比哪里更难/更易；还有没有替代路线”，必须给视频帧而非想象后续结果。交换前/后提问顺序与同义措辞后应稳定。若仅复述红块位置或输出伪成功概率，不能算独立验证。
- H：先让 P 列关系，再让独立上下文 F 找替代路径/错误归因，只有两者证据一致才出确定事件信用；否则 `uncertain`。其唯一潜在增量是**质疑关系变化是否真的改变目标续行的可行性**，这在 ARS 的一般事件核查之上是否有实际效果尚未证实。若 H 的收益仅来自更多帧/token、弃答或重复 P 的措辞，弃用 H。
- D（直接提示控制）：同骨干、同目标视频与同等可用帧/token/调用预算，直接输出相同接口。若 D 已正确，结构化机制没有效益主张。
