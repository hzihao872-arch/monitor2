# ReKep（Huang et al., arXiv:2409.01652v2）

一手：[论文](https://arxiv.org/html/2409.01652)、[官方代码](https://github.com/huangwl18/ReKep)。它输出行动控制，不输出本题的独立逐时进度；VLM 根据指令和带编号关键点图像编写分阶段关系约束，优化器检查子目标/路径约束并执行、失败时回退。

路径：RGB＋点云＋分割→DINO 特征聚类关键点→VLM 生成 Python 约束→3D 关键点/碰撞场与机械臂状态→优化规划/约束违反检测→阶段推进。`main.py` 第60–72行读 `rgb,points,seg`；第93–100行加载阶段约束；第121–145行检查路径违反并回退。这些是执行系统可用的特权几何/实时状态，不能放入本研究 Monitor 提示。

B+ 对应清障约束达到；B0 约束仍违反；U0 与目标约束无关；H− 违反先前满足约束。它展示结构化关系检查能用于机器人行动，但不证明单视频能自动发现并核查所有隐含前置条件。反证：若将其关系约束的可见部分用同一 RGB 视频判断仍可靠，无需另造新机制；但要单列输入适配，不能称 ReKep 原版离线基线。代码是静态追踪，未安装 3D/机器人依赖或运行。
