# 主动反例记录

机制：`support_surface`；解析与有限搜索详见 `necessity_report.json`。

阻挡态续行成功（潜在反例）：0；开放态续行失败：0。逐种子、目标末态及实际抓握记录在 `paired_continuations.json`。有限搜索没有发现反例不能充当穷尽证明；同步运动学滑件不能证明自由动力学抓取能力。

| 反例尝试 | 本地证据与边界 |
| --- | --- |
| 在目标区边缘、导轨或绿色标记上搭住蓝块 | 中央合格足迹限制为左右 ±45.5 mm；绿色标记内缘在 ±57 mm，导轨内缘在 ±62 mm。完整足迹内没有这些高位接触面。 |
| 倾斜/旋转放置 | `static_candidate_search.json` 用固定种子搜索 50,000 个含倾斜姿态：11,822 个完整在目标区，3,272 个满足目标高度/平面窗口；其中阻挡态有高位承托的候选为 0，展开态为 3,272。有限搜索不代替几何论证。 |
| 放在下方桌面、由夹爪扶持或滑落 | 高度、直接板接触、无其他承托、松爪及稳定窗口的反例测试均拒绝。 |
| 阻挡态直接抓放 | 两条路线 × 三个成对扰动种子：0/6 成功；开放态相同尝试 6/6 成功。种子不是六套独立场景。 |
| 抓蓝块时顺带把板推到位 | 部署状态仍必要，但本版板为运动学滑件，未能物理检验同步推动。因此不得宣称“必须先独立展开板”。 |

最强未消除风险：读者可能误把导轨或边界标记当作可在目标中央承托蓝块的表面；由独立盲审核对普通 RGB 是否足以判断。
