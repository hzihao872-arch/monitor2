# 主动反例记录

机制：`access_gate`；解析与有限搜索详见 `necessity_report.json`。

阻挡态续行成功（潜在反例）：0；开放态续行失败：0。逐种子、目标末态及实际抓握记录在 `paired_continuations.json`。有限搜索没有发现反例不能充当穷尽证明；同步运动学滑件不能证明自由动力学抓取能力。

| 反例尝试 | 本地证据与边界 |
| --- | --- |
| 旋转/倾斜蓝块缩小入口投影 | 解析下界 46 mm；10,000 个随机方向的最小投影约 46.36 mm，均大于 30 mm 的 S 开口。随机搜索只挑战下界，不证明下界。 |
| 顶孔之外从侧面或底面进入 | 盒底、四壁、顶框均为有碰撞的实体；唯一顶孔闭合时由有碰撞的滑盖覆盖。具体刚体尺寸在场景源码与状态流。 |
| 蓝块靠顶框、盖、墙边或机械爪扶持 | 完整八角、盒底高度、直接盒底上托冲量、无其他上托、松爪及稳定窗口的反例测试均拒绝。 |
| 阻挡态直接抓放 | 两条路线 × 三个成对扰动种子：0/6 成功；开放态相同尝试 6/6 成功。种子不是六套独立场景。 |
| 抓蓝块时顺带推开盖 | 状态改变仍必要，但本版盖为运动学滑件，未能物理检验这一同时操作。因此不得宣称“必须先独立开门”。 |

最强未消除风险：主视角下 30 mm 的缺口与 46 mm 的蓝块宽度能否由普通读者准确比较，须待独立盲审；不能以隐藏尺寸代替可见判断。
