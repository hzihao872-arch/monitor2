# v0.2 开发实验：语义证据复核记录

审读顺序：先查 Qwen 原答的可见事实、实体/区域、0/7/8/14 秒关系、续行和理由，再查自动胜负汇总。本记录依据完整 `raw.jsonl`、已有的源视频逐帧审读图，以及这次重新查看的两个 G 末帧。A/B 是已暴露开发集。审读者是 Codex 的视觉/文本逐案复核；**没有独立人类审读者**，不能把此记录称为独立人审共识。

判据：仅仅说“蓝块仍未移动”不构成前置关系或撤销的充分证据；`valid` 只表示 schema、引用秒数和读出一致，不表示画面事实正确。对单视角未证实的替代路线，保留证据不足。

| --- | --- |

| A R/0005 | 入口 0 秒关闭，7/8 秒打开，14 秒复原。TP1/TP2 记录了关闭→打开→关闭的可见关系，这是少数正确时间事实；但它们把初态续行写成 `possible`、末态 `blocked`，自报 `harmful` 且校验失败。D/T/P/D2/D3/F3 的净 `unchanged` 仅靠蓝块未动，未证明撤销。V0 也漏了关键入口变化。 |

| A I_o/0004 | 入口一直开放，粉色物体动作无关。D2/D3 给 `unchanged` 但没有入口稳定证据；T/P/TP 的 `harmful` 自报与字段冲突，混淆了无关动作与目标入口。 |

| A G/0002 | 14 秒蓝块位于盒内，末帧再次目视确认。V0 及 D1/T1/P1/D2/D3/F3 的完成事实有可见支持。TP1/TP2 的 `goal_done.t14=true` 也是对的，却自报 `beneficial` 而非完成优先的 `completed`，两次 `direction_conflict`。 |

| B S/0006 | 黄板只部分移动，末态承托不足。V0 关注机械臂，方向候选关注蓝块未动；`unchanged` 有标签相符但缺承托事实。 |

| B N_b/0007 | 黄板一直收起。V0 无显著变化可接受；方向候选未给承托关系，常把两端续行写成 `possible`，与源视频准入审读不合。 |

| B I_o/0002 | 黄板一直部署，粉色物体动作无关。D1/D2/D3 自报 `harmful` 与 `possible→possible` 字段冲突；TP1/TP2/F3 的非法 `blocked` 枚举/续行判断不能代表真实阻断；其他 `unchanged` 仍缺承托事实。 |
| B N_o/0003 | 黄板一直部署。V0 的无显著变化可接受；方向候选均未明确记录承托板端点，虽多给 `unchanged`，依据仍不足。 |
| B G/0001 | 14 秒蓝块位于已部署的黄色承托板上，末帧再次目视确认。V0 的目标物移动事实正确；D1/T1/P1/TP1 的文字证据也描述放置，却把 `goal_done.t14` 留成 `false`，因此校验失败。D2/TP2/D3 把完成字段改为 `true` 后有效；F3 再次自报完成但字段为 `false`，产生方向冲突。 |

第一错误归类：E/H 主因是目标相关实体/区域和视觉端点遗漏或看反；R 是时间关系虽偶有被看见，但续行端点和最终撤销读出仍错；G 的可见放置通常能读出，主要损失来自完成字段与方向不一致。对无关动作/静止对照，`unchanged` 大量依赖未动蓝块，不能当作对前置机制的有效负证据。原生 TOPReward 数值曲线不含这些关系字段，因此不能从曲线反推它的内部视觉错误。
