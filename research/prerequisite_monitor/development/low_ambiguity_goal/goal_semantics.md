## 候选 A：唯一目标凹槽的底面被占据

**最终指令原文（拟用于该候选全部六段）：**

> Place the blue cube fully into the single green socket so it rests flat on the socket floor; release it and leave it stable.

目标物是蓝色立方体。目标区域是唯一绿色凹槽内壁围成的空间，指定支撑面是该凹槽的绿色底板。`fully into` 要求蓝块的平面投影完整落在凹槽内，蓝块底面平放于底板；偏心但仍完整在内是合格的。`release` 要求夹爪不再承托、夹持或接触蓝块。`stable` 要求在短暂观察窗中不再滑移、滚动或倾倒。普通读者应接受图 A、C，拒绝图 B、D、E、F、G、H（图号见独立审读包）。

机器人可用桌面单机械臂做任何物理可行的抓取、移动、绕行和放置，也可在执行目标时接触非目标物。目标句不规定准备动作、路线、抓取姿态、必须先动哪个物体或中间顺序。候选机制的设想是让另一物占据唯一能由底板支撑蓝块的位置；这是**待检验假说**，不是目标语义的一部分。

**仅评测侧的操作化定义（不得进入模型提示）：** 蓝块全部顶点投影在凹槽内壁以内并有容差；底面与指定底板构成承载接触且接触法向、姿态与重力相容；与其他物体、夹爪的接触不替代底板承载；夹爪张开并离开；连续短暂窗口内位置、角速度和线速度均低于事前固定阈值。数值容差、接触 API 与窗口长度待新场景代码和负例测试确定，不能事后为得到想要的标签调整。静态图只能审语言判读，不能证明动力学稳定或主视角可见。

## 候选 B：源端单入口封闭结构

**最终指令原文（拟用于该候选全部六段）：**

> Place the blue cube fully into the single green socket so it rests flat on the socket floor; release it and leave it stable.

目标物、目标区域、支撑、释放、稳定与候选 A 相同；同一目标句下图 A、C 应被接受，图 B、D、E、F、G、H 应被拒绝。源端是否有门、从哪边抓取、怎样清开入口均不在目标句内。机器人动作范围也相同。候选机制设想是蓝块起初位于可见的源端围护结构内；一处可移部件可能决定是否有可行抓取入口。这一设想尚未由几何、可达性或主视角证明，侧抓、上抓、绕行和接触推开均要作为反例挑战。若围护结构遮挡蓝块、存在其他抓取入口或关系只能靠隐藏尺寸判断，候选 B 应排除或重设计。

**仅评测侧定义：** 终态谓词与 A 使用同一版本；源端部件状态只用于必要性反例搜索和物理对照，绝不能加入成功谓词，也不能给 Monitor。将源端可达性定义成“单一固定中央上抓控制器能否成功”会偷换研究目标。
