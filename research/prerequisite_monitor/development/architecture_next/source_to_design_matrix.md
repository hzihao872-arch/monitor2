| --- | --- | --- | --- | --- |

| Subtask/remaining-action reasoning, [ROVER](https://arxiv.org/html/2508.01943), [ProcVLM](https://arxiv.org/html/2605.08774), [PRIMO R1](https://arxiv.org/html/2603.15600) | D2 overlooks useful preparation. | Text reasoning legal; original specialized weights absent, ROVER API unavailable under no-purchase constraint. | D2 can name substeps in its review; extra reasoning tokens can itself help. | Do not add a third reasoning pass or claim novelty. Native models only if **already** available later; report missing otherwise. |
| Counterfactual alternate route, [CoINS](https://arxiv.org/html/2601.03956) | A relation can be true while bar removal is not strictly necessary (s01 off-center, s02 side grasp). | Questioning from RGB legal; native map/depth/skill truth illegal. | Yes, D2 has `alternative_route`; the candidate must name a concrete visible disproof to add value. | Keep as an output uncertainty field, **not** a new F agent. A no-bar-move valid route falsifies strict necessity before model comparison. |
| Completion-token score, [TOPReward](https://arxiv.org/html/2602.19313) and Robometer progress | G+ seen while B+ missed; checks whether a progress curve detects a preparatory effect. | Legal native inference and outputs already sealed. Their targets/scales differ from D2. | N/A. | Preserve as external native baselines, never a strict same-backbone ablation or a prompt feature. |

Three competing routes remain: a direct two-pass D2; one two-pass relation/endpoint verifier; a trained process Critic if already weighted. The chosen experiment changes only the **question the second pass is required to answer**. It does not add a crop, agent, vote, caption, or F/H hybrid. Its claim is limited to a testable implementation choice, not invention of relation verification.

**Direct falsifier of our criticism of direct methods:** a new admitted source and target six-condition pair on which D2 gives valid candidate object, relation, endpoints and directions at comparable coverage. Then the structured second question has no incremental value.
