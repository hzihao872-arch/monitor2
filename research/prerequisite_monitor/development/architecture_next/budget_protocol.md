# Stage C/D budget and isolation protocol, v1

Primary comparison is the same already available Qwen3-VL-8B-Instruct **exact revision** on both arms, with 15 decoded 640×480 1 FPS preparation frames, inspected seconds `[0,2,4,6,8,10,12,14]`, each rendered to 512×384. Two visual calls per video, same 512 maximum new tokens each, same single conversation context for each call (second call includes only the first raw draft as text). No crop in the main comparison. D2 gets a direct first question and review second question; candidate gets a relation proposal first question and verification second question. Both use the same record schema and `monitor_contract` v1 parser/direction/score; `candidate_object`/`region_kind`/`region` are common extra audit fields. No evidence of a triggered v1 parser bug justifies changing the sealed contract. Its known-states plus `comparison=unknown` risk must be counted as abstention and reported in both arms; any future contract fix requires a new shared version and new paired run, with old results preserved.

Record **per call** input/output tokens, elapsed milliseconds, peak VRAM, prompt hash, raw output, parse validity, error, frame seconds/size, video SHA and decoded-pixel hashes. At the case level report output validity, cited-frame structural validity, semantic relation/object validity (post-seal human audit), explicit `unknown`, valid direction coverage, and pair order. Record nominal token ceilings and actual totals; actual prompt tokens need not be identical, so no strict “same token” claim unless verified. A method taking more actual token or abstaining more is analyzed separately. D1/P/F/H0 old outputs are historical context; if needed on admitted development scenes, use the same backbone/frames/schema and publish their unequal call budgets, never mix native TOPReward/Robometer scales with this index.

Runner entry receives only `model_input/` plus locally present model checkpoint and output path. It rejects any input directory named otherwise and an output inside it. `truth/`, continuation video, frozen condition map and old result files are inaccessible to runner code; scoring/auditing opens truth only after raw JSONL is sealed and hashed. A smoke should first use one **old** development video only to check format and memory, without recomputing a completed full experiment. Full mechanism is the statistical unit; no splitting conditions or 20 perturbation seeds as independent tests. A candidate with additional crop/high-res/call is a separate budget stratum, not primary evidence.

No stage D call may start until `development/scene_video_next/SCENE_READY.json` passes semantics, predicate, route necessity, observability, at least two distinct complete six-condition mechanisms, input/truth segregation and SHA checks. No new rental/purchase/download. ARS original stays unrun while official code is unavailable.
