# 蓝块—红块—绿框：语言、视觉与进度读出归因实验计划

制定日期：2026-10-06。状态：**待执行计划**；没有在本计划下连接服务器或生成新模型结果。适用对象是 TOPReward 原生 8B 和 Robometer-4B PR #33 dtype 兼容版。现有六段是已见开发集，不能重新命名为盲测。

## 0. 要回答的问题与现有证据

**问题：**在不改变模型权重和原生打分机制的条件下，语义等价的目标表述或更清楚的合法视觉输入，能否让两种方法把红块移出目标区视为有利、红块移入视为有害、框外搬动视为无效？若不能，故障发生在视觉事实、隐含因果推断、原生进度读出中的哪一层？只有在这些小改动经过固定对照后，才讨论关系模块或训练变更的实际增益。任何有限组提示失败都不能从逻辑上证明“必须采用新架构”。

**已封存事实：**上一轮在单场景六段上，两种原生进度方法按预定首尾三秒中位数配对均仅赢 `G+>N0`；TOPReward 的 `B+>B0` 对末三秒窗口敏感，最后 t14 已反转为赢；TOPReward 的 `H−<N0`、Robometer 的 `B+>U0` 和 `H−<N0` 到 t14 仍失败。Robometer 的 success head 只作终态识别阳性对照，不用“不奖励准备动作”作为该 head 的缺陷。`relation_endpoint_v1` 六段全部弃答；同预算 D2 没有有效前置关系证据。基础 8B/4B 的聚焦事实回答不等同于原生模型的内部过程。

**物理目标：**沿用原句，蓝块完整在绿框内、一个整面直接贴桌、夹爪放开并移开、蓝块静稳。主任务不点名红块。几何与两类固定续行支持“中央红块状态必须改变才能有合法平放终态”，不证明“必须先做独立搬红块动作”。原始输入 ZIP 的 SHA-256 为 `c99543639e2ac7e8ddf270654d1394f42d6f121021463bf3f452648686183cfa`，既有可运行代码 ZIP v3 为 `244ef6bdbeb93bc3360149a9801d929dc10c793345e443192bd77141290ea5c5`；本地 2026-10-06 再次核对二者哈希匹配。上一轮结果及首次服务器失败、修复后原文保持封存，不覆盖。

## 1. 假设和最小改动实验矩阵

六段条件固定：`B+` 中央红块移出，`B0` 移出又返回，`U0` 红块始终在框外但移动，`H−` 红块从框外移入，`G+` 蓝块完成，`N0` 静止。每个实验臂均跑完整六段；同一臂给所有视频同一任务句。模型只能拿匿名视频、任务句和必需的媒体清单，不能拿条件映射、仿真状态、尺寸、后续成功率或旧分数。

| 臂 | 唯一主要改动 | 目的及可解释范围 |
| --- | --- | --- |
| R0 | 原句、原视频、15 帧 | 已封存基准；开发集不重复调用，直接引用原文与曲线。 |
| L1 | 同视频，同帧，只换一条简短等价目标句 | 检验长句负担/措辞偶然性；未直接给出红块关系。 |
| L2 | 同视频，同帧，换另一条等价目标句 | 避免只凭一个改写下结论；未直接给出红块关系。 |
| V1 | 原句、同 15 个时刻，固定视野优化视频 | 检验物体太小/空间关系看不清；裁剪或重渲染必须保证整段蓝块、红块、绿框及动作关键段仍可见。 |
| C1 | 原视频和帧，目标句补充**条件性红块规则** | 诊断模型会不会使用已明说的因果关系；这是受提示上限，不能算自然目标成功。 |
| Q1 | 同权重、相同可见帧的独立事实与因果问答 | 定位感知、时间追踪、隐含几何推断；回答不冒充原生评分过程。 |

先固定 L1/L2 的逐字英文句子，并按“完整入框、直接桌面接触、释放、静稳”四项逐条核对与 R0 等价；独立审读若可获得，另记其意见，但不把等待外部读者当作服务器预检的前提。建议候选：

- L1: `Place the blue cube completely inside the green square, with one whole face resting directly on the tabletop. Release it, move the gripper clear, and let it settle.`
- L2: `Set the blue cube flat on the tabletop so it lies entirely within the green square. Let go, move the gripper away, and leave the cube still.`
- C1: 保留 R0 全句，再追加 `A flat tabletop placement is possible only when the red cube does not occupy the green square.` 这是额外关系信息，单列为上限。若人类审读认为任一 L 句改变成功条件，必须在服务器运行前修订、重审并重新记录哈希；不在模型结果出来后改句。

V1 用原 MP4 全部 15 个时刻，固定同一个裁剪/更近相机配置，不随条件或时刻手工追踪目标；不得叠加箭头、框、字幕或状态文字。已有 640×480 联系表显示目标区域较小，V1 是否可行须在本地逐帧检查 90 帧后固定。若固定视野无法同时保留蓝、红、绿框和关键运动，改用相机重渲染并为**每种条件重新制作同路线配对**，不能用丢失物体的裁剪硬跑。每个新视频记录解码后像素哈希。

Q1 拆成两次独立任务，并保存原文和 `unknown`：事实题只问 t0/t7/t14 红块在框内外、是否移出又返回、蓝块是否移动、G+ 是否可见直接桌面接触；因果题问“若红块保持当前占位且后续不再主动处理红块，能否把蓝块完整放进绿框并直接贴桌？为什么？”不提供尺寸或正确答案。TOPReward 使用其同一 8B 检查点另开问答；其原生奖励分数本身没有解释字段。Robometer 专用 checkpoint 的输出是 progress/success heads，现成接口不提供可靠语言问答；基础 4B 问答只作旁证，**不能声称 Robometer 内部知道或不知道关系**。Robometer 的直接能力对照主要靠 L/V/C 臂的原生进度变化；若 C1 不起效，还必须考虑新任务措辞超出其训练分布。

## 4. 评分、判定与下一轮新样本

**旧六段开发评分**同时报告：原预定 `Δ_window = median(r12,r13,r14) − median(r0,r1,r2)`；以及已标记为事后敏感性的 `Δ_t14 = r14 − median(r0,r1,r2)`。不能用 t14 替换原预定指标后重新宣称旧 R0 胜负。新实验臂可预先同时比较两指标；若彼此矛盾，结论标为时间窗敏感。Robometer success head 只报终态对照；进展假设只由 progress head 检验。TOPReward 不使用逐视频 min–max 归一评分。

按顺序看 `B+>U0`（近似匹配红块单程动作量）、`H−<U0`（相同开放初态、近似匹配单程动作量）、`H−<N0`（相同开放初态）、`B+>B0`（相同 blocked 初态，但 B0 往返动作更长）、`G+>N0`（成功锚点）。B0 另看移出阶段是否升、返回后是否降；不能要求其全程零。报告每个比较的原始差值、平局和方向，不能跨模型比较分数绝对值。

**分层解释规则：**

| 观测结果 | 可支持的结论 | 不能说 |
| --- | --- | --- |
| L1/L2 在新视频保持正、负、零三类区分 | 自然语言表述足以救回该模型的单场景行为 | 所有任务不需要关系模块 |
| V1 有效，L1/L2 无效 | 视觉输入是主要可修复瓶颈之一 | 原权重已经在原视频上看懂关系 |
| 只有 C1 有效 | 给出红块规则后模型能利用它，原自然任务仍有隐含推断缺口 | 原问题已被无提示解决 |
| Q1 事实错 | 视觉/时序识别未过关 | 原生评分必然缺因果能力 |
| Q1 事实对、因果错 | 可见事实可提取，隐含几何推断仍不足 | 仅换进度头就一定解决 |
| Q1 因果对、自然目标原生分数错 | 可显式提取关系，但原生读出未稳定体现该关系；值得测试轻量两阶段读出 | 原生方法内部必然曾使用同一关系 |
| 任一原生基线自然目标下已稳定赢所有核心配对 | 收窄对该方法的缺陷主张 | 仍宣称其必须加新模块 |

六段旧视频只用于定位和筛选版本。**在看新模型输出之前**先确定复现成本和固定组数；建议 8 组新生成、完整六元配对（48 段），保留相同三物体与几何关系，小幅变动镜头/初态/路线，并重新核物理真值、动作量、可见性。新 B0 必须在 t12 前放回且静稳，使预定末三秒窗口确实表示“返回后”。在新组上同时跑 R0 与每个基线**预先选定至多一个**自然目标救回方案；C1 只能作为额外受提示对照。事先把描述性“稳定救回”定为：每个核心配对 `B+>U0`、`H−<U0`、`H−<N0` 和成功锚点 `G+>N0` 至少 7/8 组方向正确；`B+>B0`、B0 暂态与完成子条件单列。保留精确差值和区间；7/8 是决策门，不是普遍性证明。

若简短目标句或视觉优化过门，则不需要为了这个单场景结果引入新模块。若自然目标仍失败而 Q1 显式因果正确，另建**最小**关系读出 v2，与同权重直接提示 D2、最佳无模块变体在相同实际帧和近似 token/时延预算下比较；先用旧六段做回归，全部错例与弃答保留，再到第二个物理机制的新开发场景验证。只有跨机制新样本上的稳定增益，才支持更广泛的方法主张。若 Q1 因果也失败，优先研究感知/推断能力或训练数据，不把复杂模块预设为解法。
