# Relation and counterfactual methods: executable mental models

## Relational preconditions / SORNet / ReKep

[Sharma & Kroemer](https://proceedings.mlr.press/v155/sharma21b.html) learn pairwise object-relation representations in simulation, then classify if a named skill can execute; their real setup uses fused multiview geometry. [SORNet](https://proceedings.mlr.press/v164/yuan22a.html) conditions RGB features on canonical object views and tests spatial relations plus skill preconditions. [ReKep](https://rekep-robot.github.io/) obtains RGB/points/segmentation, proposes keypoints and generates staged relational constraints, then uses geometry/collision and execution feedback. Their predicted quantity is skill executability or constraint satisfaction, not our offline 15-point progress. Training/implementation privilege (skill label, 3D, simulator points/seg, executable controller) is not allowed in this Monitor.

With a *known* correct relation, all four cases are simple: B+ false→true, B0 false→false, U0 true→true, H− true→false. But source selection and whether this relation is actually necessary remain unprovided. The old human-fact substitution only demonstrates that a deterministic rule maps those states to directions; it does not test visual extraction. A useful ablation is relation-correct but alternate-route-present video: if the method still calls B+ positive, relation validity alone is insufficient. Conversely, if a legally adapted single-view relation model gets the right relation and calibrated unknowns on two mechanisms, this challenges the need for a multi-step VLM proposal.

## CoINS — [paper v1](https://arxiv.org/html/2601.03956), §IV / Appendix

The observable question is whether removing object `o` changes reachability. CoINS defines a map path-gain `G(o)` after deleting that object's occupied point cloud, selecting the manipulable object with highest gain. Object masks, depth back-projection, metric map, robot skill and embodiment constraints construct training labels; the VLM internalizes this logic. Its output drives navigation/interactions, not an independent tabletop progress trace. B+ should have positive path gain, B0 remains blocked, U0 is already traversable and should not demand interaction, H− reverses connectivity. These cases directly anticipate our alternative-route concern. Native CoINS cannot be used under goal+single preparation RGB video with no map/skill inputs; copying its question into a prompt is only a hypothesis, not original CoINS. Falsifier: an adapted **same-budget direct** counterfactual question identifies a concrete alternative route or remaining blocker from the legal video and beats relation checking; then choose that simpler route, not an added verification agent.
