## 0. 可作的主张和当前门槛

首轮目标是**离线、冻结模型的逐要求监测判断**：在已有局部成果后，判它是否仍有效；若一个局部动作成功却使另一项**原指令要求**失效，能否及时撤销当前有效性，同时不抹掉确曾发生的历史事件，也不误撤销仍有效的成果。全程约束只在原指令确实给出或单列的受控新指令条件中评分。正常慢速、必要调整、停滞、真正退步是反向压力测试；若所选材料没有足够真值，只报告可见窗口变化，不宣称识别意图或永久失败。D017 的“终态不能倒推全程”和 D030 的历史、累计成本规则贯穿全文。

**目前不满足正式 H1 测试的数据门槛。**下表及[来源与试标清单](07_source_and_trial_annotations.md)核实了实际文件和少量样例，却尚未核得同时具有原始要求、局部成功后失效与未失效的真实配对、完整同步轨迹、可审计参考状态及清楚再用许可的材料。故下面的指标、预算和决策规则是预注册草案；带“待决”的项目不能被视为已冻结的正式测试配置，更不能宣称阶段 6 完整验收。若最终只有终态要求，应缩窄为当前关系有效性，不评分全程合规；若连当前关系的正反例也不可标，应回到问题定义，不为保留 C1 凑样本。

## 2. 标注对象、证据权限与时间

单位为 `u=(轨迹 r，要求版本 v，对象 o，状态变化事件 k)`；对象取：历史事件 `H_o(≤t)`、当前有效条件 `C_o(t)`、过程/区间合规 `P_o([a,t])`、整体完成 `G(t)`，以及单列窗口变化 `W_o([a,t])`。**参考层** `R_u(t)∈{真,假,参考未知}` 可用完整视频、同步特权状态或独立记录；**在线支持层** `J_u(t)∈{可确认真,可确认假,未知}` 只用当时声明的允许历史。`R` 真而 `J` 未知是合理遮挡，不是模型漏检；`J` 可判不自动表示模型看懂。参考未知不得由在线猜测补成真/假，单列数量和原因，不进入有真值的主分母。每个标签存证据来源、相机/传感器、帧/时间、要求原话与标注解释、置信理由和歧义。

`t_e(u)` 为参考中状态变化/违反的发生时刻，若只有相邻帧则记区间 `[t_e^L,t_e^U]`；`t_v(u,q)` 为权限条件 `q` 下**该对象、该变化**首次有充分在线证据的时刻或区间。`t_j` 是共同查询时刻。可判性存为多个半开区间 `V_u^+`/`V_u^-`；状态再被遮挡即结束该段，再出现证据可开新段，**一次可判不保证以后持续可判**。当前关系的 `t_v` 不借给过程合规或完成。若 `t_e`、视频时间和传感器时间未能同步，记待对齐/区间不确定；主延迟仅从保守 `t_v^U` 后第一个共同判断机会起算，不捏造精确秒数。未发生目标事件的轨迹记“无该事件”，不虚构检出延迟或右删失事件；已确认事件但始终没有可判机会者记“不可评在线检出”，排除条件性检出延迟分母并报告数量。只有已进入可判风险区间但观察结束前未检出的事件，才记该分析中的右删失。监测 JSON 的首次非接受帧仅是监测状态记录，须核对谓词语义、完整轨迹和时钟后才能认作物理违反的 t_e；尤其 eventually 类义务暂未满足不自动等于当时已经发生不可恢复违反。

在线权限首轮拟为 `P0-RGB`：原始指令及生效修订、从同一固定单相机视频在每个完整秒取不晚于该秒的最近帧、这些帧的轨迹内时间；历史池仅由已到达的抽样帧构成。动作命令、执行回执、深度、特权状态、监测 JSON、标签、任务成功反馈、未来画面、跨轨失败记忆、人工关键帧和额外相机均禁止。参考标注可用完整材料但与模型输入物理分离。若最终源视频有不同原始帧率，1 Hz 抽样规则和最近过去帧规则不变；若帧率/对齐使目标变化无法观察，该事件不能补成可判。`P1`（动作/第二视角/传感器）只能作为独立信息条件，不能与 P0 主比较混算。上述 P0 是**计划配置，受数据门槛和阶段 7 可行性门槛约束**。

旧证据规则：带时间的确证历史事件保留“发生过”，即使成果后来失效；模型先前**误判**可凭合法新证据更正，保留旧输出和更正日志，不倒写成原先正确。当前真值只有连续可见、可靠跟踪且无未观察交互等已审定条件才可延续；一开始遮挡、跟踪断裂、视角不足或不确定接触，不能凭旧画面永久确认当前仍真。没有统一秒数的“保鲜期”；根据对象、可能交互、采样遗漏和传感器误差逐条裁定。过程 `P` 的“始终”真要求完整区间证据或足以覆盖间隙的可信传感器；1 Hz 画面通常不能排除两帧间短暂违反，故此时在线 `P`/`G` 保留未知。已确证且语义不可逆的过程违反可保留为假，当前关系仍可在合法修复后重变真；允许修复与否只按原指令或明确修订，不由模型自定。指令修订在生效时刻产生新版本和评分段，不追溯改变旧判断；任务描述歧义先标“待澄清”，不替用户补速度、保持或碰撞禁令。

**试标与复核**：[清单](07_source_and_trial_annotations.md)是本执行者对几个真实文件的单人诊断试标，保留不可判和指令歧义，**没有独立标注者一致性结果**。正式纳入前由至少两名互不看对方标签/模型输出的标注者按同一说明独立标参考状态、证据区间与 `t_e/t_v`；必要时将全轨参考审查和在线前缀可判审查分配给不同人以防未来画面污染。报告对象级混淆、原始一致率、`t_v` 区间重叠/差值、分歧类别及仲裁前后数量；由第三人依原话和原始证据仲裁，无法消解者保留“参考未知/指令歧义”及筛选原因，不为得到好结果而删除。标注准则只在开发/试标阶段改版，保留旧版与影响清单；保留测试不用于改标签规则以迎合模型输出。

## 3. 冻结模型、基线、输出映射与资源

**首轮拟用模型**：[Qwen/Qwen3-VL-2B-Instruct 官方权重](https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct)，固定 HF revision `89644892e4d85e24eaac8bacfd4f463576704203`、原始 BF16 权重与同 revision processor/chat template。官方模型卡标 Apache-2.0，支持文本、图像与视频；本协议只送离散 RGB 帧及轨迹内时间。HF 文件树的 `model.safetensors` 为 4,255,140,312 字节；`config.json` 的文本位置上限为 262,144，但这是配置容量，**不是本地可承受帧数或吞吐的证据**。本机 `nvidia-smi` 为 RTX 4060 Laptop、8188 MiB VRAM、驱动 595.97；原始 BF16 加视觉、KV 缓存和运行时是否可装入仍**待阶段 7 最小烟测**。目前未下载权重、未装推理环境、未验证 Windows 后端/处理器版本；若不能运行，须在测试解封前记录替代精确 checkpoint、量化影响及重新冻结，不能把不同权重版本的结果当同模型机制比较。模型卡与[配置](https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct/blob/89644892e4d85e24eaac8bacfd4f463576704203/config.json)为接口依据，不能据营销性“长视频”描述假定本机可运行。

**主预算档 B1（设计上限，非已测性能）**：共同观察/判断钟每轨迹内完整秒一次；各方法每钟最多 **1 次该冻结 VLM 调用、4 张 256×256 RGB 帧、处理器计数的输入文本+视觉 token ≤4096、输出 token ≤256**；任何携带到下一钟的文字状态/摘要 ≤512 token，计入下次输入上限。超限不截掉有利/不利内容后继续，而记预算失败并按失败规则评分。模型温度、解码、图像预处理、时戳表达、提示和阈值在开发集确定并在保留测试前冻结；默认拟采用确定性解码。所有基线有相同历史**来源池**和原指令。B1 的主约束是**每个共同钟与整轨累计的 VLM 调用/输入输出 token 上限**，并固定图像张数/分辨率；即 `N` 个钟的上限为 `N` 次调用和 `N×(4096+256)` token，初始条件解析、摘要建立、选帧、触发检测所需调用均占额度。独立代码、CPU/GPU 预处理、检索、状态维护、壁钟延迟、峰值显存和若有的网络/费用另逐项报告实际值及每判断、整轨累计值，不伪造任何已测速度。B2 若确需两调用，必须另设 **2 次/钟**同等 token/图像总额的 S2 对照，不把 B2 对 B1 的增益解释成机制。若实际接口无法按这些限额给出有效输出，只能在阶段 7 的开发先导改版 B1 并重新冻结，当前 B1 保留为预设而非假装可运行。

| **CaM** | [CVPR 2025 原文](https://openaccess.thecvf.com/content/CVPR2025/html/Zhou_Code-as-Monitor_Constraint-aware_Visual_Programming_for_Reactive_and_Proactive_Robotic_Failure_CVPR_2025_paper.html)用两路 RGB-D、几何追踪/分割与部分 ConSeg 环境微调；[作者页](https://zhoues.github.io/Code-as-Monitor/)当前未给可核验的完整代码入口。不能删这些能力后报“原 CaM 同权限”。保留任务/机制强参照；原系统只在获得匹配权限和合法复现时进入独立条件比较，P0 的代码化约束检查若做则标 *CaM 思路适配*。若无法运行，H1 结论只能限于本协议已实现强对照，不能宣称胜过 CaM。 |
| **其他近期方法** | [Sentinel](https://proceedings.mlr.press/v270/agia25a.html)完整 STAC 需动作块分布与校准，P0 仅可能比视觉失败报警；[Robometer](https://robometer.github.io/)有发布权重，但输出连续进展/二元失败并有既有大规模训练及阈值，适合 B 类独立对照；[RoboFailRing](https://github.com/DynamicPoet/RoboFailRing)代码期待外部失败图像库、任务 ID 和多相机，所查仓库无数据及许可证，不能在 P0 冒充等权限。SafeManip 是特权参考真值/规格参照，不是视觉同权限模型。首轮不强迫完整运行这些系统，也不以“论文未报”断言其做不到。 |

输出统一解析为每对象 `+`（确认真/有效）、`−`（确认假/失效）、`?`（证据不足）、`⊥`（未运行、超预算、非法/不可解析），并留原文与证据时间。二元“失败报警”**只**映射为其定义的失败/未失败及对应已明示约束，不给它补历史事件、合法未知、过程合规或整体完成的细粒度输出。连续进展分数仅在开发集冻结阈值后比较明确的窗口变化/整轨故障，不能逆推出逐项有效性。不可比较对象记 `NA`，不强加 `?` 再惩罚；可比较的二元输出若在在线未知区间硬报成败，则照样计过度确信。新增条件生成必须有“原话/研究者新指令/方法推断”来源字段，推断条件不能冒充原任务要求。

## 4. 两种公平实验、划分与冻结

**判断机制实验（H1 主实验）**：对所有方法预先固定同一相机、1 Hz 历史抽样流和每钟实际四帧包：当前帧、起始帧、最近 `t−1 s`、最近 `t−5 s`（不足或重复则去重、不补未来帧）。各方法从轨迹开始顺序处理**完全相同的包前缀**；可保有自己的 ≤512 token 状态/摘要，但此前看到过的包、产生/维护状态的调用与整轨成本必须同源同档。`t_v` 依据此合法前缀而非原视频中未送入的高帧率画面复核。每钟都评分/保留输出，不由 C1 自行挑时刻；若事件驱动触发另有内部成本与报警分析，不能改变主评分机会。固定包可能漏失效；这会产生 `J=?`，不是强迫失败判断。

**证据选择实验（可选，独立于 H1 归因）**：各方访问同一截至当前 1 Hz 历史池，在 B1 的帧/调用/token 上限内选不同 ≤4 帧；记录选帧及来源时间，比较均匀/近期、S1 自选与候选选择。若多相机或额外高帧率可见性变化，另标信息条件。选择结果改善只支持证据分配收益；随后把**实际选到的完全同一证据包**交给各判断方式作机制复核。C1 不能以专属历史台账掩盖基线未见旧帧，S1 应能从相同前缀按同预算建立摘要；若实在无法同时匹配摘要质量、调用和 token，报告这些差异并收窄因果主张。

材料角色：`试标` = 本文件列出的公开样例，只用于检验字段/缺口，永久排除正式测试；`开发` = 以后有许可和完整真值时调指令解析、帧选、提示、阈值；`先导` = 阶段 7 仅测可标性、可运行性、预算和方差，允许改协议但必须升版本；`保留测试` = 在数据审查、模型/提示/阈值/预算/指标代码全部冻结后才解封一次主分析。即使不训练，也按**任务族、场景配置、来源策略/操作者/生成程序和同一原轨迹衍生视角**构建近重复连通组，整组只在一个角色；复用任务改写或视频切片不能跨组。公开样例/论文演示若看过即不作保留测试；基座模型可能预训练见过公开素材，记录这一不可排除风险，不伪称完全防泄漏。所有开发尝试及更改原因登记；任何看过保留结果后的新指标/阈值只作探索性分析并另找新测试源。

## 5. 共同评分、指标公式与统计

设 `Q_r={0,1,...,⌊T_r⌋}` 为轨迹完整秒的共同判断机会；所有方法同机会输出或记 `⊥`。标签者事后标事件与可判区间，**不给方法事件时刻**。H1 主分析单位是一次先前局部成果后的**对象状态事件**，不是帧：`E−` 为该成果后相关当前条件参考失效、且至少有一个共同钟落在 `J=可确认假` 区间的事件；`E+` 为相匹配的仍有效事件，且有 `J=可确认真` 区间。`E+` 的锚点取同类后续动作/交互后首次重新可判机会，而非任取长时间静止帧；匹配依据任务要求、对象关系、场景及动作/遮挡风险在看模型输出前固定，同一轨迹密集正帧不能重复充样。每事件取新状态**首个**合格共同钟 `q_u`；对时间区间含糊者取 `t_v^U` 之后首钟。多事件同轨迹保留事件 ID，方差按来源聚类。无可判机会的事件计在筛选/删失表，不塞入主分母；若 `E−` 或 `E+` 为空，**不得宣布 H1 主比较成立**。

对方法 `m` 的首钟输出 `Y_{mu}`：

\[
\mathrm{CY}^{-}_m=|E^-|^{-1}\sum_{u\in E^-}\mathbf1(Y_{mu}=-),\quad
\mathrm{CY}^{+}_m=|E^+|^{-1}\sum_{u\in E^+}\mathbf1(Y_{mu}=+),\quad
\mathrm{BCY}_m=\tfrac12(\mathrm{CY}^{-}_m+\mathrm{CY}^{+}_m).
\]

`BCY`（两侧平衡正确覆盖）是 H1 **主指标**；`?`、`⊥` 和错判均贡献 0，一律未知无法得分。并排报告错误确认 `FC_m=|E^-|^{-1}Σ1(Y=+)`、错误撤销 `FR_m=|E^+|^{-1}Σ1(Y=−)`、首钟漏检 `Miss0_m=1−CY^-_m`（拆为错误确认、未知、失败/非法），不可将 `?` 当正确检出。已确认失效事件的时间延迟 `D_u=min{q∈Q_r∩I_u^-:q≥q_u 且 Y_{mu}(q)=−}−t_v^U`，其中 `I_u^-` 为包含首个合格钟 `q_u` 的本次可确认假区间，且限参考条件仍失效的时段。可见性结束或片段结束时未检出则右删失；条件先被修复应单列“修复前未检出”的竞争终止，不能在修复后把错误报警算检出。重新出现可判区间的机会另作预先约定的分段分析，不能跨遮挡无界搜索第一次负输出。报告检出累积曲线与删失数；片段结束、传感器掉线及运行失败分别注明。物理 `t_e→检出` 的延迟另列，仅在时钟已对齐时计算，不与 `t_v` 延迟混名。

在参考真值已确认的全部预定对象×共同钟上另分 `D={J∈{+,-}}` 与 `U={J=?}`：`coverage=Σ_D1(Y∈{+,-})/|D|`，`correct_coverage=Σ_D1(Y=J)/|D|`，`selective_error=Σ_D1(Y∈{+,-},Y≠J)/Σ_D1(Y∈{+,-})`（分母零时报未定义），`overconfidence=Σ_U1(Y∈{+,-})/|U|`。所有 `?` 在 D 中降低覆盖，所有 `⊥` 在 D 中降低正确覆盖并另报运行失败/非法率；在 U 中 `?` 是合适弃答，`⊥` 不算合适弃答。参考未知段独立报告总量、持续时长、原因与模型有无硬报，**不混进**上述 U 分母或用作正确率。各指标均报原始分子/分母、按对象及来源分层，不合并参考未知和在线未知。对 `H/P/G/W` 只在有原任务语义和相应真值时分别评分，绝不拿二元失败分数填满所有对象。窗口 B 类仅在有明示截止/速度或经审定的净变化误差与必要调整证据时另列双向混淆；回到原位只判该窗可见净位移，不判所有信息/准备价值。

主要对比是**同一轨迹、同一事件/钟、同一冻结模型**的 C1−S1 `BCY` 配对差，并同时看 `FC/FR/Miss0/coverage/overconfidence` 与成本。主点估计按上述公式在全部合格事件上分别计算两侧比例再等权合成，不另改成各轨 BCY 等权平均；轨迹内保存各侧的正确数与分母，再按任务/场景/来源连通组整体配对重采样、每次从这些计数重算 BCY 及差值，形成 95% 区间。同轨多帧和同任务多轨绝不当独立样本。若独立任务组太少导致聚类区间不稳定，报告逐任务配对差与精确/保守置换或任务级区间，不报虚假显著性。随机采样方法在相同种子/抽帧下成对重复；确定性解码也要在先导核对重复性。样本规模不在此凭空承诺：阶段 7 用先导的**任务组级配对差或分层估计影响值**估标准差 `s`、正反事件率和可判比例，正式独立组数按预设 95% 区间目标半宽 `h=0.025` 的近似 `n≥(1.96s/h)^2` 计算并以组级重采样校核；单组缺一侧事件时不能硬算该组 BCY，须用整体分层估计影响值并检查两侧跨组覆盖。若所需组数/正反事件不可取得，则缩窄或停止，不暗改 `h`。重复次数取能使运行随机性的配对差 Monte Carlo 标准误低于 `h/4` 的最小次数，并报告决定过程；全程不拿测试集估这些量。

**判读阈值是研究上预设的实际价值界限，非已测改进**：`δ=0.05`（BCY 绝对 5 个百分点），且不能以超过 `0.02` 的 FR 增加或正确覆盖下降换收益。若 C1−S1 的任务聚类 95% 区间下界 `>δ`，FR 增加的上界 `<0.02`，正确覆盖差的下界 `≥−0.02`，主预算合规且差异不被 S2/保守弃答/额外信息解释，可说**在该离线任务与权限下支持 H1 剩余价值**；对合法可运行的最近方法还需另报，未比不得声称超越。若 BCY 差的区间上界 `<δ`，或任一反向代价越界，不能支持预设的**有意义改善**；只有整个等效区间落入 `[−δ,+δ]` 才可说“无实质差异”获得相应精度支持。“不显著”/区间跨 0 或跨 δ 只算**证据不足**，不自动证明等效。阈值若经先导显示与标注误差/资源不相称，必须在保留测试解封前升版并解释，不能事后移动。

## 6. 反证、消融、决定与阶段边界

| 预设检验 | 可能支持 H1 的观察 | 否定/收窄规则 |
|---|---|---|

## 8. 阶段 7 最小实现的操作约定（draft-3 增补）

此节仅消除字段和边界歧义，不把合成夹具提升为数据证据。一个在线轨迹文件只含轨迹 ID、帧的轨迹内秒数/路径/校验、原指令版本与对象 ID；参考 `R/J`、事件/可判区间在**独立标签文件**，不得由运行器读取或写进提示。开发清单登记每件材料的来源、许可证、角色、纳排理由和哈希；先前已看样例均标 `screening_only`，不得转保留集。

共同钟从轨迹起点 `0 s` 开始取非负整数秒，直到已知最后一个观察时间的下取整；每秒的允许池只取时间 `≤t` 的最近原始画面，不插补未来。固定包在该池取当前、起始、`t−1`、`t−5` 秒对应帧；负目标钳到起点，同一画面去重。`q_u` 为落在目标可判半开区间且 `q≥t_v^U` 的首次共同钟。若只有事件发生区间没有在线可判区间，则主检出分母不含该事件。所有方法的输入清单与实际帧 SHA 逐钟落盘；S1 通用摘要和 C1 台账均只能由各自已见的相同包前缀生成。

工程解析契约为严格 JSON：顶层 `judgments` 是按预先声明对象 ID 的列表，每项的 `H/C/P/G` 值仅为 `+/-/?`，可附不晚于当前钟的 `evidence_time`；顶层 `memory` 是可选的跨钟文字。`S0` 不继承 memory，`S1` 把它作为普通历史摘要，`C1` 把它作为待检验的条件台账；两者均须在下一钟重新计 token，且其文字本身不是参考真值。无法解析的整段输出对该钟全部对象记 `⊥`；可解析但缺失/重复/越权对象或非法字段的对象仅该对象记 `⊥`，原文仍保留。模型可承认不知道；解析器不从自由文字替它补正误。多对象在 256 输出 token 内是否可行待烟测，不可运行时须开发阶段升版。

预算以实际处理器展开后的输入 `input_ids` 长度计文本和图像 token，以实际生成 token 数计输出；读取旧摘要/台账、初始解析、额外选帧或触发调用全部计入当钟和全轨。任何一步超 B1 上限记 `budget_failure` 并输出 `⊥`，不静默截掉内容后重试。异常/中断留失败运行记录和原始错误；恢复只能从已持久化的最后完整钟续跑，不重写先前输出或累计成本。因修复而提前结束失效风险段时记 `repair_competing`，不可见段或轨迹终止前未检出记右删失，两者不得混算。以上实现行为须以合成语义测试核验，**不提供 H1 的任何效果证据**。

## 9. 阶段 7 工程核验后的补充约定（draft-4）

`E−` 的首次共同钟还须**早于合法修复时刻**；若状态在首个可判共同钟之前已修复，该事件列入“修复早于评分机会”，不进 BCY 分母，也不当右删失。计时的全钟墙钟时长从指令版本/选帧开始，覆盖提示构造、图像读入/预处理、推理和解析；另存模型适配器内部时长，不能把合成后端的伪 token 或零显存作资源测量。旧摘要/台账的 token 按同一处理器重新计算，输入 token 由处理器展开后的 `input_ids` 实测。

在线轨迹媒体路径在真正模型运行前逐件重算 SHA-256；与清单不一致则停止该运行并记来源失败，不采用后来同名文件。此规则来自本轮合成夹具路径被烟测图覆盖的实际问题；旧 `fixture_chain` 已审计作无效来源，另建隔离的 `fixture_chain_v2` 重跑，记录不删除。恢复时已落盘的失败钟保持 `⊥` 和已耗调用，后续只从下一钟继续；汇总既要报告整个轨迹是否走完，也要列失败钟数。

冻结模型的工程提示 `engineering-v2` 在共同格式中强化单字符 `+/-/?` 与纯 JSON 要求，三法共享该格式，只在直接判断/逐项摘要/证据台账的更新规则上不同。此前 `engineering-v1` 的合成输入输出多为围栏或非法值，保留原文并记 `⊥`；提示修订仅证明接口可解析，**不构成 H1 的开发调优或机制效果**。H1 先导若以后获准，须在合法开发材料上给 S1 合理滚动摘要和同等开发机会，锁定一个新提示/协议版本后成对运行；不能把本轮合成 v1/v2 数字当效果比较。

已定向补查 RoboCasa365 实物任务/逐集元数据及 RoboFAC 任务 QA，见[来源清单新增节](07_source_and_trial_annotations.md)与[机读筛查清单](../experiments/data_manifest.json)。它们补齐任务级文字和时间结构字段，未证实每集执行时原话/修订，也没有经过独立复核的“局部达成后失效/仍有效”对象级参考事件与 P0 可判区间。故阶段 6 继续为**草案**，阶段 7 的 H1 开发先导停止，保留测试未解封。最小外部材料需求为：同一原任务族下至少各一条可研究再用的完整失效与仍有效轨迹，执行当时原话/修订、同步视频及足以审计对象状态的参考材料、允许用途与来源标识，再由第二名独立标注者盲标和仲裁。若这些材料不可得，可另议事前向所有方法同样宣告、明确“放入篮后在搬运期间保持面包在篮中”的 `C-NEW` 受控指令并重新采集正反执行；它须独立报告，不能改称 RoboCasa 原话的隐藏义务，未经用户决定不实施。
