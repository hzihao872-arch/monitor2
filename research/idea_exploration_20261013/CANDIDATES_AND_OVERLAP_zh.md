# 候选机制与相邻工作

2026-10-13。用于判断想法如何收敛，不能据此声称穷尽了文献。

## 三个候选的完整机制

| 候选 | 科学问题 | 输入与输出 | 真值与训练 | 接入机器人 | 决定性验证 |
|---|---|---|---|---|---|
| 1. 完成机会变化 | 环境变化为何对目标有作用，后果监督能否迁移 | 目标＋视频前缀；机会差值向量、作用、独立完成判定 | 匹配状态干预＋相同冻结续行；小头或 LoRA，策略冻结 | 固定技能的继续／准备选择 | 换目标、尺寸与关系；等数据普通微调；独立闭环结果 |
| 2. 能力边界适应 | 监督者能否从少量局部经验学会当前机器人的能力边界 | 状态＋目标＋技能／能力；局部成功概率与不确定性 | 合格技能结果按顺序更新适配器，基础模型与策略冻结 | 技能触发与准备选择 | 换冻结控制器；等反馈检索／校准／普通更新；旧能力保持 |
| 3. 未来条件与准备 | 哪项目标条件将被下一步破坏，哪项准备有用 | 前缀＋候选短技能；未来条件及候选方案收益 | 实际准备／续行分支；动作条件头，先不训练完整世界模型 | 有限候选中的高层选择 | 当前状态分类器、一般风险预测、规则规划与恢复基线 |

三条分别研究变化监督、部署适应和动作后果预测。它们可共享工具，但不能用多个模块叠加后的结果替代各自的机制证据。

| 工作 | 已有覆盖 | 对候选的影响 | 需要额外证据的区别 |
|---|---|---|---|
| CoINS | 用反事实地图后果产生交互必要性监督；技能能力入上下文 | 支持候选1的借鉴来源，也限制其“首次反事实”主张 | 操作中的接触／支撑／空间教师；任务条件与成对机会差值监督 |
| Relational Preconditions | 用交互后果学习关系，并迁移到少标签技能前提 | 是候选1直接操作先例，必须比较 | 从静态前提判定扩展到环境变化的目标作用；同关系、不同目标和能力测试 |
| Robot Critics | 成败与时间配对学习局部进度比较 | 普通偏好学习已经成熟 | 同源状态受控干预，相同续行和预算提供局部后果标签 |
| ARS | 环境事件、条件撤销、核验、修订与离线筛选 | 覆盖原问题中的很多现象 | 后果监督的学习与泛化价值；与强事件评价器公平比较 |
| Robo-Dopamine-2 | 历史条件进度、合成正负与恢复、编辑数据 | 数据编辑和恢复标签已有先例 | 真实分支后果定义标签；不默认原图正、编辑图负；小数据收益 |
| SayCan／ConditionNET | 技能价值与动作前提／后效 | 候选2不能只叫“学可行性” | 能力改变后的顺序适应；局部反馈归因和物理事实保持 |
| HiRE | 带结果历史改变奖励支持集 | 候选2必须比较非参数适应 | 等反馈下局部能力更新是否优于检索与全局修正 |
| MoMo | 部署中的失败监测学习与人类干预 | 从经验更新监测不是新概念 | 不更新策略的能力迁移实验与局部结果监督效率 |
| eVTA₀／FIERCE | 评价器适应、结果监督和策略学习 | 限制泛泛的“监督者进化”说法 | 冻结机器人、明确局部反馈与能力依赖；避免只换系统名字 |
| ContactGuard／Foresight | 动作条件未来特征与风险 | 候选3不能只加一个未来预测头 | 具体条件后果和准备选择产生独立收益 |
| CoRe | 想象续行、最小恢复、冻结策略交接 | 对宽泛预测恢复方案的重叠很强 | 多种有效目标路径与实际后果监督；需超过重表述 |
| STRIPS World Models | 视觉转移学习、离散条件与规划 | 条件世界模型与规划已有组合 | 少数据、局部预测或新泛化问题上的机制证据 |
| UniGoal／MomaGraph／TFP／主动感知规划 | 图匹配、功能更新、时序记忆与主动核验 | 这些模块可用，暂不独立推荐 | 新反馈目标与公平消融，不能靠操作场景替换宣称新颖 |

## 保留、修改与暂缓

| 原始灵感 | 判断 | 修改后的可研究版本 |
|---|---|---|
| 开盖、展开支撑算进展 | 保留其自然动机 | 后果监督学习完成机会变化；现象本身已有工作覆盖 |
| image editing 造正负例 | 修改 | 提出候选环境变化／外观扰动，用物理分支或独立核验决定作用 |
| 终局成功教会所有中间判断 | 修改 | 局部合格技能反馈；只对被尝试的条件／能力更新 |
| 机器人冻结，Monitor 越用越懂 | 保留为第二候选 | 能力改变后的顺序适应，明确更新的适配器与对照 |
| 世界模型想象未来、然后恢复 | 收窄，优先级第三 | 短技能的任务条件后果与准备方案比较，核查 CoRe 等强先例 |
| 从导航借图记忆和核验 | 作为方法部件保留 | 服务于具体条件问题；与直接操作先例比较 |
| 换更强视觉模型 | 作为强对照 | 判断新监督是否仍有收益；不独立承担主贡献 |
| 一次集成训练、TTT、世界模型、RL | 暂缓 | 先选一个学习问题和一个机器人接口取得因果上可解释的证据 |

## 选题不应依赖的推论

- 现有八例出错，不推出新架构有效；强底座解决八例，也不否定后果监督作为独立研究问题。
- 门打开、物体没动、之后回退，这些现象不是新的发现。
- “导航用了，我们转操作”需要明确教师、关系和控制语义的变化。
- 标签来自机器人后果，就只在声明的技能、预算与目标条件下成立；不能自然升级成通用物理价值。
- 当前报告没有新训练或闭环结果；优先级依据是问题的自然性、可证伪性和依赖规模。
