# 从研究问题长出来的 Monitor 想法

2026-10-13。选题构思与一手文献核查，尚未运行新实验。

## 先说最值得讨论的想法

**让 Monitor 学会判断：一个环境变化，给完成任务创造了什么机会，又拿走了什么机会。**

这条想法直接来自我们关心的现象：方块还没移动，盒盖打开，任务已经向前走了一步；支撑面展开，后面的放置才有意义。开盖、移开障碍、搭好支撑看上去是不同动作，却有一个共同作用——改变接下来可以怎样完成任务。

顺着这个理解，监督也很自然：把机器人放在变化前后的两个状态，从那里继续做同一个短技能，看看成功机会、所需准备和执行代价有什么区别。用这些实际后果教 Monitor，它就有机会学到“为什么这一步有用”。

第二个值得讨论的想法是：**让 Monitor 通过执行经验，逐渐学会当前机器人的能力边界。** 同样一条缝，对小夹爪够宽，对大夹爪不够；物体在物理上能放稳，也不代表当前控制器能顺利释放。机器人策略保持冻结，监督者可以通过少量尝试学会“对这台机器人，什么时候真的可以继续”。

第一条适合作为主选题：问题、监督来源和研究方向衔接得最紧。第二条适合作为独立候选；是否值得做，取决于执行反馈能否提供比普通技能成功分类更强的学习信号。预测未来保留为第三条扩展，已有非常接近的工作，需要进一步收窄机制。

本文的构思依据是研究问题与师姐的建议。已有 Monitor 的错误、旧流程和八个开发例只影响验证方式，不决定选题。

## 想法一：从执行后果学习环境变化的任务价值

### 为什么会让人觉得合理

假设目标是把方块放进盒子。把盒盖从关到开，目标方块可以完全不动，但下一步放入变得可行。反过来，在放入前重新关盖，会把这个机会拿走。换一个目标，例如把盒子保持关闭，开盖的作用又不同。

因此，变化的任务作用可以由三个量共同决定：**目标是什么、改变了哪个环境条件、接下来允许怎样执行。** 这给出了一个有物理依据、能通过实验检验的学习问题。

师姐建议的少量微调、图像编辑和世界模型，都能放到这个问题里：微调用来学习后果与视觉变化的联系；图像编辑扩充外观或提出候选变化；世界模型提供待检验的续行预测。选题的中心是监督依据，工具选择随验证结果调整。

### 怎样成为一个具体方法

训练时，从可复位的仿真状态构造一对分支。两支保持目标物、机器人初始配置、控制器、时间预算和随机种子一致，只改变一个环境条件，如入口宽度、障碍位置或支撑面状态。对两支执行同一组预先定义的短续行方案，用独立的几何、接触、释放和稳定性条件评价结果。

记一个续行方案为 k，一个预算为 H。教师估计：

`q_k(s, g, H) = 从状态 s 执行固定续行方案 k，在预算 H 内满足目标 g 的概率。`

变化的标签来自 `q_k(s_after, g, H) - q_k(s_before, g, H)`。有随机性时需要重复试验；确定性仿真中的单次结果只支持该具体配置，不能包装成可靠概率。

学生 Monitor 读取目标与视频前缀，预测哪些续行机会增加、减少或保持，以及当前是否已经完成。第一版固定续行库，学生不必在测试时执行仿真。若后来支持新的技能或机器人，则必须把能力描述或技能条件加入输入，重新定义泛化范围。

**先保留机会向量，再根据明确规则汇总作用。** 如果不同续行方案受益与受损并存，就报告混合作用，不能任意挑一个成功分支说整体变好。完成判定保留独立输出；续行库包含停止选项，已经满足任务时不强迫继续动作。

学生可以先用冻结视觉语言表征加小预测头；如果需要学习细粒度几何关系，再比较 LoRA。机器人策略和续行控制器都保持冻结。训练目标至少包括分支结果预测与成对差值预测；结构化条件描述可以作为辅助监督，不能先假定它必然带来收益。

### 最小例子与一个必要边界

入口从 0 mm 变成 30 mm，方块宽 46 mm。对于立即放入的固定技能，两支都失败，不能因为“盖子动了”就捏造正标签。

如果续行库允许继续以小步打开，且实际测得 30 mm 状态减少了后续准备代价，才有依据称为部分准备。若尚未测得这种差异，标签只能是“结构变化、立即放入机会未增加”。这使“有变化”“有准备价值”“已具备执行条件”成为可检验的区别。

同样，支撑面的展开需要通过后续放置和释放来验证。视觉上出现一个平面，只是候选证据。支撑条件必须在目标规定的稳定观察窗口内有效；任务已经结束之后发生的扰动，应按新的监测义务处理，不能悄悄延长原任务定义。

### 与已有工作究竟差在哪

CoINS 已在交互导航中用反事实地图比较移走物体前后的可达性与路径代价，再把这种判断蒸馏给 VLM。它还具有训练过的操作技能，不能描述为“导航完全没有操作”。对本选题真正有用的是**用可计算的后果产生监督**这一机制。[CoINS，IV-C 至 IV-E](https://arxiv.org/html/2601.03956v1#S4.SS3)

转到桌面操作，需要把地图连通性教师换成接触、支撑、装配空间和技能续行结果。移走一个物体可能疏通入口，也可能撤掉支撑；入口让物体通过，也未必让夹爪通过。这些差异要求新的后果定义和成对数据，单纯替换场景名称不足以构成贡献。

操作领域也有直接先例：Relational Learning for Skill Preconditions 从仿真交互后果学习物体关系表征，再用少量标签学习技能前提。因此，“用物理后果学习前提”不能作为首次提出的主张。我们的待检验点是把**受控环境变化、目标条件与续行机会差值**组织为监督，训练视频前缀中的任务作用评价器。[Relational Learning for Skill Preconditions，III](https://arxiv.org/html/2012.01693v1#S3)

Robot Critics 已利用成功轨迹与失败轨迹的配对、以及成功轨迹内的时间顺序学习进度比较。这里的区别需要落实为同一状态的环境干预与相同续行，而非把两条整体成败不同的轨迹直接当作局部作用真值。[Robot Critics，3.1](https://arxiv.org/html/2606.21572v1#S3.SS1)

ARS 已评价环境条件建立与撤销；Robo-Dopamine-2 已训练带历史、正负与恢复的进度评价，并使用编辑数据。这里不能声称首次处理目标物未动、撤销或图像编辑。需要证明后果监督比事件描述、时间代理和同预算普通微调更能迁移到新的尺寸、关系和目标。[ARS，3](https://arxiv.org/html/2609.34484v1#S3)、[Robo-Dopamine-2，方法及附录](https://arxiv.org/html/2608.15680v1)

### 什么结果能支撑这条选题

关键结果应该是：在新物体、新尺寸关系和新目标上，模型能根据变化所造成的后果判断作用；它还能够拒绝视觉相似但功能无效的准备。在固定机器人和固定高层动作集合中，这种判断减少无效续行，并提高独立任务成功率或减少成功所需准备次数。

特别有价值的测试是“同一变化，换目标后作用改变”和“外观变化相似，物理后果不同”。如果模型只记住“开盖好、收支撑坏”，这条想法没有被验证。

建议首先做静态学生和固定技能的高层继续／准备选择。离线数据筛选可以作为另一个接口，但不宜同时承担第一轮主结论；完整策略 RL 也不是验证这个学习问题的必要条件。

## 想法二：让执行经验教会监督者当前机器人的能力边界

### 自然的出发点

环境条件有两层含义：它在物理上提供什么机会，以及当前机器人的技能能否利用这个机会。二者相关，却可能不同。

如果我们换一个夹爪、一个抓取技能或一套释放动作，物体、任务和盒子都不必改变，但“可以继续”的边界会移动。让监督者通过少量执行学会这条边界，正好回应师姐关于“机器人不动，监督者从经验中进化”的建议。

### 更新什么，怎样更新

保留目标与环境状态的表征，单独学习一个技能／机器人条件化的可行性适配器。输入包括当前状态特征、目标、拟执行技能和可用能力信息，输出本次短技能的成功概率及不确定性。首次部署用已有数据初始化，之后按真实执行顺序更新适配器；基础 VLM 和机器人策略先冻结。

每次反馈只监督**实际尝试的技能与当时的局部状态**。例如已经进入放置阶段、成功释放并稳定的结果可以更新放置条件判断；在抓取阶段就失败的整段任务，不能直接教模型“盒口太窄”。仿真阶段用阶段与接触日志审核这种归因。若现实反馈只剩最终成功／失败，就应收缩为整段结果适应，不继续宣称学到了局部条件边界。

一个干净的实验是：训练阶段使用小夹爪或宽容的放置控制器，测试阶段换成能力受限但冻结的控制器；按顺序提供少量合格技能反馈，观察新夹爪条件下的判定和后续选择怎样改善。同时保留旧能力测试集，检查是否把“当前机器人做不到”错误改成普遍的物理事实。

### 这条的贡献要求更高

SayCan 已把语言任务相关性和技能价值结合起来；ConditionNET 已学习动作前提和后效条件。HiRE 已用执行结果调整奖励支持集。MoMo 已在交互部署中学习失败监测。eVTA₀ 与 FIERCE 也有评价器适应，并与策略更新结合。因此，“根据成败微调一个 Monitor”本身不够。[SayCan](https://arxiv.org/abs/2204.01691)、[ConditionNET](https://arxiv.org/html/2502.01167v1)、[HiRE](https://arxiv.org/html/2609.27068v1)、[MoMo](https://arxiv.org/html/2310.17552v1)、[eVTA₀](https://arxiv.org/html/2609.33653v1)、[FIERCE](https://arxiv.org/html/2609.18651v1)

本候选的潜在贡献是：**用可归因的局部经验学习能力依赖的条件边界，并保持对目标与环境事实的判断。** 它必须在相同反馈预算下优于支持集检索、单阈值校准、普通局部监督更新，以及不区分能力的整体结果学习。

若这些简单对照同样有效，就应采用简单方法，或把它作为想法一的部署模块。第二条目前值得作为候选，不适合先保证独立论文价值。

## 想法三：预测哪项任务条件会被下一步破坏，用它选择准备动作

### 顺着监督者往前走一步

当前状态可以满足条件，但接下来的动作会把它破坏：搬动物体时带走支撑、夹爪进盒时撞上盖板、释放后失去稳定性。一个有用的预测型 Monitor 可以比较“直接继续”和“先做一个准备动作再继续”，指出哪项条件会改变，并让固定高层接口选方案。

第一版只预测少量与目标有关的条件在短技能之后是否成立，训练小的动作条件头；不必先生成完整未来视频。真实分支结果是训练与评价真值，世界模型可用于提出候选或扩充经核验的数据。若只有观察前缀，没有拟执行技能或可解释的默认策略，就不能把输出解释为特定动作后果。

### 为什么暂列第三

Foresight 与 ContactGuard 已利用动作条件未来表征监测风险。CoRe 更接近完整的“冻结 VLA、想象续行、寻找最小环境恢复、再交回策略”框架。STRIPS World Models 已把可学习视觉转移与离散规划结合。因此，未来预测加恢复已有强先例。[Foresight](https://arxiv.org/html/2606.23085v1)、[ContactGuard](https://arxiv.org/html/2608.13438v1)、[CoRe](https://arxiv.org/html/2608.14822v1)、[STRIPS World Models](https://arxiv.org/html/2606.06832v1)

可以继续探索的差异，是用明确任务条件比较多个有效完成路径，并用实际准备／续行分支监督选择，而非只预测风险或恢复到原路径。这个区别仍需通过实验形成方法贡献；仅把预测输出改成条件文字不够。它还需要动作日志、可复位状态和多个准备技能，工程依赖比第一条多。

建议在已经取得分支后果数据之后再尝试它。若当前状态加技能的分类器已经足够，未来潜在动力学不必加入。

## 导航借鉴应该借到哪一层

| 可以借的机制 | 移到操作后的实质变化 | 需要比较的直接先例 |
|---|---|---|
| 反事实可达性监督 | 接触、支撑、夹爪空间与目标条件共同决定续行后果 | CoINS；操作中的 Relational Preconditions |
| 目标与当前场景的图匹配、接近后核验 | 识别正确实体只是开始，关系还需满足尺寸与接触条件 | UniGoal；MomaGraph 的功能关系更新 |
| 探索中的记忆与错误候选排除 | 操作会主动改变条件，过去的否定需要能撤销 | UniGoal；TFP 的时序与接触更新；ARS 的修订 |
| 选择更有信息的观察 | 改变视角应降低影响决策的条件不确定性 | Robot Planning and Situation Handling with Active Perception |

图记忆和主动核验可以帮助上述想法，但已有操作工作覆盖其中很多部分。当前不把“加图、加记忆、加一次核验”列为独立主选题。[UniGoal](https://arxiv.org/html/2503.10630v1)、[MomaGraph v2](https://arxiv.org/html/2512.16909v2)、[TFP v3](https://arxiv.org/html/2607.08283v3)、[主动感知规划](https://arxiv.org/html/2604.26988v1)

## 最后的取舍

**优先讨论想法一。** 一句话能解释动机，也能明确指出数据为何这样构造：环境准备改变完成机会，用匹配续行后果提供监督。它把少量训练、造数据和导航借鉴接到同一个科学问题上，同时允许先做小实验。

**把想法二作为第二候选。** 它与“监督者从执行中学习”衔接最好，但需要建立能力迁移与局部反馈的独立价值，不能只做终局标签回灌。它与第一条可以共享数据工具，论文问题应分别评估，不必一开始叠加。

预测型想法是有吸引力的扩展；完整视频世界模型、全套规划和策略 RL 先不加入首轮必要条件。具体最小实验、对照与投入见 [MINIMAL_EXPERIMENTS_zh.md](MINIMAL_EXPERIMENTS_zh.md)。文献关系与定位见 [CANDIDATES_AND_OVERLAP_zh.md](CANDIDATES_AND_OVERLAP_zh.md) 和 [SOURCES_zh.md](SOURCES_zh.md)。

这些是经过邻近机制核查的研究假设。已有文献支持它们的出发点，尚未证明所提方法的收益、迁移性或独立新颖性。
