# 研究想法讨论材料

2026-10-13。以“沿着研究方向自然长出的想法”为目标，不以修复现有 Monitor 为选题依据。

- [主报告](REPORT_zh.md)：三个具体想法，优先推荐完成机会变化与能力边界适应。
- [与师姐讨论](DISCUSSION_WITH_SENIOR_zh.md)：可以直接讲清楚的动机与追问回答。
- [最小实验](MINIMAL_EXPERIMENTS_zh.md)：分阶段验证、强对照、参数与成本边界。
- [候选与重叠](CANDIDATES_AND_OVERLAP_zh.md)：完整机制、相邻工作和保留／修改判断。
- [来源定位](SOURCES_zh.md)：固定版本、原文 URL 与实际阅读范围。
- [来源清单](sources/manifest.json)：本地公开论文快照索引。

本轮只做文献核查、构思与实验设计，未运行新模型训练、机器人实验或服务器任务；旧文件未改写。
