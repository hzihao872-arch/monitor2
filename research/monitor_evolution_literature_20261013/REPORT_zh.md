# 机器人 Monitor 的监督者进化：查重、借鉴与下一版方案

检索截止：2026-10-13，Asia/Shanghai。仅检索、阅读、只读源码核查与写新研究笔记；没有训练、模型评估、仿真或机器人实验。本文优先依据最新 idea_team 材料，已阅读用户指定的五份笔记、相关 mechanism / literature_followup / overlap_followup 文件，以及两张师姐截图。旧报告均保留。

## 先用一个例子理解问题

任务：把红方块从**指定入口**放进去，释放后由**指定平台**稳定支撑。假设入口在物体通过期间配置固定、观测充分。

| 时刻与变化 | 物理条件 | 当前仍需的条件 | 已完成成果与任务判断 |
|---|---|---|---|
| 入口打开，方块未动 | 通行条件可能成立，需绑定方块尺寸和路线 | 仍需要通过入口 | 建立准备条件，可以帮助下一步；尚未完成放置 |
| 入口关小，小到方块不能按合同通过 | 经几何核验才可标通行 false | 仍需要通过 | 阻碍下一步；不等于撤销已完成放置 |
| 重新打开，方块完整通过 | 当次通过见证成立 | 此后通常不再需要入口 | “已经进入”完成；后来的通过不能给中间关小阶段贴 true |
| 释放并在规定时间窗稳定支撑 | 指定支撑关系成立 | 稳定支撑须按任务要求继续维持 | 放置完成，检查最终完成条件 |
| 此时入口关闭 | 入口条件可能 false | 不再需要入口 | 放置仍成立时，关闭入口可以与当前任务无关 |
| 平台被移走，方块失去指定支撑 | 支撑关系 false；原证书失效 | 支撑要求仍在 | 当前成果被撤销，应报告退步；历史上曾完成这一事实仍然保留 |

我们要学习的是：**后来出现的局部交互证据，怎样纠正和训练前缀 Monitor，同时不误改它不支持的历史状态；这些改进能否传递到任务进度判断。** 条件判断是子模块，最终输出仍包含帮助、阻碍、无关和成果撤销。四类可能同时出现，例如移走平台既撤销成果又阻碍后续；建议内部保留多标记，再按预先约定的优先级生成单标签。

这里“前缀”就是当前及以前的画面；“证书”是附着对象、时间和核验依据的事实记录；“传播”是把该事实作为邻近历史状态的候选训练标签；“校准”是用另外一批审核材料检查规则多容易出错。“小头”是接在冻结视觉特征后的小预测网络。它们是不同步骤，证书不会自动给出可传播边界。

## 本轮判断

1. **“部署反馈反过来更新机器人 Monitor”已有直接实现。** Model-Based Runtime Monitoring、Sirius-Fleet、ThriftyDAgger，以及新补充的 Willibald–Lee 增量执行监控系统，都不能绕开。它们不全是视觉进度模型，但确实更新运行时监控组件。
2. **“执行后修正评价者”也不限于异常监控。** 新补充的 GCR 用在线失败末段微调奖励表征；HiRE 用执行结果更新奖励支持集。前者更新参数，后者更新记忆，须分开。
3. **环境条件、后视核验、区间传播和退步均已有重要先例。** ConditionNET、ARS、WVN、Robo-Dopamine 2.0 和 Video2STL 分别覆盖相关部分。不能用“它们只看目标物体”或“只有我们用未来纠正过去”制造区别。
4. 本轮**没有找到一篇核实为全部同构**的实现：独立局部物理证据＋证据适用范围学习＋条件/成果/剩余义务分离＋更新仅看前缀的视觉 Monitor。但这只是检索范围内的结论，模块组合不自动成为方法创新。
5. 建议保留方向、收窄主张。首版研究**同反馈与人工预算下，证据适用范围控制是否比直接纠错和事件帧学习更有效**。先用短区间与拒绝传播，LTT 作为有足够独立审核数据后的选项。

## 最接近的五篇如何借

方法细节与证据定位见 [五篇精读及代码审核](DEEP_READ_AND_CODE_zh.md)。五篇是 Runtime Monitoring、Hierarchical Task Decomposition、ConditionNET、ARS、WVN；另核查 Sirius-Fleet 与 GCR 的更新链条。

- Runtime Monitoring：借累积反馈、按轮替换和独立评测监控器；改掉接管代理标签，使用任务限定的证书/直接纠错；固定策略以分离贡献。
- Hierarchical Task Decomposition：借对“不熟悉”与“已知异常”的不同处理，以及子目标和约束各自建模；不照搬力域GMM当视觉条件真值。
- ConditionNET：借冻结特征的小条件模型与预期状态比较；不能照搬三类互斥阶段作为多个物理条件的标签，core无判断也必须单独报告覆盖。
- ARS：借证据覆盖、修改后重新核验和保留局部退步；作为离线标签教师/强对照。物理证据的独立性需要传感/日志/人工标准，不能只换一个同款VLM。
- WVN：借事件—历史图像关联、异步小头更新、新旧证据组织；把保守导航损失与真值监督区分，未知区域不能当我们的可靠负例。

## 师姐建议的精确解释

两张截图确认她接受“小量初始化→新执行→错误/不确定/结果→核验→更新Monitor”的流程。她提到 ttt，并写“不动原模型参数”，但没有指明“原模型”是哪一个。下面三条都属于我们提出的可行解释，不能反写成她的确定原意。

| 路径 | 固定/更新对象 | 合适的名称 | 本项目的取舍 |
|---|---|---|---|
| 冻结执行策略，更新Monitor | 执行策略固定；Monitor小头/适配器甚至主体可更新 | 部署反馈分轮微调；若跨轮保留旧能力则研究持续学习 | 推荐用于归因；当前没有已确认可靠策略库，先做记录流设计 |
| 冻结Monitor基础权重，只更新头/LoRA | 基础权重固定；整体Monitor函数会变；执行策略可另外固定 | 参数高效适应；不是“Monitor完全不训练” | 首版小头，失败后再考虑适配器；小头无法补回冻结特征里缺失的几何信息 |
| 所有模型参数固定，更新证据缓存 | 更新支持集、检索结果及证据版本 | 非参数记忆适应 | 必须做强基线；HiRE已提供先例；上下文失效的证据不能继续检索使用 |

经典 [TTT，ICML2020](https://proceedings.mlr.press/v119/sun20b.html) 用测试输入的自监督目标在测试时适应。收到本次执行结果后、审核后给下一轮训练，是**延迟监督适应/分轮重训**；不因发生在部署后就自动叫经典TTT。若当场更新，仍须写清何时反馈可用、优化什么、哪些参数持久保留。持续学习还要验证遗忘；检索更新没有梯度。世界模型可预测未来，但预测不能作为独立标签真值。

## 更具体的方案与最低成本入口

建议题目层面的研究问题：**“局部执行证据的适用范围能否在有限人工预算下改进因果任务监控？”** 暂不以“首个会进化的监督者”或“LTT保证机器人安全”为主张。

三个方案按复杂度排列：

1. **事件帧＋直接纠错＋任务账本。** 最容易实施，也是最强简单基线之一。局部事件只给其实际证明的帧/短窗口；人工挑关键条件与进度状态纠错；冻结特征训练头。无自动扩展的新颖性，适合作为可靠原型。
2. **连续局部片段＋相关变化截断＋拒传。** 从证书锚点向相邻历史生成候选；身份、查询、相关配置改变、遮挡或冲突即停止。独立审核验证误传播与覆盖。推荐先验证这个机制是否值回成本，不能把“没检测到变化”叫物理不变证明。
3. **独立风险校准选择传播规则。** 固定传播器和参数集，采用LTT或单规则二项上界。只有审核数据足够、方法2已有收益时升级。它控制的是选定统计风险，不能生成证书、边界或保证出域安全。

整体接口与实验规格见 [方案与最小验证设计](DESIGN_AND_MVP_zh.md)。核心是分别维护条件当前真值、成果当前有效性、历史曾完成事实和剩余义务。先限定入口/指定支撑两个合同及少量固定任务图，承认这不是任意任务自动分解。

主实验在相同初始Monitor、相同接口、相同记录流与完整预算下，比较直接状态标注、事件-only、未校准扩展、校准扩展；加固定窗、证据缓存、阶段边界、RWS/HMM等实际必要的强对照。新增条件头则所有组都加；不能用条件标签代替阶段/进度标签。之后适配第二种可训练Monitor，再比较完整系统。离线ARS与在线前缀系统分别报告。

成本必须包含事件核验、负例获取、传播器训练、完整范围审核、任务合同、人类时间、计算和反馈数量。真实/外部稀疏证据是潜在应用；现有仿真全状态的直接真值训练必须保留，不为了显得省标签人为遮掉现成标签。

## 是否值得保留，什么时候应该放弃

**值得保留为研究假设，不宜立即投入完整持续学习系统。** 证据显示问题有实际接口缺口，但目前没有结果证明新监督更好，也没有保证论文贡献成立。

| 重合/障碍 | 可操作调整 | 判据 |
|---|---|---|
| 闭环与冻结小头已有 | 用已有骨架，研究证据适用范围及任务进度收益 | 不再宣称闭环本身首创 |
| ARS区间审核及退步高度重合 | 同证据预算比ARS教师；测试其区间合法性；在线教师不得看到未来 | 若ARS同预算同样好，放弃“新核验架构”主张 |
| 范围机制近似普通时间传播 | 比固定短窗、阶段截断、RWS/HMM；计入训练/审核成本 | 若简单规则同样好，保留简单规则，撤回复杂算法贡献 |
| 只有成功证书，失效没有真值 | 另收可靠几何反证、指定接触失效或独立人工审核 | 未取得可信负例前，不声称学会失效 |
| 回溯前态缺少相同上下文 | 只取事件窗口或unknown；支撑不能跨释放/对象姿态变化倒推 | 若大多数证据不能扩展，事件-only可能更合理 |
| 隐藏变化在视觉前缀不可辨 | 输出拒答与可观测性标记；分别报告可见/不可见子集 | 不把增加推理次数当成解决不可辨性的办法 |
| 范围审核比直接状态标注更贵 | 做总分钟—任务监测质量曲线 | 若没有预算收益且无其他收益，不保留传播主线 |
| 条件提升不改善进度，或损害普通任务 | 进度/完成/撤销作为共同主指标，保留普通物体任务 | 仅条件准确率提升不足以完成当前目标 |

当前没有“整个研究致命重复”的证据；**如果方案只是小量SFT＋部署后再SFT＋已有区间规则，则以新算法立项的理由很弱。** 若进一步研究范围仍不能胜过直接纠错，剩余价值可能是清楚的评测/数据组织贡献，须凭困难实例、可靠真值和成本证据支撑，而不能改名保住新颖性。
