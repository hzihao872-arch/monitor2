# 经查重后的方案与最小可行验证设计

2026-10-13。以下全部是未来设计，不是已经实现或做过的实验。当前授权不含训练、模型评估、仿真或机器人执行；本轮没有启动这些活动。现有九条开发录像仅用于理解已有资产，不是充分校准样本，也不是未见测试集。

## 1. 精确研究问题与贡献边界

给定任务g及观测前缀o₀:ₜ，Monitor估计环境条件、已完成成果是否仍有效、当前剩余任务条件，并据此判断变化的任务作用。后来的独立局部证据用来训练下一部署快照。待检验问题是：**控制证据对历史的适用范围，能否在同人工/交互预算下减少错误监督，并改善最终进度判断？**

已经有先例：执行数据更新监控器、冻结编码器小头、物理体验回配视觉、离线后视核验、阶段限制传播、前缀因果监督、任务逻辑和非参数奖励编辑。参考 [Runtime](https://arxiv.org/html/2310.17552v1)、[WVN](https://arxiv.org/html/2404.07110v1)、[ARS](https://arxiv.org/html/2609.34484v1)、[RoboMonitor](https://arxiv.org/html/2609.30715v1)、[Robo-Dopamine2](https://arxiv.org/html/2608.15680v1)。

待验证而非既成创新：查询绑定的证据适用范围是否比普通窗口/阶段界更有用；拒传能否改善预算效率；条件和义务分离能否避免真实任务退步误判；监督范围控制能否跨第二种Monitor仍有效。若只是组合已有接口，可能是评测/数据贡献，需凭新困难实例和同预算收益支撑。

## 2. 从条件头接到整体进度，不能直接替换任务

首版给定两类条件合同和少量人工确认任务图，承认限制；不同时研究通用任务自动分解。

每项查询q至少记录：物体ID、入口/平台ID、刚体形状/尺度、指定路线或候选放置配置、条件含义、需要的证据来源。区分两种完全不同的支撑查询：

- “这个平台对指定放置配置有稳定支撑能力”，是尚未使用前的能力条件；
- “这个已释放物体现在确实被指定平台稳定支撑”，是当前效果关系。

后者的释放稳定事件不能自动给释放前贴true；前者若回推更早配置，需要独立能力判据及配置保持证据。首版优先做后者，避免把当前事实与反事实能力混在一起。

内部变量建议：

| 变量 | 含义与监督 | 例子 |
|---|---|---|
| Cₜ(q) | 条件当前物理真假；缺标签用mask，推理证据不足可unknown | 指定尺寸物体在固定入口几何中存在合同路线 |
| Aₜ(k) | 历史上曾达到里程碑；时间事实不回改 | 红方块曾完整进入、曾稳定放置 |
| Vₜ(k) | 里程碑的当前成果是否仍有效 | 方块仍在目标区，指定支撑仍有效 |
| Rₜ(q) | 剩余任务当前还需不需要条件q；由任务合同/合法前缀事件决定 | 通过之后入口通常不再需要；支撑需按合同维持 |
| Eₜ | 当前证据可靠性/可观测性与引用 | 遮挡时旧证书不再足以证明当前情况 |

unknown是对真值的知识不足，不是第三种物理状态。停止相信旧证据不等于条件已为false；证书失效与事实失效也不等价。若V未知，报告未知，不偷偷保持旧true或改false。

输出保持结构化：`{conditions, achieved_ever, valid_now, still_required, task_complete, change_roles, uncertainty}`。整体变化角色定义：

1. **成果撤销**：先前有效且仍须维持的成果现在被独立反证否定；A保留，V撤销。
2. **阻碍下一步**：尚未解除的必要条件由true变false，或已false造成当前指定步骤无法满足合同。判断的是该步骤/指定路线，不能在未检查其他方案时断言整个任务无解。
3. **帮助任务**：建立必要准备条件，或达到/恢复有效成果。条件成立本身不等于动作已完成。
4. **无关**：变化不影响剩余义务或仍需维持的成果。例如已稳定放置、无须再经入口时，入口关闭。

同一变化可以有多个角色。外部若必须四选一，预先约定“撤销>阻碍>帮助>无关”，并保留内部多标记；这是报告接口选择，不宣称新理论。

首版建议进度用 `(当前有效成果, 当前可执行准备, 剩余义务)` 三项展示。若必须单一标量，预注册里程碑权重，以V计算成果分，准备度另列，避免开门和经过开门重复计分。任务要求到达后维持到何时必须写明；不把历史success-once当当前完成。

## 3. 什么证据实际能生成什么标签

### 通行证据

物体完整通过指定入口，能够见证当次交互确实发生。要教“某时刻固定场景中存在无碰撞通路”，还须入口/障碍配置在通过过程固定且路径证据合法；若边走边开门，动态通过不直接证明任一单帧静态配置的同一命题。证书绑定物体/尺寸/路线/有关碰撞几何。不会证明所有控制器或姿态都能通过。

### 支撑证据

释放后连续规定时间窗内，由指定平台承托、无夹爪/其他支撑、位移/速度满足合同，可以标该稳定窗口内关系。不能倒标释放前、尚在晃动的阶段，也不能保证任意未来扰动下稳定。若只知道最终留在盒内，没有支撑身份/其他接触证据，证书不足。

### 可靠负标签另有来源

完整几何核验发现指定路线不可通行；直接观测/传感证实指定支撑解除或物体脱离目标关系；独立人工按明确标准审核。碰撞一次、技能执行失败、超时和最终失败均不能独自证明环境条件false。没有真实负证据时，先限定为正事实学习和拒答研究，不声称解决失效。

### 证书记录

`{event_id, q, anchor_interval, polarity, measured_at, available_at, verifier, dependency_set, context, evidence_refs, quality, version}`。

`measured_at`是事实对应时刻；`available_at`是核验完成可以用于更新的时刻。若核验错误后来被纠正，保留旧版本及撤回原因。审核者不能仅复述学生判断；自动事件检测器若也是学习模型，需计入其训练/误差/审核，不能当免费oracle。

## 4. 第一版传播器：先简单，再决定是否校准

建议首版做有限规则：从可信锚点向前扫描相邻片段；只使用q相关对象/部件关系、跟踪质量与可见性。身份改变、尺度/查询改变、相关关系变化、遮挡、证据冲突任一出现，即拒绝继续。候选可以是短窗集合；不跨短暂失效再恢复来涂满两真锚点之间。

这条规则从图像检测“未发现相关变化”，仍不是物理不变证明，故标签是经独立审核的候选监督。隐藏锁扣/载荷变化等可观测性问题需要unknown和统计检查。若有完整仿真状态能逐时刻直接判真，直接训练真值是更强且更简单的基线；不制造人工缺标成本。

对比以下替代：事件-only；固定短窗或指数时间衰减；仅按动作阶段截断；条件相关视觉截断；[RWS](https://openaccess.thecvf.com/content/WACV2024/papers/Hirsch_Random_Walks_for_Temporal_Action_Segmentation_With_Timestamp_Supervision_WACV_2024_paper.pdf)或锚点约束HMM。RWS的种子传播与HMM平滑都已有；如果现成规则同预算同样好，就不加BOCPD/HSMM求解器。

只审核“有没有相关变化”并不能免费获得完整合法范围。要估算范围误传播，需要审核者能判断锚点与历史是否同查询、是否存在隐藏/不可见状态，未知是否算未认证；这部分成本须独立记录。自我评分、VLM置信度不是独立审核。

## 5. LTT是否必要：重审后的取舍

[Learn then Test](https://arxiv.org/html/2110.01052v5)可以检验固定候选策略风险并处理多重检验；不是边界生成器。风险控制伪标签也有 [Selective Generation](https://proceedings.neurips.cc/paper_files/paper/2024/hash/5a6815122f533193a022cbc41786c1cc-Abstract-Conference.html)、[ConformalSAM](https://openaccess.thecvf.com/content/ICCV2025/papers/Chen_ConformalSAM_Unlocking_the_Potential_of_Foundational_Segmentation_Models_in_Semi-Supervised_ICCV_2025_paper.pdf)先例。加校准不能宣称首次。

最简单的有统计检查版本是：**预先固定一个规则，独立审核后用二项置信上界；不在同批审核数据上挑多个窗再当单规则检验。** 只有确实需要从多个候选中选覆盖最好者，才用LTT或合法多重检验。该建议避免在首版引入不必要算法，不说明统计验证成本消失。

若上LTT，可定义整条独立轨迹损失：

`L_i(λ)=1{该轨迹至少有一次接受的传播超出独立认证范围}`。

未知范围算未认证。拒传轨迹损失为0，因此风险是随机轨迹上的未认证传播概率，**不是接受帧的条件错误率**。必须同时报告非空传播轨迹比例、合格覆盖/分钟、每轨迹等权覆盖和学生收益；全拒绝零风险不算成功。若关心已接受区间的选择性错误率，另定义风险，不能把前者结论套用。

校准要求固定传播器/候选、独立可交换或同分布单位与可靠审核。相关帧、同回合多个事件、同脚本的近似重放不是更多独立轨迹。主动难例采集使数据分布变化，不能直接用它估计普通部署风险。

量级计算：对单个预先固定的Bernoulli规则，n个独立审核轨迹零污染时，95%单侧上界是 `1-0.05^(1/n)`；n=9约28.3%，达到不高于5%至少59条。当前九条又是被看过的开发材料，不满足这个独立前提；59也不是足够训练整个Monitor的承诺。多候选、条件子组及反复挑选/重校准会增加成本。

学生参数更新但固定传播器、目标部署分布稳定时较容易保持校准对象。改传播器、改变收集策略/环境域或任务合同后，旧保证不能自动沿用。重新独立校准，或只报告经验风险；不未经证明称随时有效。近期[Experience-Driven Terrain](https://arxiv.org/html/2609.39755v1)的新域验证＋历史anchor更新门值得借鉴，但那是经验模型升级门，不等于传播风险定理。

## 6. 冻结路径与更新协议

首版设计：固定执行策略/记录流，固定视觉主体，更新小型时序条件/成果头；任务账本为所有组共有。若冻结表征缺少身份/细几何，再考虑视觉或语言LoRA，并重新匹配所有组。不是预设8GB机器能训练任意VLM；RoboMonitor原文预训练/微调用多H100，不能把52标注回合读成低总成本。

两个部署选择：

- 分轮：M₀先预测新轮所有前缀，反馈审核后形成训练集，回放新旧证据得到M₁，再部署。最易归因，推荐。
- 即时：只用在当前时刻已可用证据更新，记录每次参数/缓存快照；需要更严格预序评估与延迟/遗忘控制，首版暂不首推。

这不是自动等同经典TTT。监督者原模型指谁仍未确认；上述固定对象是本项目实验设计。记忆基线在所有参数固定时更新同样证书，检索匹配q与上下文、撤回失效证据；它与小头更新是独立选择。

未来信息只进入离线教师制标签。对时间t的训练样本，学生输入只含≤t观测；同轨迹不同窗口需因果mask。不能让未来帧通过视觉摘要、检索、文件名或归一化统计泄入学生。迟到证据可纠正过去标签、训练下一模型，但在线指标保留当时已发出的预测，不让新模型追溯重算来改善旧指标。

## 7. 分阶段最小验证，按门槛继续

### 阶段0：规格与数据可行性

本轮只完成规格，不实施。未来先核对两类合同能否独立认证正/负事实；九条旧录像只能解释例子和调试标注规则。列出需新增的不同场景/物体/配置与独立审核来源；没有已确认真实机器人/成熟技能库，不把真实闭环写作既有资源。

若没有可获取的真实/外部局部证据，可先进行仿真机制验证，但必须承认它仅测试污染/覆盖，不证明真实省标签。现成仿真state真值全部用于oracle上界/直接监督对照，不隐瞒。

### 阶段1：只测试标签构造，先问是否省审核

未来拿冻结规则比较事件-only、短窗、阶段截断、相关变化截断、未校准/校准版本。独立审核完整范围，记录遗漏短暂false、错误实体、跨配置和遮挡误传播。只看有效标签/总分钟、污染—覆盖曲线，不以伪标签总帧数算收益。

通过门槛：在预先约定污染容忍度下，净合格监督/总成本胜过短窗或直接审核，并覆盖可靠失效/撤销案例。若新增监督大都需完整人工范围，自动传播价值可能不存在；此时保留事件-only/直接纠错。

### 阶段2：同一Monitor公平主比较

所有组同初始权重、输入前缀、输出头与任务账本、反馈记录流、数据划分和训练计算（无法完全匹配则透明列出）。主比较四组：

| 组 | 在同预算下买什么监督 | 必须计入的额外成本 |
|---|---|---|
| D 直接状态标注 | 人直接标条件、当前成果和角色；可挑信息量高帧 | 看录像/挑帧/纠错全部分钟，不用随机糟糕帧削弱它 |
| E 事件-only | 只用事件实际支持的窗口＋共有义务监督 | 事件检测、核验、负事件取得 |
| U 未校准扩展 | 同事件与传播特征；依规则扩展 | 传播器初始训练/人工规则、开发审核 |
| C 校准扩展 | 同事件与传播器；独立范围校准＋拒传 | 全部校准审核、多候选选择和重校准 |

同一批后续执行证据对四组共享，不能让某组得到更多正负事件或更容易场景。D可以把其他组的校准分钟用于额外直接标注，这是必要成本对照。义务/里程碑监督统一，不把未来已知阶段oracle仅送给提案。条件标签不能直接作为进度标签；共有账本输入来自模型前缀预测或共有合同。

强简单基线：E＋冻结小头＋相同任务账本；D主动状态纠错；同证据非参数缓存。按阶段1结果保留短窗/RWS/HMM中实际竞争者，不为了数量把所有复杂方法都训练一遍。oracle有效区间与全state标签是上界，额外特权必须标明。

指标分三层：

- 监督：轨迹级污染概率、接受区间/帧错误率（分别定义）、非空接受率、可认证覆盖、正/负标签比例、总人工分钟与事件数。
- 条件与成果：true/false宏召回，false放行/误拦截，失效/恢复定位与延迟，指定实体绑定，unknown覆盖—误差曲线，V当前有效与R剩余需求正确率。
- 整体任务：帮助/阻碍/无关/撤销宏F1；完成精确率/召回；条件已用完后的假退步；普通目标物体任务是否退化；如适用另报进度误差，不能单一均值掩盖短暂撤销。

报告episode/场景级置信区间；同一轨迹多个帧不作独立统计样本。训练/开发/校准/测试按轨迹族、场景、物体/配置分组，重复脚本相邻seed另审。测试无审核反馈，参数冻结。

### 阶段3：才测试监督者进化

按真实时间顺序，新记录先预测后审核/更新，比较固定Monitor、累计直接SFT、事件SFT、传播SFT、证据缓存。数据到达序列一致；保存轮间快照，混合旧数据回放；独立旧任务保留集与新域验证共同决定是否升级。难例主动采集另作研究，不混进第一项公平记录流。

评价新轮错误减少与旧任务遗忘、更新/审核耗时和拒答覆盖。若所有收益来自多了普通人工标签，而传播不胜直接SFT，撤回传播贡献。

### 阶段4：第二模型及完整系统

在第二种可训练Monitor复用同监督规则与接口，检验不是某一冻结表征特例；不强行复现多H100预训练。随后与ConditionNET式完整系统、RoboMonitor式前缀系统比较，明确动作/状态特权。ARS完整录像离线组与前缀在线组分开；ARS-prefix是适配而非原论文配置。最后如有独立授权/硬件再测闭环恢复或策略效果，目前不承诺机器人成功率提升。

## 8. 必须包含的反例

| 反例 | 要排除的错误解释 |
|---|---|
| 打开→关小→重新打开→通过 | 最后通过给中间false贴true；同样外观两端不证明中间 |
| 已稳定放好→入口关 | 物理条件失效被错当已完成成果撤销 |
| 尚未通过→入口关 | 真正当前必要条件失效，被账本误判无关 |
| 已放好→指定平台移走但他物临时托住 | “没掉落”被错当指定支撑仍有效 |
| 执行失败但条件合法；换控制误差后成功 | 控制失败被标环境条件false |
| 隐藏支撑/暗锁改变，可见前缀相同 | 无法观察的问题被当成视觉算法一定可解决 |
| 错物体/错入口；尺寸变化 | 存在事件但查询身份/尺度不匹配 |
| 无关背景/相机变化 | 全图变化截断丢掉监督；相关变量机制是否有收益 |
| 释放后短暂晃动，再稳定 | 终局稳定倒推过去已稳定 |
| 成功一次后成果又被破坏 | 历史A与当前V混淆，最终完成误报 |

可见/不可见子集均报告，不能删除难例后宣称普遍可靠。隐性差异确实不可从输入辨认时，正确目标应允许unknown，而不是强求零错误分类。

## 9. 成本台账、停止条件与首版决定

计数分开：独立交互回合、可信事件、可靠负证据、人工总分钟、传播器训练/校准/重校准分钟、学生GPU小时、推理/更新延迟、存储、任务合同设计。不要把相邻帧数量或低标注回合数当总成本。

任何以下结果均应调整或停止复杂主线：没有可信负例；有效范围过短；独立审核比直接标注更贵；短窗/缓存同预算同样好；条件提高不传到进度；普通任务退化；冻结表征无法绑定实体；新分布下旧校准失效且无法负担重新审核。不能以添加新模块回避这些否证。

目前推荐先形成**事件监督＋相同任务账本**的清晰规格，再以短区间候选验证范围价值。LTT需要数据与预算门槛，暂不作为项目必须坚持的核心。部署闭环是应用组织方式；如果最终有贡献，应来自可信范围、任务作用判断和预算证据，而不是“监督者进化”这个名称。
