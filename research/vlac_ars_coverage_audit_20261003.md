## 3. 洋葱例：标签继续退步，预测却回升

进展单位沿用作者的百分点。按照 `frame / 30` 定位，在线性插值曲线上读取作者语义锚点：

| 帧区间 | 作者标签起止 | 预测起止 | 方向结论 |
|---|---:|---:|---|
| 0 → 70 | 0 → 10 | 0 → 5.100 | 一致 |
| 70 → 130 | 10 → 18 | 5.100 → 9.375 | 一致 |
| 130 → 162 | 18 → 5 | 9.375 → −5.900 | 都下降，正确退步对照 |
| **162 → 240** | **5 → −5** | **−5.900 → 1.000** | **标签下降、预测上升** |
| **240 → 272** | **−5 → −10** | **1.000 → 3.278** | **标签下降、预测上升** |

两个错误区间都位于预测时间范围内部，不依赖端点外推。

进一步直接读取模型原始输出点：**6.1 秒（183 帧）预测 −8，8.3 秒（249 帧）预测 2；对应作者稠密标签为 2.3、−6.4。** 因此，预测回升现象并不是把稀疏输出插值后才产生的。标签仍是作者的标注体系，不等于独立复核后的物理真值。

逐区间数据：[anchor_diagnostic.json](sources/vlac_ars_coverage_20261003/anchor_diagnostic.json)。画面：[洋葱接触表](sources/vlac_ars_coverage_20261003/contact_02.jpg)、[原视频](sources/vlac_ars_coverage_20261003/early_example02_video.mp4)。

**我们的视觉观察：** 桌上有多种仿真蔬菜；中段纸箱被抬动/倾斜，紫色目标出现在箱体下缘附近，之后在可见桌面区域不再清楚可见；后段夹爪在黄色玉米与浅色物体附近继续操作。第 240 帧不足以支持“洋葱已入箱”。画面存在遮挡，不据此断言目标准确掉落位置。

**待验解释 H1：** 后续非目标物体操作被赋予了恢复进展。竞争解释包括目标身份混淆、遮挡下状态不确定、对于负进展/恢复的标度理解不同，以及稀疏观测遗漏。模型只输出点值，没有推理轨迹，不能从曲线反推出它具体看错了哪个物体。作者标签持续降低的精细幅度也尚未独立复核。

## 4. ARS 覆盖判断：问题重合强，具体效果未知

ARS 明确研究错误物体操作引发的虚假进展；其流程包含按需查看视频/裁剪、事件核验和外部曲线审计。它支持退步，但默认数值范围为 `[0,1000]`。这些都能对应本例的候选解释。作者也展示过核验后仍存在的边界偏差，故“有核验机制”不等于每例正确。来源：[ARS 正文与附录 A—C](https://arxiv.org/html/2609.34484v1)。

| 本例需要检查的环节 | 与 ARS 的关系 | 本轮能否下效果结论 |
|---|---|---|
| 给非目标物体操作加分 | 直接问题重合；优先作为最接近方法比较 | 不能，未运行同例 |
| 补看后续帧、局部裁剪、验证恢复是否成立 | 机制已有明显覆盖 | 不能把这些模块本身当新颖性 |
| 多物体杂乱场景中目标暂时不可见 | 比其简化错误物体测试更复杂的迁移条件 | 只是待测条件，不能命名后便宣布新缺口 |
| 作者负进展标签与 ARS 非负分值的对应 | 输出约定不同 | 不能直接以负值 MAE 判 ARS 失败 |

这里的“覆盖”是我们依据论文所作的机制对应判断，**不是 ARS 实验结果**。是否引用 VLAC-Cut 不影响这种重合判断；能否修好该视频需要同样本运行。我们没有发现 ARS 在该 VPB 示例上的公开结果。

## 6. 当前研究取舍与下一次最小比较

**本轮决策：暂不围绕这个案例设计新架构，也不凭 ARS 存在就淘汰整个研究问题。** 该错误已经足以提出问题假说，但现有“错误物体＋补看验证”解释没有形成与 ARS 的实质机制差异。此时继续扩大同类截图收集的收益低于一次同例比较。

下一次比较只使用上述 3 段开发样本，先回答：ARS 能否去除洋葱例的虚假回升，同时保留另外两例的有效进展与真实退步？

1. 使用保存的原生输出作参考；若运行基底，记录权重、prompt、输入帧与新输出，不能假定与作者缓存相同。
2. 加入固定骨干上的简单单次提示对照，以及可核实配置的 ARS；原生系统比较与同骨干机制比较分别解读。记录查看帧数、分辨率、调用数与成本。
3. 主要比较相同区间的方向及事件是否有视觉支持；去除虚假上升只是必要条件，全部输出常数不能称解决。成功推进与正确退步对照必须同时保留。
4. 对齐任务规划和离线可见信息；不向模型提供逐帧 GT、成功/失败目录名、结果标签或成功示范。ARS 若改变数值下界或使用额外结果条件，标明为适配版本，不能冒称原版结果。
5. 若简单提示或 ARS 已稳定修正且控制未受损，降低此切口优先级；若仍错，先查运行配置、信息和尺度，再根据实际失败提出不同机制。3 段只能筛方向，不能证明总体优越；后续需要新任务与保留样本。
