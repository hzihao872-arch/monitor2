# 有证据边界的 Monitor 自改进：未来规格

2026-10-13。本文件全为不运行的设计；没有已实现的模型、实验结果或硬件闭环。继承 [原方案](../monitor_evolution_literature_20261013/DESIGN_AND_MVP_zh.md)，不替换原证据范围假设。新假设单独验证，失败可删除扩展而保留原研究。

## 1. 原主线与新增假设

原主线问：同反馈成本，查询限定的局部证据范围控制，能否减少误监督并改善前缀 Monitor 的阻碍、恢复、无关变化与成果撤销判断？先固定数据选择，验证范围机制。该阶段没有通过时，不把主动选择混入主比较。

唯一新增主假设 H：**从第一轮独立范围审核学得并保留的核验排序，在相同第二轮候选池、共同学生快照和总核验预算下，比旧排序及强主动学习带来更大的独立未见轨迹任务角色宏 F1 增益；且监督污染、输出覆盖、旧任务能力达到固定门槛。**

需要区分三种结果：M₁ 在不再训练时已比 M₀ 准；M₁ 比 M₀ 更会选下一批例子；在给定相同 M₁ 输入时，新排序 w₁ 比旧排序 w₀ 更会选例子。第一种是任务能力，第二种是能力反馈到学习，第三种才支持这里的“改进机制本身变好”。它们都不等于增益越来越快或无上限。

## 2. 两条方案，固定与可变边界

### C：保守方案

固定策略或共同记录流；固定视觉主体；小头初始权重一致。独立核验给出证书/直接纠错，范围规则产生受限标签；用相同更新配方混合旧数据训练小头。只在旧任务与新域的独立升级验证通过后替换部署快照。核验对象按冻结的强选择规则挑选，范围规则首版也冻结。

优点是检验原范围主线容易，工程负担小。它属于延迟监督持续学习；账本更新与模型学习仍分别记录。对新增 H 而言，它是冻结改进机制的对照。

### R：最小受限递归方案

在 C 上仅增加一个可持久更新的核验排序权重向量 w，不加世界模型、代理代码搜索或第二套大模型。

候选审核单元 x 为 `(查询 q, 实体/尺度, 路线或放置配置, 历史候选区间, 已有证据引用, 提议错误类型)`，不是“所有帧”。候选由同一固定生成器产生，所有组共享。排序特征使用已可获得信息：当前小头的条件/成果/需求不一致；相关配置变化；证据身份/版本冲突；对边界的分歧；未覆盖类型与重复程度；估计审核分钟。具体特征必须预注册，并让强主动学习组也获得相同输入与证据缓存。尚未购买的人工真值不出现在特征、文件名或元数据中。

排序可以实现为一组固定特征的正则化线性/逻辑模型：估计一次审核发现范围错误的概率，乘以可去重的潜在受影响单元数，再除以估计审核成本。影响单元数须截断，防止靠提议极长范围占便宜。这个分数是采购代理目标，**不是物理真值、不是预先知道的最终学习增益**。最终价值仍由共同起点的学生与独立测试判定。

第一轮审核产生 w 的训练标签：提议标签是否错误、错误类别、原区间中经独立确认的支持/拒绝边界、真实审核分钟。全体候选包括拒绝/unknown/无收益项，不只保留成功提议。未审核候选为缺失标签，不能当正确或错误。w 的拟合/正则、特征和可选参数范围固定；对 w₁ 的选择只用单独开发资料，不拿最终测试回调。更新后保存权重、训练样本版本、成本与适用域。

**Monitor 更准确不必然使核验更有效。** 它可能更自信但仍有系统性盲点，也可能把剩余错误压到难以核验的隐藏状态。w₁ 只能改善有限家庭内的排序，是否有效全由实验决定。对一个固定规则调用 M₁ 进行选样，可称主动持续学习；加入 w₁ 后才测试受限的机制改进，仍不等于任意自主 RSI。

| 对象 | 首版是否可变 | 修改/使用边界 |
|---|---|---|
| 物理条件、任务合同、稳定时长、维持终点、指定实体 | 固定 | 稳定时长不能从 3 秒自动缩到 1 秒；指定平台不能换成任意托住 |
| 独立教师的核验判据与证据权限 | 固定 | 不由学生置信度或新排序签发标签 |
| 最终测试、分组、打分、覆盖和退化门槛 | 固定、封存 | 更新过程看不到逐例真值或最终成绩 |
| 策略、候选记录池、视觉主体与输出接口 | 固定 | 避免策略成功变多或换主体导致不公平 |
| Monitor 小头 M | 可按轮更新 | 只吃核验标签与同样旧数据回放；固定训练配方 |
| 核验排序 w | R 中可按轮更新 | 只改少量排序权重，不能改核验标准/标签传播规则 |
| 证据缓存和任务账本 | 可按事实更新 | 证据/事实变化不记成参数更新；关联身份与时间失效 |
| 范围接受规则、监督风险阈值 | 固定 | 首版允许提议边界、拒绝传播；不能自动扩大准入 |
| 优化器/配方选择、世界模型、任务图生成、任意代码 | 暂不变 | 将来另立假设与预算，不与 H 同时变 |

## 3. 数据、证据和升级的接口

**独立证据不是“另一个代理说正确”。** 来源可为可复核的几何/接触日志或独立人按固定合同审核；人工需能区分指定实体与支撑来源。有日志不代表无噪声，要记录测量误差、缺失和权限。如果只有同一视觉模型的自评，则该例不能成为独立物理标签。

证书至少保存 `claim/q/entity/config/source/evidence_time/supported_interval/contradictions/unknown_regions/version`。事件完整通过只给对应物体、路线、有关配置的当次见证；几何可通行条件与“动作确实通过”是两个命题。边走边开门时，动态通过也不自动证明任一静态快照的同一通行命题。负证据另取：经核验几何不可通过，或指定支撑关系确实解除；控制失败不能替代。

固定范围过滤器检查身份、查询、配置连续性、遮挡、矛盾与实际覆盖。**没检测到变化并不证明物理不变。** 外观相同的两端不能跨中间失效连起来；证据不足则事件-only/unknown，不让 w 放宽阈值。可提出候选范围，但须独立核验范围中关键变化及覆盖，再决定哪些标签入训练。

学生在历史 t 的输入只含 `o≤t`、当时合同和当时可用的共同前缀账本；后来的证据仅用于离线教师标签。采集系统的墙钟核验时刻、事件时刻、标签生效时刻分别记账。选择器在审核时可使用当时已公开的证据，但未购买真值和最终测试真值不能输入；所有主动学习组权限一致。

训练样本需同时有 `student_prefix_end=t`、`teacher_evidence_time`、`scope` 和未知 mask。教师看未来不是学生看未来；视觉摘要、检索、同轨迹随机切分、归一化统计、追踪ID、文件名都需避免泄漏。晚到证据可改变离线训练标签，不能改写当时已存的在线预测或追溯重算旧在线分数。

升级验证检查新域与旧任务，模型和排序各有版本且可分别回滚。选择器候选失败时保留旧 w；小头失败时保留旧 M。最终部署组合 `(M,w)` 另检查兼容性，因为排序会改变学习数据分布。升级验证属于可重复使用的开发门，可能被多次试验过拟合；每轮候选数固定并记录，最终封存测试完全独立。验证可给是否升级的固定信号，不能当无限供应的免费训练真值。

每轮固定 20% 核验预算用于分层随机覆盖，80% 用排序；分层至少含入口/支撑、未达成/已达成、正常/相关变化/遮挡与可靠负例候选。20% 是拟议设置，需在看最终测试之前固定；所有组同样保留它。记录每个样本被选概率，随机覆盖用于估计自信漏错和选择偏差。必要的总体统计采用分层/选择概率加权，但不许凭加权代替缺失真值。

## 4. 两轮完整例子与错误账本

以下时间是解释用假设，非已有录像测量。合同设最短稳定时长 T=3 秒；仍须维持到回合终点 t=20。通行采用指定路线与几何判据；一个时刻的 C 值若写 true/false，均假设已有相应独立核验，否则为 unknown。

变量：C 为当前条件；A 为历史曾达成；V 为当前成果有效；R 为剩余义务。unknown 表示证据不足，不是第三种物理真值。成果支撑的瞬时关系与“已稳定满 3 秒”分别定义；完整任务最终完成只有在回合结束且维持要求也满足后才签发。

### 第一轮：建立可用标签，学习何处需要审核

| 时间 | 事件/证据 | C、A、V、R 与任务作用 | 可给什么监督 |
|---|---|---|---|
| 0–2 | 指定入口打开，红方块未通过 | 几何核验可令 C入口=true；A进入=false；R入口=true。开门有帮助但未完成进入 | 独立几何覆盖的同配置窗口；**后来的通过本身不证明此窗口** |
| 3–4 | 入口关闭/缩窄至合同不可通过 | C入口=false；R入口=true；阻碍指定下一步，未撤销一个尚未达成成果 | 独立几何负证据；若仅动作失败则不标 false |
| 5–7 | 重开，7 时完整通过 | 当次 C通行见证成立；A进入=true；V在目标区=true；R入口=false | 当次交互实际证明的物体/路线/配置；不能跨 3–4 补 true，更不能自动跳回 0–2 |
| 8 | 在指定平台释放 | A稳定放置=false；稳定等待义务存在；夹爪解除需核验 | 释放事件不等于指定平台已稳，也不倒推释放前支撑效果 true |
| 8–10 | 晃动 | “已稳定满 T”尚未成立；可核验关系与运动，等待窗口 | 不把终局稳定广播给晃动期 |
| 10–13 | 指定平台独立承托，符合运动阈值持续 3 秒 | 10–13 的瞬时稳定关系可离线核验；只有到 13，A稳定放置 才 true，V当前成果=true；R维持=true | 稳定窗口的关系标签；里程碑达成时间不能提前到 10。学生在 10 没见未来，允许 unknown/尚待确认 |
| 14 | 已通过后入口关闭 | C入口 可 false，但 R入口=false；V放置仍 true 时通常无关 | 入口真假与任务作用分别监督；不误报成果撤销 |
| 15–16 | 平台/方块遮挡 | 旧证据不足以证明当前 V，标 unknown；A不回改，R维持仍 true | 遮挡区域缺失标签或 unknown，不强延续 true，也不自动 false |
| 17 | 恢复可见，指定平台移走，方块被别的物体托住 | 指定支撑=false；A仍 true；V指定放置=false；R维持=true；成果撤销，也阻碍维持 | “没有掉落”不证明指定支撑成立；需要身份/接触来源反证 |
| 20 | 回合终点，未恢复指定支撑 | 完整合同未最终完成，历史曾稳定仍保留 | 终局失败不广播为所有历史条件 false |

初始 M₀ 假设犯两类错误：把 7 时成功投到 3–4；把 13 时稳定倒推到 8–10。核验生成器提议这些范围后，独立教师明确拒绝。错误记录保存“入口相关配置改变”“释放/晃动边界”“指定支撑身份变化”“遮挡未知”，而不是笼统保存失败视频。

C 路线用这些核验标签和旧回放更新 M₁；w₀ 不变。R 路线同样更新 M₁，同时由独立审核是否发现范围错误拟合 w₁，保存下一轮排序。若 M₁ 未通过旧/新验证，维持 M₀；若 w₁ 未通过开发排序检查，维持 w₀。上述成功情况只是设计分支，不是已测得改进。

### 第二轮：让改进能力回到反馈环

新候选池换入口宽度、红方块尺寸或指定平台ID，并包含：很多普通完整通过/稳定片段；一个短暂变窄后重开的入口；一次控制滑脱但入口几何合法；通过后的关门；指定支撑被替换但未掉落；遮挡；无关背景运动。

给 M₁ 与 w₁ 的预期作用是：把核验预算更多花在相关配置短暂失效、查询尺寸不匹配、指定支撑身份、遮挡后的有效性，少花在重复简单正例。**不是把这些提议直接当标签。** 选择“滑脱失败”的核验可以发现它是控制问题，并阻止将入口 false 入库；选择“背景运动”的核验也可能发现它无需截断，但成本与无收益审核照算。

独立教师再给可靠 true/false、拒绝范围或 unknown；按固定规则制标签，训练 M₂。同样保留 A、更新 V、解释 R：尚未通过的关门是阻碍，已经通过后的关门通常无关，维持期间指定支撑解除是撤销，遮挡是知识不足。没有新证据时 w₁ 或 M₁ 再自信都不能补签真值。

**第二轮最关键的比较：** 用完全相同的 M₁ 分叉，一边 w₀，一边 w₁。各自核验同一个候选池中的不同对象，但总分钟、独立证据权限与训练预算相同；得到自己的监督后都从 M₁ 更新。若 w₁ 获得更好的 M₂，且随机审核显示未隐瞒污染，才支持“上一轮反馈改进了下一轮改进过程”。固定反馈组可能同样选中这些边界，因此不能预设 R 必胜。

### 反馈环容易在哪里失真

| 环节 | 失真方式 | 固定防线与失败证据 |
|---|---|---|
| 候选选择 | 只挑高置信易成功片段或重复正例 | 分层随机份额；可靠负例/实体类型覆盖；记录未选分布 |
| 证书生成 | 最后通过证明所有门配置；失败证明门不能过 | claim、物体/尺度/路线/配置绑定；独立负证据；不支持即 mask |
| 范围审核 | 跨关闭、遮挡或身份变化继承标签 | 固定过滤、证据覆盖与反证；未知不能自动穿越 |
| 学 w | 把学生自己的疑虑当“发现真实错误” | w 的错误标签来自独立审核；拒绝/无收益候选也记录 |
| 训练 M | 大量相邻伪帧盖过少量负例；忘记旧任务 | 证据簇去重权重、共享回放、污染审核、新旧验证 |
| 评价 | 新模型重算旧预测；同录像近邻进测试；不断看测试改排序 | 保存当时预测；按轨迹族/实体配置分组；封存测试，仅终评 |
| 更新策略 | 变相缩短稳定时间、放宽指定支撑或减少覆盖 | 合同、门槛与覆盖固定；触犯则实验无效，不能算进步 |

## 5. 不运行的最小实验规格

### 固定数据、来源与分组

首版两类合同、共同固定记录流。原九条开发录像只用于例子与标注流程，不作充分校准或未见测试。未来必须先确认能获取 independent 正负证据；没有就停在可行性阶段。若未来以仿真机制验证，现成 state 真值必须保留作为直接监督/上界，所有组同权限，且结论限于机制验证。

规划起点可采用 240 条短轨迹族：40 开发/规格、40 公共第一轮反馈池、80 第二轮候选池、40 升级验证池（新域与旧域分开）、40 封存测试（旧任务20、新配置20）。这些是**工作量示例，非统计充分性结论**；数帧不替代独立轨迹数。两类合同和关键反例须分层，每个实体/场景/生成脚本族仅进入一类 split，相邻 seed 若同族不能分散。最终样本量按开发集轨迹级方差和预定最小效应计算，必要时增加；增加前更新预算或承认只能做探索性试验。

隐藏测试需独立完整标注 C/A/V/R 与变化作用，而非只审核模型提出的片段；不知道此成本就不能宣称“省标签”。范围开发、排序训练、升级门与最终测试分开。升级新域来自已允许的更新分布，封存新域再按不同配置族保留。

学生：共同冻结视觉主体＋轻量序列/查询小头；所有组同 C/V/角色接口、同因果输入和共同合同账本。A/R 由固定合法前缀事件及合同驱动，不能把真值 A/R 只送给 R。样本没有监督用 mask；unknown 的训练与评分规则预先写明。

固定配方：首版最多每轮一次小头更新，固定更新步数上限、相同优化器/学习率/旧回放比例（可将50%作为开发起点），固定 checkpoint 选择办法；不在 R 组额外调参。原模型未指定，学习率/维度等必须在开发阶段统一冻结，不能编造已有可运行架构。若各组有效数据量不同，匹配总训练步数并记录重复曝光；多监督组不能偷偷多算力。

### 主比较与必要基线

| 组 | 反馈选择与更新 | 它排除的解释 |
|---|---|---|
| F 固定选择＋固定配方 | 分层、去重、按预算的冻结合理排序；原范围标签与小头更新 | 只是每轮多监督，固定程序已够用 |
| D 累计直接监督 | 挑有用状态/任务角色直接标注，累计更新；可用全部省下的范围校准成本多标注 | 方法省的是伪标签帧，未省人工 |
| AL 强主动学习 | 每轮最新 M 的不确定性＋分歧＋多样性＋成本＋任务相关性、错误回放、随机覆盖；同范围规则 | 普通主动学习已能达到；不得用固定 M 或糟糕随机 AL 削弱它 |
| R 受限递归排序 | 最新 M＋由独立范围反馈更新 w；其他组件与 F/AL相同 | 查询限定范围错误信号是否有增量 |
| K 证据缓存 | 所有模型参数固定，同证据/预算，检索匹配 q/config、证据失效撤回、相同账本 | 收益是否无需训练、只来自额外信息与记忆 |
| Z 冻结学习器 | 相同初始 M 与接口，不更新；可按固定协议更新事实账本 | 参数训练是否确实有增量 |

D 可以使用与范围组相同的审核/事件信息及条件头。F 不是必须随机采样；用合理冻结排序才公平。K 不接测试终局/未来证书，只有当时可用证据。旧研究中固定短窗、事件-only、阶段截断、ARS离线教师对照先在原范围阶段选出必要竞争者；新 H 阶段复用冻结胜出规则，不为数量重跑一整套无关大模型。

### 共同起点分叉：分离两种收益

公共第一轮数据生成 M₁ 和 w₁，保持 M₀/w₀ 副本。第二轮进行四个采购分支：

| 选择器看哪版 Monitor | 旧 w₀ | 新 w₁ |
|---|---|---|
| M₀ | S00 | S01 |
| M₁ | S10 | S11 |

四分支共享候选池、预算与独立教师，得到各自标签后，**下游学生全部从同一个 M₁ 初始化**、同配方训练。S11−S10 是固定选择输入下的排序改进；S10−S00 是新 Monitor 帮助买反馈；差分交互 `(S11−S10)−(S01−S00)` 探索两者是否互补。每项都是增益比较，不把分支表现当已知结果。

强 AL 分支也从共同 M₁ 训练。至少需要 S10/S11/AL 的主比较；M₀行是机制诊断，资源不足时预先标为后续而非暗删不利结果。公共第一轮为控制实验提供共同起点，只能支持“有限二轮机制”结论；最终若要说持续自改进，应另用独立时间流验证各组各自 M/w 连续演化，不能拿这个人为共享起点自动推广。

另将相同选中标签交给同一配方/起点，验证可复现的数据效应；用同一标签更新不同快照回答任务能力问题。不能从实际不同数据的全闭环曲线直接拆出机制贡献。K/Z不适合被当作该参数训练分叉的完全等价组，须明确是系统信息/记忆对照。

### 主指标、门槛与否证

主指标是可观测新配置封存测试上**任务变化作用的宏 F1 增益**，包含阻碍、帮助/恢复、无关、成果撤销。内部多标签保留；如果外部要求单标签，优先级预注册且所有组一致。门槛包括：旧任务宏 F1 非劣、完成误报不过阈值、范围污染不过阈值、可观测判断覆盖不降低、未知案例不过度自信。unknown 在可观测案例上不能当正确逃避；在真不可辨前缀上由独立规则判断是否合适。

主比较先 R 对 AL，再 R 对冻结 w；多次比较的错误控制预注册。建议开发阶段讨论固定最小效应（例如绝对3个百分点）、旧任务非劣容忍（例如1个百分点）、覆盖下限与污染容忍；示例数字不是理论保证，也不是当前统计能力。最终效应与95%轨迹/场景簇置信区间均报告；未排除0或样本量不足，称证据不足，不能称证明递归有效。

机制次指标：每总审核分钟发现的去重范围错误；经独立确认的可用监督单元/分钟；误传播率/轨迹级至少一次污染率；正负/身份变化/撤销覆盖；发现自信错的概率；C/V召回、误放行/误拦截、恢复/失效延迟。帧数只有辅助意义，不用每帧独立 CI，不以新增伪帧数量代表改进速度。

否证条件：共同 M₁ 下 w₁ 不胜 w₀；不胜强 AL；收益仅存在于训练候选或容易核验正例；总体覆盖下降；更多审核/更新/重核成本消掉收益；旧任务退化；标签污染或未来泄漏；增益来自缓存而非更新。H 被否证时，删掉 R、保留达到门槛的 C 或直接监督，不增加复杂模块重新定义成功。

## 6. 资源与总核验成本

先将预算写成向量：`(人工分钟, 独立事件数/获取成本, GPU小时, 推理/API费用, 墙钟时延, 存储)`。不能无说明地把一分钟人工和一小时GPU加成一个数。主比较匹配人工总分钟与交互/教师权限，计算另设相同上限；若要换算货币，单价必须事先公开。

单分支第二轮拟议 60 人工分钟，包含看录像、找事件、核对身份/几何/接触、全范围审核、未知/失败审核、纠错、重新核验与记录；随机覆盖12分钟、排序48分钟。w的专门训练标签、开发调参和重复升级审核都计入该方案总账；无法塞进60分钟时减少可买监督，不将它当免费开销。获取事件本身若需额外真实操作分钟也算，不能只算标签点击。

示例资源账：第一轮公共反馈60分钟；六系统第二轮各60分钟为360分钟；S11可与R共享，S00/S01/S10额外三分支180分钟（F固定数据选择，不与S10混同）；合计单个种子批次600分钟。若3次独立采样/训练重复均重新购反馈，则为1,800分钟=30小时。若重用同一人工审查库，实际人时不能重复虚增，各分支仍按被揭示标签的收费预算结算，并报告真实唯一审核成本；纯训练种子重复不提供独立采购重复证据。

另单列共同合同/开发/完整升级与封存测试标注成本。例如240条短轨迹平均完整审核5分钟会需1,200分钟=20小时，**这里只是排预算的假设，需未来计时后替换**。不能把共同测试真值免费送入采购，不能把重复全审核成本双计；预算表应列“真实实际总成本”和“各组授权揭示成本”两列。按示例最大相加50小时只是粗上限，范围重核可能更贵，不是承诺。未计真实新轨迹采集/硬件费用，因为资源未确认。

只读 preflight 观察到 RTX4060 Laptop 约8GB显存；当前查询到的 Python 环境没有 torch 包元数据。此信息不证明任何拟议模型可运行，不安装依赖/下载权重。本轮允许的只是报告与来源快照。未来8GB是否足够取决于冻结表征与序列长度，先实测轻量特征/小头成本；不承诺复现 RoboMonitor 预训练或大VLM教师。初步 GPU 规划只能设上限，实际小时需授权后的 smoke test 才能估计。

## 7. 明确建议

先做“范围监督与预算”的可行性和固定选择主比较；通过后启用 R 的两轮共同起点检验。当前标题与主贡献保持证据范围；RSI作为启发和可检验扩展。成功后可称“范围反馈驱动的有限递归监督改进”，仍同时承认与主动学习、持续学习及已有自改进系统的重合。失败结果同样有价值：它告诉我们省反馈的真正瓶颈在核验来源/范围而不在选择器。
