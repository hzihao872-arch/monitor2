# RSI 是否值得加入当前 Monitor 研究？

日期：2026-10-13，Asia/Shanghai。文献研究与未来设计；未训练、评估模型、仿真或执行机器人，未下载模型或数据集。既有材料未改。本报告依据四份指定背景文件；具体设计见 [DESIGN_AND_MVP_zh.md](DESIGN_AND_MVP_zh.md)，逐条来源、原文定位及检索记录见 [EVIDENCE_AND_SEARCH_zh.md](EVIDENCE_AND_SEARCH_zh.md)。

## 1. 先回答你的问题

**值得加入的是“Monitor 改进后，帮助选择下一轮该核验什么”；当前最好称为“证据约束的主动持续监控”，把有限递归自改进作为待检验扩展。** 不建议把 RSI 或“爆炸式进步”直接变成论文的主要创新声明。

现在的流程已经有自改进的雏形：新的执行结果纠正旧错误，下一版 Monitor 因而可能更准确。不过，固定反馈、固定标注办法、固定更新办法只证明学习器在迭代。新增问题是：**上一轮学到的能力，能否让下一轮以同样总成本得到更少污染、更有用的监督？** 例如，从反复审核显而易见的成功片段，转向核验短暂入口关闭、遮挡后的身份、指定支撑解除这些容易污染标签的边界。

这会增强当前“证据适用范围”主线，前提是新增选择器专门服务于查询和范围错误，最终仍用独立新轨迹上的阻碍、恢复、无关变化与成果撤销判断检验。如果同时让系统改任务标准、教师判据、策略、世界模型和训练算法，就会稀释主线并使归因困难。首版暂不加入自主改代码、通用研究代理、自动任务分解、模型主体训练、真实探索行动或无外部证据的伪标签循环。

### 从 RSI 想法映射到我们能做的事

| RSI 中的想法 | Monitor 中的具体对应 | 当前决定 | 怎样才算新增价值 |
|---|---|---|---|
| 经验形成持久改进 | 独立执行证据产生范围受限标签，更新 Monitor 小头 | 保留现有方向；已有先例 | 未见轨迹提高且旧任务不退化 |
| 更强系统改善下一次改进 | 新快照更好地定位需核验的查询、实体、配置和边界 | 值得作为下一阶段加入 | 同一下一轮学习器、同预算，更新选择器比旧选择器更有效 |
| 改善经验获取 | 对固定候选记录池选择审核对象，少买重复易例 | 首版只选核验对象 | 包含全部选择与审核成本后仍胜强主动学习 |
| 改善监督者 | 学习“哪类候选范围容易错”，排序请求独立核验 | 可受限学习排序权重 | 少污染并提升任务角色判断；置信度本身不当真值 |
| 改善改进策略 | 以后从少量预先批准的更新配方中提候选 | 暂缓 | 必须另行固定数据做配方归因，计入搜索预算 |
| 递归修改自身改进代码 | Monitor 或代理任意改训练、评测、完成标准 | 现在不加入 | 当前没有必要、资产或可归因设计支持 |
| 智能爆炸 | 连续收益加速、能力增长反过来扩大研发能力 | 不作项目承诺 | 两轮收益或准确率上升远不足以证明 |

## 3. 学习、自我纠错与“递归”的区别

以下是本项目采用的操作性区分；领域术语并不完全统一。

| 做法 | 改变什么 | 为什么单凭它不能证明递归收益 |
|---|---|---|
| 累积监督/持续学习 | 更多独立标签训练参数，保留旧能力 | 更新程序和反馈选择可一直固定 |
| 迭代自训练 | 自己生成答案/伪标签后再训练 | 重复采样可能放大错误；没有独立真实性来源 |
| 自我纠错 | 当前答案、事件时间线或当前账本 | 本次答对不证明跨独立任务持久改进 |
| 主动学习 | 挑下一批标注对象 | 已经具有学习影响采样的反馈环；不应换名算首创 |
| 元学习 | 学习初始化、优化器或学习策略 | 可离线由人组织；未必让后继能力改善再后的过程 |
| 本项目最小递归扩展 | 小头改进，同时独立核验结果更新有限核验排序；后继系统再用它取得下一轮监督 | 只有新选择机制在共同起点上降低成本或提高下一轮收益，才支持“改进过程变好” |

采用严格说法，递归至少要展示：改进被保留；后继能力进入未来的改进环；未来改进效率的收益能独立测量。任意自改代码不是必要条件，模型参数更新也不是唯一形式。固定函数调用更新后的 Monitor 选反馈，可以叫学习器条件化的主动学习；若要声称改进机制也进化，则需保留并检验选择策略本身的改变。

[STOP](https://arxiv.org/pdf/2310.02304v3) 用生成代码改善代码改进器；[Darwin Gödel Machine](https://arxiv.org/html/2505.22954v1) 保留自修改代理并作实测选择；[Hyperagents](https://arxiv.org/html/2603.19461v1) 把任务代理与可修改的 meta 代理区分，并提供冻结 meta 机制等对照。它们是受限实证先例，不能给视觉 Monitor 的物理证据兜底。Hyperagents 也说明：任务能力与改进能力在代码外未必一致。精确原文定位见证据记录。

## 4. 与 Monitor 最近邻比，哪些已经有人做过？

本轮重新读原始正文，沿用旧报告的固定源码核查，而没有声称重新复现它们。

| 最近邻与原文 | 已有事实 | 我们借鉴 | 仍待验证的区别 |
|---|---|---|---|
| [Runtime Monitoring §III-D](https://arxiv.org/html/2310.17552v1) | 部署反馈按轮更新策略与监控组件 | 快照、累积反馈、Monitor 单测 | 查询限定物理证据与范围；闭环更新本身不新 |
| [Sirius-Fleet §3.1/3.2.2](https://arxiv.org/html/2410.22689v1) | 最新部署数据微调失败分类器，累计数据更新 OOD，介入标准随表现适应 | 强自适应请求基线 | 范围错误选择能否胜过风险/新颖性门控；不能说已有系统不改善请求 |
| [ConditionNET §III](https://arxiv.org/html/2502.01167v1) | 学 preconditions/effects，冻结特征训练条件模型，按行为树预期监控 | 当前物理状态与任务需求分开 | 同对象/路线/配置的独立范围监督与撤销；条件头本身不新 |
| [ARS §3.2–3.6](https://arxiv.org/html/2609.34484v1) | 自适应看录像，事件提议、区间核验、修改后重核、允许退步 | 强离线标签教师及证据版本 | 多轮范围监督效率；ARS 自适应取证已存在，两个 VLM 上下文不等于独立真值 |
| [WVN §3.3–3.5](https://arxiv.org/html/2404.07110v1) | 物理经历回配过去图像，冻结表征在线训练小模型 | 反馈关联与小头 | 尺寸/身份/配置、unknown、指定任务作用；小头和事后制标签不新 |
| [RoboMonitor §IV](https://arxiv.org/html/2609.30715v1) | 预测表征预训练、因果监控监督、可训练头/适配器 | 前缀读出与标签教师分离 | 可信反馈选择闭环；利用未来预训练不等于部署中读取真实未来 |
| [Robo-Dopamine 2.0 方法及 OOD 附录](https://arxiv.org/html/2608.15680v1) | 历史条件化有符号进度、阶段内后效传播 | 阶段截断强基线 | 相关配置变化与身份边界是否比阶段更值钱；负进度与受限传播不新 |
| [经验驱动地形学习 §III/IV](https://arxiv.org/html/2609.39755v1) | 足接触后效关联过去视觉，冻结特征、回放、新旧验证升级 | 独立证据与升级门 | Monitor 选核验的因果增量；后视物理小头更新不新 |
| [ThriftyDAgger §4](https://proceedings.mlr.press/v164/hoque22a/hoque22a.pdf) | 风险/新颖性、预算门控，人和机器人转移更新 Q 与策略 | 强主动反馈/成本基线 | 不把普通风险门控改名 RSI；指定条件真值不同于到目标概率 |

[GCR](https://arxiv.org/html/2410.19989v2) 的在线失败反馈修正奖励表征，以及 [HiRE](https://arxiv.org/html/2609.27068v1) 的支持集更新，说明参数与非参数的“评价者进化”都已有实质先例。失败末段或终局标签不能直接变成入口条件 false。

由此，**“Monitor 越用越准”“主动取反馈”“范围审核”“会判断退步”都不能单独作为新贡献。** 真正待验证的窄问题是：查询限定的范围错误信号，是否让后继系统在同总预算下取得比强主动学习更有价值、污染更少的监督，并转化为独立轨迹上的任务判断收益。本轮没有证明新颖性、没有穷尽所有相关论文。

## 5. 两个方案与两轮例子

**保守方案 C：** 策略/记录流、视觉主体、任务合同、核验标准和更新配方固定；只用独立反馈生成有范围标签，混合旧数据训练小头，新旧验证均通过才升级。称延迟监督的持续适应。先证明原主线值得做。

**最小递归方案 R：** 在 C 上只允许一个额外变化：核验对象排序的少量权重。第一轮独立范围审核产生“何处标签提议会错”的反馈；更新小头及排序；第二轮用后继快照和排序选择核验对象。可提议实体/边界，但不能自签标签或放宽独立核验。详细接口与共同起点分叉见设计文件。

贯穿合同：红方块通过开关控制的**指定入口**进入目标区，在**指定平台**释放，稳定至少规定时长，并保持到本轮结束。

| 轮次 | 执行与证据 | 学习/选择新增什么 |
|---|---|---|
| 第一轮入口 | 打开→关闭/变窄→重开→完整通过。几何独立核验关闭区间，交互见证仅证实当次物体/路线/配置 | 拒绝把最终通过广播为整个历史 true；审核这种越界提议，记录为范围错误 |
| 第一轮平台 | 释放→晃动→经核验稳定窗口；通过后入口关闭；仍须维持时指定平台支撑解除；另有遮挡 | 只教稳定窗口；入口后来关闭通常无关；支撑解除撤销 V，A 保留；遮挡为 unknown。纠正模型和核验排序 |
| 第二轮入口 | 新配置出现短暂变窄、身份/尺寸变化或无关背景运动 | 后继系统应优先核验相关边界及实体匹配；背景运动不自动截断。但是否真的选得更好必须实测 |
| 第二轮平台 | 大量普通稳定例与少量指定支撑替换/遮挡 | 把有限核验用于支撑身份与有效性，并留随机覆盖以发现自信错误；不以自身高置信度给免审 true |

比固定反馈→固定更新多的是**反馈采购与范围审核的选择改变**，不是获得更多真值、自动修复全部历史或让任务要求变简单。完整 C/A/V/R 状态表、每轮时间线、污染与泄漏位置见 [设计 §4](DESIGN_AND_MVP_zh.md#4-两轮完整例子与错误账本)。

## 6. 不运行的最小验证与建议

唯一新增主假设：**在同一第二轮候选池、同一学习器起点和总核验预算下，经过第一轮独立范围反馈更新的核验排序，比冻结排序及强主动学习带来更大的未见轨迹任务角色判断收益。** 核验污染、unknown 覆盖和旧任务保持是门槛；不用模型自评当结果。

第二轮从共同 M₁ 分叉：旧排序/新排序各选自己的反馈，随后都从同一个 M₁、同配方、同旧回放更新。另交叉用 M₀/M₁ 作为选择器输入，最后学生仍从 M₁ 出发，从而分离“用强模型挑例”和“排序机制学得更好”。必要对照包含固定选择固定更新、累计直接监督、随学生更新的强主动学习、同证据缓存、冻结学习器。预算按人工总分钟及获取/审核/重核成本算，计算另设相同上限。[完整未来规格](DESIGN_AND_MVP_zh.md)。

若新排序不胜强主动学习，或收益全来自第一轮模型更强、买了更多标签、降低覆盖、只选容易核验正例，就撤回递归过程贡献；若核验范围反而贵于直接标注，退回直接监督/事件-only；若固定缓存同样好，优先缓存。不得通过新增世界模型、代理或更大主体回避否证。

**推荐顺序：先完成证据范围主实验，再把 R 作为单独二阶段扩展。** 当前项目题目可继续围绕“有限预算下的局部证据范围与因果任务监控”；讨论中说明受 RSI 反馈机制启发。只有第二轮共同起点与预算比较通过，才使用“有限递归改进”结果表述。即使通过，也只说明特定合同/模型/预算下改善监督效率，不说明通用 RSI、真实机器人成功率或爆炸式进步。
