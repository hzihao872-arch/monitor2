## 1. 判断对象：发生过、仍成立、完成、未知

**用户已固定要求**是判断任务要求是否真正得到满足，以及过去进展是否仍有效。以下为**暂定操作定义**，采用四种标注视角；它们不对应四个系统模块。

| 对象 | 在时刻 `t` 要判断什么 | 支持肯定/否定的证据 | 易混淆点 |
|---|---|---|---|
| 历史事件 `H_e(≤t)` | 某个明确事件是否曾在 `t` 前发生，及发生时刻/先后；例如杯子曾被放进托盘。 | 带时间的观察或可核验记录。发生过的事实不会因后续撤销而变成“从未发生”。 | “曾放入”不等于“现在仍在”。若事件本身未观察到，标未知。 |
| 当前有效条件 `C_i(t)` | 某项要求在 `t` 是否仍成立；包括需保持的关系及已经取得但可失效的成果。 | 指向当前状态的观察，或在已定义的持续性和观察误差范围内足够可靠的连续证据。旧画面单独不能保证现时成立。 | 条件变假可撤销其**当前有效性**，不擦除历史事件；暂时远离目标也不自动使其他保持条件失效。 |
| 整体完成 `G(t)` | 用户明确要求的终态、必要过程约束和先后条件是否同时得到满足。 | 各必要条件有当前或全程证据，且不存在已知违反。某局部目标达成不够。 | “尚未完成”是一个时刻的任务状态，未必是不可恢复的任务失败。 |
| 不确定 `?` | 对具体事件、条件或整体状态，按**声明的在线输入权限**截至 `t` 是否缺乏足够证据。 | 遮挡、视角不足、传感器缺失、指令歧义或观测误差。须记录缺什么以及哪次后续观察可能解决。 | 参考真值为假与在线不可知可以并存；未知既不是失败，也不是成功。 |

标注时分开两层：`R_i(t)` 是参考状态，可依据完整轨迹或独立传感器取“真/假/仍无法核定”；`J_i(t)` 是截至 `t` 的允许输入能支持的“确认真/确认假/未知”。参考层看过未来，不使在线层提前知道未来。若已知某必要终态条件为假，则 `G(t)=尚未完成`；若所有必要条件均有充分支持则为“完成”；无已知反证但尚有必要条件未知，则为“完成状态未知”。明确违反全程保持条件时，参考层记录违反；任务是否仍可恢复另记，不擅自等同永久失败。

“当前有效进展”暂指已经取得、且其相关要求在当前仍成立的成果；无需把每一步映射为百分比。对一个观察窗口，还可另记“可见净推进”“与任务相容的调整”“可见无净推进”“证据不足”。后两种都不自动等于任务失败。正常慢速不能仅因用时长而判停滞；暂时回撤不能仅因几何距离增大而判退步。若任务没有截止时间、速度或单调接近要求，标注者不能补造这些用户约束。

### 事件与可判断时刻

对每个关键条件，分别记录：`t_e`（参考材料能定位的实际事件发生时刻）、`t_v`（按给定在线权限首次出现足以支持该状态的证据时刻）、`t_j`（被评估方法实际作出判断的时刻）。`t_v` 随输入权限和可视条件变化，可能晚于 `t_e`，也可能截至片段末仍不存在。参考真值可用完整视频核定 `t_e`；在线输入必须截断到 `t_j`，不能使用未来画面、未来反馈或标注。检测延迟从 `t_v` 起评估，并同时报告从 `t_e` 起的物理延迟以免混淆；`t_v` 前不能要求方法准确报告尚不可见的失效。预测只能记作预测，不能写成已发生事实。

**审查补充：终态证据与全程约束。**遮挡后重新看到杯子直立，只支持“当前直立”，不能排除遮挡中曾倾倒后恢复。对“运输期间始终直立”这类全程要求，必须分别标注当前条件与历史区间是否合规；缺少区间证据时，整体完成仍未知，即使参考完整轨迹显示实际合规。各对象有各自的 `t_v`，不能用当前条件的 `t_v` 代替整体完成的 `t_v`。若示例指令仅要求结束时直立、不要求全程保持，同一终态证据才可能支持整体完成；这是另一种任务语义，不能擅自替换原指令。

## 2. 候选输入与权限边界

**暂定操作定义**：阶段 3 不决定正式评测的输入集。下表的 P0 仅供概念案例说明“截至当前可见”之意；其余都保留为可比较的选项，不能因文件存在或模型能够处理便默认开放。

| 输入/信息 | 概念案例 P0 | 后续权限原则 |
|---|---|---|
| 用户原始指令及截至 `t` 的明确修订 | 给出，附生效时刻 | 保留原话和修订来源；标注者的任务解释另列，系统推断不得冒充用户要求。 |
| 带时间的视觉观察 | 案例写明每一时刻可见部分；只到 `t` | 历史长度、相机、帧率、分辨率和视角仍待选择；不可暗中补全遮挡。 |
| 动作命令、执行成功回执 | **未给** | 可选；命令意图不等于动作已成功，更不等于目标状态成立。 |
| 深度、位姿、力/接触等传感器 | **未给** | 可选；要记录校准、误差、掉线和产生时间。 |
| 场景图、任务元数据、对象身份、外部日志 | **未给** | 可选；只允许当时已存在且有明确来源的信息。 |
| 模型自身预测、解释或先前输出 | **未给** | 若以后使用，应标生成时刻和权限；它们不是独立真值。 |
| 完整轨迹、未来观察、独立标注、成功反馈 | **在线禁止** | 仅用于参考标注与事后审计；若有任务结束反馈，不能回填到更早判断。 |

以后比较方法时，必须为每个方法写清实际可见的指令版本、时间截断、模态、历史范围和外部反馈。改变这些权限本身就改变问题，不可把信息增益当成推理改进。

## 3. 候选错误：判定条件及反例

以下均为**暂定操作定义**。“可判”指在线允许的证据从 `t_v` 起足够区分；在此之前，肯定或否定输出首先计为证据不足却过度确信，不能按未来真值要求模型提前诊断。一个输出可落在多个分析轴，例如错误确认同时构成漏检；记录原始输出后再按轴计数，不重复包装成独立样本。

| 错误 | 可判定条件 | 不应算作该错误的反例/边界 |
|---|---|---|
| 错误确认 | 在可判时刻后，方法确认某当前条件有效、窗口有效推进或整体完成，而参考状态明确相反；典型是到达目标但杯子已离托盘仍报完成。 | 只报告“托盘已到标记区”这一真实**局部事件**，并未宣称杯子关系或整体完成；或截至当前杯子被遮挡，方法输出未知，此时不能凭未来真值计为错误确认。 |
| 错误撤销 | 证据足以表明先前成果当前仍有效，方法却判其失效，或把已核定的历史事件改写成“从未发生”；例如为绕障暂时后退、杯子仍在托盘且保持直立，却撤销杯子放置成果。 | 杯子确已离托盘，撤销“当前在托盘”的有效性是正确的，但历史放入事件仍保留；仅说目标尚未到达也不是撤销。 |
| 漏检失效 | 某先前有效的当前条件在 `t_e` 失效，至 `t_v` 已有足够反证，方法在约定判断机会仍未标出失效；同时记实际发现时刻或截至片段末未发现。 | `t_e<t<t_v` 的遮挡段，或方法在首次可判时刻明确指出失效；若方法只报未知而证据已经充分，属于未检出且要单独记录弃答，不能称其错误确认。 |
| 停滞误判 | 方法仅凭耗时、短时回撤或表观速度，断言“停滞/无效”，但可见窗口内有超出测量误差的净推进，或有被当前任务约束支持的必要调整，且保持条件未失效。反向错误也记录：可判定的目标相关状态在窗口内没有净改善，方法却肯定该状态取得净推进；不能把没有可见位移扩展为整个过程没有准备或信息价值。 | 在预先说明的窗口内，多次动作后物体回到同一位置且无其他要求得到满足，可标“该窗口无可见净推进”；不能由此断言机器人永远无法完成。单次小动作低于分辨率时应标未知。 |
| 证据不足却过度确信 | 某关键关系在在线权限下不可判，方法仍无条件肯定或否定该关系/整体完成；也包括把预测、动作命令或系统推断的要求写成已观察事实或用户明示要求。 | 明确标注“未知”、缺失证据及可检验方向；或仅对确已可见的局部事实作限定判断。此类错误可在参考真值仍未知时成立。 |

若一句输出同时称“托盘到了，所以全部完成”，应分别记录：到达事件判断正确、整体完成判断错误、杯子失效是否漏检。不能用单一“对/错”抹去局部正确性。若要求本身歧义，则先标“指令待澄清”，不按标注者偏好认定模型误判。

## 4. 概念案例及配对时间轴

**以下全部为概念示例，不是实测样本或现有模型错误。**为使差异可审查，除特别注明外，共用一条**示例用户明示指令 U**：“先把杯子直立放入托盘，再把托盘送到桌面标记区；运输期间和结束时杯子须留在托盘内并保持直立，结束时托盘稳定放在标记区。”无截止时间、速度、最短路线或进度百分比要求。C 对再加明示要求 U5：“不碰桌面障碍物。”A/B/D 不含 U5。P0 只含该指令及表中写明的截至当前视觉观察；位置 `x0<x1<x2<目标` 是概念化且差异大于示例观测误差的标记，不代表已选择位置传感器。

| 对/唯一关键变化 | 时刻与用户明示要求 | 截至该时刻 P0 可见信息 | 参考状态（可用完整概念轨迹）与缺失证据 | `t_e`；最早可判断 `t_v`；当时合理判断 |
|---|---|---|---|---|
| **A1 正常推进** / A2 仅多一次杯子滑落 | `t0`，U | 杯子放入托盘且直立；未送达。 | 两案均曾放入；当前杯子关系真；目标条件假。无关键缺口。 | 放入 `t0`，可判 `t0`；历史事件确认、未完成。 |
| A1 / A2 | `t1`，U | 托盘进入标记区；夹爪遮住杯子及托盘边缘。 | A1 杯子仍在；A2 杯子于 `t1` 滑出。**两案在线都缺当前杯子证据**。 | 到达 `t1` 可判；A2 滑落 `t1` 但失效 `t_v=t2`；两案只能确认局部到达，整体完成未知。 |
| A1 / A2 | `t2`，U | 侧视移开遮挡：A1 杯子在托盘内直立；A2 杯子在桌面上。托盘稳定在标记区。 | 完整概念轨迹设定 A1 全程合规，参考整体完成；但在线仍缺遮挡期间全程保持的证据。A2 放入历史仍真，当前杯子关系假，足以否定本次整体完成。 | A1 当前杯子条件最早 `t2` 可重新确认，整体完成仍未知、片段内无充分确认的 `t_v`；A2 当前失效最早 `t2` 可判。A2 若仍报完成是错误确认兼漏检；若说“从未放入”又犯历史事件错误。 |
| **B1 正常慢速** / B2 仅最终运动回到原位 | `t0`，U | 杯子直立在托盘；托盘位于 `x0`；目标更远。 | 均未到目标，保持条件真。无关键缺口。 | 初始 `t0` 可判；未完成，不能由未到达判停滞。 |
| B1 / B2 | `t1`，U | 同样向目标移动到 `x1`，速度慢；杯子仍直立。 | 均有可见局部移动，但未达到终态。没有截止时间。 | 移动 `t1` 可判；“慢”不能推出无效。 |
| B1 / B2 | `t2`，U | B1 继续到 `x2`；B2 返回 `x0`，杯子都仍稳定。 | B1 在窗口 `[t0,t2]` 有超出误差的净推进；B2 同窗回到起点、无**可见**净推进；B2 的长期可恢复性未知。 | 最后动作 `t2` 且窗口判断最早 `t2`；B1 报停滞为误判，B2 若声称本窗托盘位置取得净推进则错误；仅凭回到原位，不能排除探查、重抓或其他准备价值，也不能直接判整个过程无效。 |
| **C1 必要局部调整** / C2 仅多一次杯子倾倒 | `t0`，U+U5 | 桌面障碍挡住当前前进通道；杯子直立在托盘，目标在障碍之后。示例几何中须先回撤才能从无碰撞通道绕行。 | 两案当前保持条件真；未到目标。遮挡区域之外没有关键缺口。 | 阻挡 `t0` 可判；当前直线前进受约束。 |
| C1 / C2 | `t1`，U+U5 | 两案都把托盘向后挪以进入侧向通道；夹爪遮住杯子。 | C1 杯子仍直立；C2 杯子在回撤时倾倒。在线缺杯子现状；后退本身不是退步证据。 | 回撤 `t1` 可判；C2 倾倒 `t_e=t1`、`t_v=t2`；当前杯子条件未知，不能提前称 C2 失效。 |
| C1 / C2 | `t2`，U+U5 | 侧视露出杯子并显示无碰撞的侧向通道：C1 直立，C2 已倾倒。两案尚未到目标。 | C1 历史放入事实及当前直立关系可确认，回撤与避障相容；但遮挡期间是否全程保持仍缺在线证据。C2 放入历史仍真，当前直立关系假，且可确认发生了过程违反。此处“必要”只在设定的示例几何下成立。 | C1 调整与避障相容及当前直立、C2 当前失效均最早 `t2` 可充分判断。C1 若被判当前已不直立或从未放入，是错误撤销；不能把对全程保持的未知算成错误撤销。C2 继续报当前直立是漏检/错误确认。 |
| **D1 当前关系观察充分** / D2 仅侧视被遮住 | `t0`，U | 杯子放入托盘，直立可见。 | 两案该历史事件真。无关键缺口。 | `t_e=t_v=t0`，确认历史放入。 |
| D1 / D2 | `t1`，U | 托盘到达标记区且稳定；运输后的杯子被遮住。 | 完整概念轨迹设定两案全程合规，参考整体已完成；在线缺当前杯子关系及遮挡期间合规证据。 | 到达 `t1` 可判；整体截至 `t1` 不可判，输出未知。 |
| D1 / D2 | `t2`，U | D1 侧视清楚显示杯子仍在托盘内直立；D2 镜头仍遮挡。其余可见内容相同。 | 两案参考状态同为完成；D1 有当前杯子证据，D2 仍缺当前杯子证据；两案都缺遮挡期间是否全程合规的在线证据。 | D1 当前杯子关系最早 `t_v=t2`，D2 当前关系在片段内无 `t_v`；两案整体完成仍未知。D2 无条件报完成或失败都过度确信；D1 对当前杯子关系仍答未知才属于过度保守，对整体完成答未知合理。 |

配对的因果用意是逐对只改一项：A 改杯子滑落事件，B 改最后一步的净位移，C 改回撤时杯子直立关系，D 改观察遮挡。所有其他叙述条件保持一致；正式数据中仍需检查轨迹差异是否真的如此受控。A 和 C 还显示 `t_e<t_v`，D 显示参考完成与在线未知能够并存。

## 5. 初步标注规范与改善判断

以下是**暂定操作定义**，供真实轨迹到来后试标和修订。

1. 先逐字保存用户要求及其生效/修订时刻；另列标注者认为必要的解释，说明依据。没有用户明确提出的速度、持续性、接触禁令等，不得从系统预测或观察结果补写。歧义保留并单列。
2. 按轨迹时间先标可核定的事件、每项当前条件、整体状态及窗口行为；每项给出引用的帧/时间或独立传感器。参考真值可用完整轨迹，但标明由什么证据建立；完整材料仍不足则参考状态也为未知。
3. 对每一判断点单独裁定 P0 或正式权限下的 `t_v`。写清缺失的证据、遮挡、测量误差和下一次可能确认的观察；在线样本只截到 `t_j`，参考答案与未来帧不进入输入。动作命令、推测和用户要求分别存放，不相互冒充。
4. 对时间窗口只报告该窗口的可见净变化及条件变化。停滞窗口长度、空间/关系误差阈值、是否有截止时间，须在真实任务与标注试验中预先确定；没有依据时用“本窗无可证净推进/未知”，不用“永久失败”。必要调整需有当时可见约束支持；后来的成功可帮助参考复核，但不能提前给在线模型。
5. 保留原始方法输出及其限定词，分别评分历史、当前条件、整体完成、失效检出、窗口停滞与未知处理。重叠错误可在分析轴上同时标记，但每个轴的分母和重复计数规则须在正式协议中预先固定。分歧案例记录分歧原因，不为得到理想结果而删去。
6. 真实轨迹试标时优先用 A/C/D 型最小差异和反例核查一致性；若单改变关系却无法稳定改变参考判断，应修订要求解释或证据门槛，而不是强行赋予标签。

**怎样才算改善（待正式指标与样本固定后验证）**：在同一冻结模型、同一时刻、同一输入权限及可比较资源下，更少错误确认、错误撤销、可判后的漏检与停滞误判；同时报告正确判断覆盖、未知比例和首次检出时刻。A2/C2 应避免肯定失效条件，A1/C1 应保留仍有效成果，B1/B2 应区分净推进，D2 应允许当前关系未知，而 D1 应确认当前关系；两案对缺证据的全程合规/整体完成仍可合理输出未知。改善需在完整样本和配对反例上成立，概念案例本身不给出任何效果数值。

**怎样只是换错**：一律报失败可减少错误确认，却增加 A1/C1 的错误撤销；一律报未知可减少肯定错误，却在 A2/C2 已可判后漏检并在 D1 放弃有充分证据的当前关系判断；只看距离会把 C1 当退步；只看“到达标记区”会把 A2 当完成；从未来补帧得到的早期正确答案属于信息泄漏。错误率必须连同判断覆盖和观察权限解释，不能只挑一个下降的数字。

## 6. 阶段 3 留给真实轨迹的检验点与阶段 4 入口

**待解决问题**：真实指令中“保持”“完成”和容许修正的语义是否可稳定标注，尤其终态成立、全程合规及违反后恢复是否分别可判；视觉证据能否可靠区分在托盘内、直立、稳定和遮挡；`t_e`/`t_v` 的标注者一致性；“慢速”与“无净推进”的误差和窗口；真实数据是否存在 A/C 类关系破坏及 D 类长期不可见；动作与传感器是否应成为允许输入。当前没有实测证据回答这些问题，也不能推断错误频率或现有模型表现。
