# 稀疏物理锚点下的时间推断：借用算法与撞题审判

日期：2026-10-13。只检索、读正文与代码；没有实现或实验。三项主要一手来源；不修改前轮文件。遵循已读 nature-academic-search，技术判断只引用原论文及作者仓库。

## 结论

**可以借现成时间推断来解决“局部反馈应教哪些较早帧”，但不能把锚点传播或后验平滑本身当新方法。** Timestamp action segmentation 已经做过固定种子图传播、软边界后验和缺失片段处理。把人工 timestamp 替换为物理事件，再给 HMM/HSMM 加约束，大部分仍是现成算法换监督来源。

对当前主思路，最自然且小规模可尝试的借法是：**query-specific 变点模型产生概率回溯窗，物理事件提供独立局部标签，低观测可靠度直接拒传，再教只看前缀的视觉条件学生。** 不是保证新颖性，而是一个与数据规模匹配的算法插件。BOCPD 比 HSMM 少依赖条件时长和生命周期先验；若确有丰富的重复成立/失效序列，语义 HMM/HSMM 才更合适。

## 三个强来源

### 1. RWS：随机游走的核心已经完整覆盖

[Hirsch et al., WACV 2024，§3.1–3.3](https://openaccess.thecvf.com/content/WACV2024/papers/Hirsch_Random_Walks_for_Temporal_Action_Segmentation_With_Timestamp_Supervision_WACV_2024_paper.pdf)：逐帧特征构图，邻帧特征相似度给边权；已标 timestamp 是 seed，解 Laplacian 方程得到首达各类 seed 的概率。用法包括 pseudo-label、可训练损失和预测平滑；边界不确定性已有。标准设定每个 action instance 有一个 timestamp，标签仍是互斥动作类别，非条件物理状态。

[作者代码 RoyHirsch/RWS](https://github.com/RoyHirsch/RWS) 有 stand-alone 入口。本轮实际读 [random_walk.py](https://github.com/RoyHirsch/RWS/blob/main/stand_alone/random_walk.py)：邻域稀疏 affinity、`solve` 的稀疏分解、timestamp prior、dense pseudo-label 函数均存在。可借其数值求解器，不必训练 MS-TCN 才使用；原实验依赖预计算 I3D 特征与动作标签，不能当现成机器人条件数据。

**审判：**“视觉相似帧连边、物理事件作 seed、变化时切边、解传播概率”几乎就是换任务的 RWS。把边权加入部件运动信号是合理适配，是否方法贡献需另证明，不能天然拉开区别。

### 2. EM-TSS / EM-Gen：软边界与漏锚点也已有

[Rahaman et al., ECCV 2022，§4.2–4.4及附录](https://arxiv.org/pdf/2207.10137)：把边界当隐变量，E-step 算边界后验并积分成逐帧软类别权重，M-step 是加权 CE；弱时长先验，先从已标帧分类器初始化。EM-Gen 允许两锚点间存在漏标动作；SkipTag 进一步允许随机标帧。未标不确定性进入软权重，而非全硬标签。

其前提仍是动作分段类别与片段结构，不是独立且同时成立的多条件，也不等于物理条件可观测。正文有方法伪码，提到将提供代码/标注工具，但本轮未核实官方实现入口，不声称已读其代码。它已经否定“少反馈、有 unknown、用 EM 回头修正标签”本身的新颖性；只用模型 posterior 自举，还可能放大错边界，独立物理锚点不能验证锚点之间所有帧。

### 3. BOCPD：适合借回溯权重，不提供物理证明

[Adams & MacKay, 2007，§2.1–2.3、Algorithm 1](https://arxiv.org/pdf/0710.3742)：递归维护当前 run length 分布，用观测 predictive likelihood 与 hazard 在“延续”和“重置”之间分配概率；模型假定变点前后生成参数独立。它识别观测生成机制的改变，不自动识别哪个条件成立，也不内含物理锚点或 unknown。

若一个有效条件锚点发生在 τ，后验尾概率 `P(r_τ ≥ τ−t | f_1:τ)` 可成为前帧 t 与锚点同段的统计权重。该式是本轮借法推导，不是原论文提出的机器人证书算法。前后两真值锚点冲突时，需语义状态/anchor likelihood 或拒传处理；vanilla BOCPD 不会自动解冲突。本轮未核实原创作者代码，因此只把论文算法作为可实现入口，第三方 BOCPD 包不冒充官方。

## 最可行借法：概率回溯窗，而非手工全区间广播

以下是建议设计，没有运行验证。

1. **明确查询。** 每项条件绑定对象、载荷/形状、技能路径和当前任务。一次特定物体通过入口，只教同查询的通行条件；不得自动扩大到不同物体或任意路线。
2. **独立事件给局部标签。** 接触、载荷稳定、通过等事件需预先定义哪一时刻/短区间证明 c。成功通过可见证当次几何关系；不能默认通过后门仍开。失败不是负标签；负锚点只来自独立直接反见证。传感缺测不产生负标签。
3. **条件依赖的特征产生变点后验。** 使用相应对象/部件的关系特征与观测可靠度，而非全图变化。对候选前帧使用 BOCPD 同段后验做衰减权重；遮挡、身份丢失、未观测变化、查询改变时拒传。拒传逻辑需公平计入监督/规则成本。
4. **只做软监督。** 标签置信度来自事件可靠度、同段后验和可见性，不能由学生自信替代。锚点约束通过校准后的 likelihood 使用；只有真正可靠局部真值才可硬约束。不同可靠锚点给冲突标签时暂停该区间传播并审核，不静默取多数。
5. **未来前缀学生。** 用稀疏直接 CE 加带权前帧监督更新轻量条件头；晚到事件仅用于教师构造。部署学生只使用当时前缀，保持时间拆分，未来帧不得进入测试输入。机器人执行策略是否能冻结仍依赖实际资产，不能未经核实假定可用。

**unknown 的含义必须清楚：**它是因证据不足而拒绝给真/假，不是第三种物理状态。若用 posterior entropy 或阈值拒传，需有独立校准片段证明阈值可靠，不能称理论保证。

## HMM / HSMM 与 BOCPD 的取舍

| 借法 | 适配能力 | 额外监督与主要代价 | 判断 |
|---|---|---|---|
| 条件 HMM 平滑 | 明确真/假状态、重复成立及失效；可放局部锚点 likelihood | 要有成立与反见证覆盖、观测 likelihood/事件错误率校准；状态转移结构可能错 | 合理备选，但锚点固定后 forward–backward 本身是标准推断 |
| 条件 HSMM | 同上，显式驻留时长 | 还要 duration 先验；短暂失效可被长时长先验抹掉 | 暂不首推，小数据时多加先验未必值得 |
| BOCPD 回溯窗 | 只估计局部特征同段概率，少生命周期假设 | 要能观察条件相关变化，hazard/likelihood 校准；不提供真值语义 | 当前最自然的小插件，与局部事件标签分工清楚 |
| RWS 标签传播 | 现成可读代码、软传播且计算简单 | 无方向语义，外观相似可跨过隐性失效，单正锚点可涂满整段 | 必须是强对照；如果它同预算同样好，无需更复杂算法 |

## “成立 / 失效 / 用完”不能直接做一个三态链

这是任务定义问题而非算法优势：门已开、机器人已通过，`door_open` 仍真，但本步 `still_needed` 已假。普通可复用支撑或入口条件“被使用”也未必消耗。应至少区分物理真值 `c_t` 与当前需求 `n_t`；任务/子目标完成事件结清 `n_t`，直接反见证改变 `c_t`。真正耗尽的资源才需要 consumed 物理状态。unknown 则是对这两个变量缺乏证据。

如果把它们混成 false→ready→used-up，不仅违反回退/重试轨迹，也会把同一幅仍然开门的图训练成矛盾标签。任务完成后任务级“不再需要”不能教成视觉“门失效”。需要至少少量人定义条件和 obligation 对应关系，否则纯视频算法无法辨别这两种语义。

## 决定性反例与否证条件

- **视觉无变、条件暗变：**隐藏锁重新扣上、负载换重、支撑内部松动。BOCPD/RWS可给极高同段置信但标签错；拒绝承诺物理保证，必须提供可观测性限制。
- **无关视觉变化：**机器人胳膊/相机移动遮挡，物理条件不变。全图变点过分切短，丢掉标签效率；应比较query特征与通用特征，但不能把真实变化 oracle 偷给方法。
- **短暂撤销后恢复：**两真锚点间 false→true 未被锚点覆盖。默认单边界 timestamp 模型、强 HSMM时长或视觉相似传播均可能漏掉。需要真实中间检查样本测试；两端真不证明中间真。
- **只有正事件：**无可信负锚点则不能承诺学会失效，采样未执行帧当 false 是错误负标。
- **“用完”外观不变：**前述门/入口例，必须任务上下文而非仅视觉真值。

## 必须打的强基线与判据

所有方法用同一物理事件、同一视觉特征、同查询定义，并计入人工分钟、审核事件数与真实负锚点数：

- 事件帧-only 条件分类，以及同人工时间直接挑状态纠错；先证明稀疏传播有增益。
- 固定回溯窗、最近锚点、普通指数时间衰减；若简单窗同样好，BOCPD没有必要。
- 原始 RWS、EM-Gen式软伪标签；再对照锚点约束 HMM。不能只比 naive 全段广播。
- 人审完整有效区间/oracle 边界上界，及同预算稀疏人工边界版本；验证好处究竟来自算法还是额外边界信息。

评价前缀预测的误拦截、危险放行、撤销延迟、拒答覆盖率/校准，以及每个真实事件或人审分钟带来的收益；以完整 episode/场景划分验证，避免相邻帧泄漏。回溯标签数量或离线分段准确率本身不能证明 monitor 改善操作/导航。

**审判结果：**建议把 BOCPD 作为候选插件，同时保留 RWS 和直接状态纠错这两个有力否证对照。只换 seed 来源或加硬约束不足以宣布新的方法；可检验贡献是物理查询范围、观测缺失拒传、可撤销条件与任务需求的正确语义，以及它们在相同反馈预算下是否确实减少错误监督。现阶段没有实验结果支持任何优势。
