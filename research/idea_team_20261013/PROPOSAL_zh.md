# 主提案：让执行教会 Monitor，哪些准备现在仍然有效

2026-10-13，Asia/Shanghai。主 agent 综合原始讨论、三个子 agent 的往返质询和一手文献作出的研究判断。本轮只阅读、只读核查与设计，没有生成实验数据、训练、评测或运行仿真。

## 我推荐的 idea

**不要先给每一帧标“进度多少”。让机器人后来真正用到的环境条件，反过来教监督者：在此前哪些时段，这项准备确实已经有效；它后来何时被破坏，以及何时已经用完、不再需要维持。**

例如，把方块放进盒子之前，开口是否真的容得下它，比“盖子动了多少”更有意义。随后一次真实通过，可以提供关于这个方块和这处入口的局部证据。只在入口有关几何和物体规格经独立确认没有变化的范围内，用它监督早先的画面。之后盖再次封堵，而方块尚未放入，就撤销这项准备；方块已经放好后再关盖，则不能照样叫撤销。

这个想法的杠杆是**监督单位的改变**：从很难标、很难归因的全任务进度，改成“一个明确条件、一个实际使用或反证事件、一段经过审核的有效范围”。执行只对它真的证实的条件负责。未知片段可以不训练，不要求补成稠密标签。

这比上一轮“变化前后运行同一组续行，再标成功机会差值”少了一项很重的前置工程：不需要每个状态都复位、配对分支、重复估计成功率。它仍需要实际使用事件、少量人工和独立日志；没有凭空获得海量免费监督。

研究问题是：**在起始人工监督较少、后续只有稀疏执行证据时，能否学习并持续校准一个只看视频前缀的条件 Monitor，比直接纠正少量状态更可靠地识别准备的建立、保留与撤销？**

## 怎样接住师姐的意思

源聊天里，师姐明确说构造“一小部分数据”微调，认可数据筛选，并提出因人工数据不会太多，让监督者利用任务执行反馈持续进化。image editing、world model、未来想象和导航方法是她举出的可能路径，不是必须集齐的模块。见[原始讨论记录](source_discussion.md)与[意图校准](intent_calibration.md)。

我的理解是：她最有价值的启发是“执行会带来新的监督”，我们要把监督规则做成立。最终任务成功不能给全部前缀正标签；一次成功通过或一次经核验的释放稳定，却可以给一个很局部的事实提供证据。本提案把她的直觉改写成这种可成立的学习信号。

我将机器人策略保持冻结作为第一版的设计选择。这不是已确认的现有资源，也不声称师姐“原模型”一词已经明确指机器人策略。第一版训练 Monitor 的条件头或适配部分，不必同时训练控制器和完整世界模型。

## 问题和边界

第一版只选两类条件：指定刚体对指定入口的几何通行条件；指定载荷、目标区域和放置配置下的承载条件。先人工写少量任务族的条件语义，不能让模型自己凭常识定义全部真值。

必须区分：

- **环境提供局部机会**：该入口在这组几何约束下容得下这个物体。
- **当前技能能利用它**：具体夹爪、路径、控制器能否顺利完成。第一版没有由前者证明后者。
- **任务现在还需要它**：还没放入时入口有用，目标已经满足时它可能不再是义务。

第一版明确选择“指定刚体在给定入口相关碰撞几何下，存在至少一种通行配置”的存在性条件。实际通过的姿态与轨迹是存在性见证，不是学生要预测的未来路径。回推须独立确认相同刚体规格及所有影响该通行定义的相关几何；进入时推开盖、障碍变化、物体变形或身份不明时，不回推。如果以后预测指定路径或技能，则必须将其参数列入查询，并重新审查证据，不能用存在性标签代替。不能据一次通过估计成功概率。

释放稳定首先证明实际载荷、支撑来源与指定观察窗口；传播到放置前的“可承载”状态，还需相同承载结构、载荷和放置配置等条件。只有看起来像平面远远不够。

整体失败不给这些条件负标签；直接几何封堵、独立确认目标区域没有任何合格支撑等才提供相应反证。平台移动可能只使旧证据失效，先撤掉监督掩码，不自动标负；实际失稳只否定当次配置和观察窗口。合同缺数据也不等于物理条件为假。视野看不清时保留“不确定”。

“现在仍需条件”有单独监督合同，不能用“任务还没完成”替代。少量人工任务模板规定：入口义务在目标物尚未完整进入时存在，独立完整入盒事件之后可以解除；承载/稳定义务则持续到相应稳定窗口完成。物体已入盒但尚待释放时，任务没结束，入口却可能已用完。这些事件由训练侧状态/日志或人审核，学生自己的阶段判断不批准真值；部署时条件事实和阶段义务都从前缀预测，不确定时不汇总局部进退。

## 一个具体、可实现的机制

1. **记录预测**。Monitor 从最终目标和截至当时的视频，预测被查询条件的成立概率，并记录实体绑定、所需任务阶段。固定任务族的条件定义是公开的设置，不是测试时偷偷输入仿真真值。
2. **取得局部证据**。任务后来执行到通过、释放稳定或明确封堵等事件，由仿真状态/独立日志或人工审核生成证据。VLM可以提出待查事件，不能批准自己的真值。
3. **限定监督范围**。审核事件指向的对象、条件、负载或入口，找到最近一个可信相关变化边界。在身份、几何或支撑关系未知的地方截断。若只能确认事件帧，就只收事件帧，不强行扩展。
4. **训练前缀学生**。使用这些有限事实标签和监督掩码训练条件头。未来片段、终局状态和外部日志只用于训练侧审核，部署时学生只看合法前缀。每张证据按一个单位计权，避免长区间凭帧数压倒其他证据。
5. **保留任务语义**。在“尚需该条件”的阶段，条件建立/丢失对应局部准备建立/撤销；任务完成另用独立输出。未知不作负例。条件之间有利益冲突或存在其他路线时，不擅自汇总成一个全任务价值分。
6. **用新执行修正监督者**。后续只更新取得合格局部证据的部分，保留旧证据回放，按真实到达顺序评价。单次反馈可安排部署后更新，不必包装成严格 TTT。

第一版可以用已有视觉语言表征加小条件头，必要时用适配器；模型大小和LoRA不是idea本身。方法实质是从稀疏后效构造有适用范围的训练约束，并学习在前缀下识别这些条件。

## 标签究竟从哪里来

第一份监督分成两层。

**已有仿真用于语义初始化和检验规则。** 本轮只读核查发现 dev_v2 实际有9段mp4及对应逐帧sim_states，不只是metadata；接触、释放、位移和速度已有任务特定合同。可从这些记录写出条件标签，并由人核查视觉是否可辨。它们是开发资产，不能支撑新泛化结论，更不能因采出许多帧就声称已有大量独立样本。具体见[资产核查](assets_readonly_audit.md)。

**真正需要省监督的是新域中的稀疏证据。** 每段新素材审核一次实际使用或反证事件，再审核有限的适用范围。人不必逐帧给任意进度打分，但仍要确认事件、对象和范围；这些工作是否更便宜，是本提案必须面对的问题。可用已有成功视频或之后正常采集的执行，不要求为每条预测专门跑成对分支。

CALVIN官方文档公开图像、动作、scene_obs与语言区间，适合检查部件状态和撤销；但没有接触、力或承载真值，不能说它免费提供本题标签。(Im)PerfectPour有人工动作阶段与异常标注，适合作为真实素材与条件学习基线，阶段标签不是充分ready标签。RoboReward有大量视频/任务/终局分数，不能广播成局部条件真值。详细字段和可得性见[监督来源账本](SUPERVISION_zh.md)。

在完整仿真状态已经能逐帧自动标的域，**应直接用oracle标签**。这里不把事后回推伪装成比oracle省；回推的理由只在新域标签稀疏时成立。

## 和最近工作比，究竟多走哪一步

[ARS](https://arxiv.org/html/2609.34484v1#S3)已有后来证据核验早先事件、条件撤销、事件时间线，并提出audit traces可作为奖励训练监督。它的代码现在已有实现，不能再沿用“仓库为空”的旧信息。因此“后视教前视”“加训练”都不能独立当贡献。

[Aff-Grasp](https://arxiv.org/html/2408.10123v2#S3)已从实际接触定位功能部位，并映射到前接触图像训练affordance。可借的是“真实使用比语言自评更接近监督”的机制；不能声称首次从交互教早先视觉。

[ConditionNET](https://arxiv.org/html/2502.01167v1#S3)已学习动作前提/后效，用人工pre/core/post阶段和一致性训练。[Relational Preconditions](https://arxiv.org/html/2012.01693v1#S3)已用大量物理交互学习关系再少样本学习前提。条件预测本身也不是新问题。

本提案待验证的增量是：**针对准备可建立、保留、撤销且会用完的条件，以稀疏、独立局部证据限定哪些前缀可训练；在相同人审预算下改善新环境的条件监测。** 不要求仿真反事实教师为每个状态算完整任务价值，也不把所有成功前缀或VLM审计结果都当真值。

这个增量目前是明确的研究假说，未证明新颖性或收益。普通区间传播加分类器可能已经足够；如果没有比简单对照更强的效果，就不为复杂机制辩护。文献检索用于把研究问题做实，而不是为了换名字避开近邻。

## 最强的简单对照

| 对照 | 它能直接挑战什么 |
|---|---|
| 同人工分钟，直接选择少量状态给条件标签，做普通SFT | 区间审核是否真的省，而非换了标注形式 |
| 只训练证据事件帧；证据帧最近邻/支持集检索 | 是否需要传播和参数更新 |
| 已审核区间标签的普通SFT | 更复杂时序/有效期模块是否有独立收益 |
| 当前帧goal-condition分类器，再做两帧差分 | 是否只是在学习更可靠的状态识别 |
| ARS后视教师产生候选标签，经同预算审核后训练同一学生 | 独立局部证据是否优于通用VLM审计监督 |
| 完整仿真几何/接触oracle | 标签正确性与任务上界；不得刻意隐藏 |
| 未微调底座、同底座普通微调、同证据检索 | 收益究竟来自监督机制、数据还是参数更新 |

比较按独立事件、场景、任务和人审时间报告，不能按生成帧数夸大。所有派生区间/裁剪按原轨迹一起划分，八例等旧开发样本不作新的测试集。

## 最小实现路径与怎样影响机器人

以下是未来实施设计，本轮未执行。

先在已有记录上定义一个入口条件和一个承载条件，核查从证据到标签的语义是否成立；不扩成全任务评分器。之后以少量新片段试做“事件+范围”审核，并记录每条所用分钟数，与直接标状态比较。可设20–40个独立证据单元作为管线试做的预算例子，这不是模型效果充分的估计，更不是论文数据量保证。

训练一个只见前缀的条件学生，用此前未见的几何、对象和撤销顺序评价。重点是视觉运动相似但功能无效、准备建立后撤销、目标完成后条件不再需要、同一条件对不同目标有不同必要性。留出按场景/对象分，不以随机帧切分模拟泛化。

第一处机器人接口是**在已存在的固定短技能尝试前检查所需条件**，决定继续、暂不调用该技能或返回不确定。现有center/offset续行代码可作有限技术起点，不能当成熟技能库，更未证明自动开盖或补支撑是可调用技能。只有之后确认可靠准备动作接口，才扩展到补准备。固定原控制器比较独立成功、无效尝试与完成覆盖率，防止靠永远不执行获得好看指标；离线重放的“如果当时拦下”只算影子诊断，不算成功率提高。

若没有可运行的冻结技能，只能先完成监督与监测研究，闭环验证仍需后续工程。数据筛选是与师姐衔接的第二个接口，但条件丢失不是动作必定无用，恢复也可能有价值；不可直接把所有撤销片段删掉就声称策略会更好。完整RL与视频世界模型不作为第一版前置条件。

## 我保留它的理由与最关键未知

我保留这个idea，是因为它直接保留原问题中最有意思的“目标物未动，环境准备已经变了”，并给师姐的执行反馈想法找到了局部、可以审核的监督对象。已有记录能给第一张物理证据，不要求先训练强技能；少量适应时也允许只学被证实的条件。

最关键的未知有两个：新域是否有足够合格使用事件与反证；审核有效范围是否真的比直接标条件省。标签传播产生更多相关帧，并不会创造更多独立物理经验。如果同预算直接纠错/检索达到相同结果，应放弃传播机制；如果稀疏证据只能覆盖极少事件，应收缩承诺，不能说解决了任意任务进度标签问题。

工程上还未知真实机器人、策略和算力。这些影响后续验证的规模，不影响现在提出具体假说；本提案没有估算录用概率。

## 唯一备选：用成功反例校准“必须”

它的aha更尖锐：**成功不能证明中途每一步都好，却能反驳某个“绝对做不到”的理由。**

Monitor说“完成必须打开主盖”，一条初始目标未完成、全程主盖条件不成立、最终经侧入口完成的独立执行，可以否证主盖是任务普遍必要条件。它不能否证“当前主入口技能需要开盖”，也不自动授权任何技能继续。适用的目标、对象、允许动作和预算须相同；前提缺失和目标成功必须独立核验。

经典[成功轨迹学习action model](https://www.ijcai.org/Proceedings/2017/0615.pdf)和[反例修复symbolic-geometric abstraction](https://arxiv.org/html/2105.06537v1)已有相关机制。可以研究的是视觉Monitor怎样把路线/技能条件误当全任务必要条件，怎样用少量反例修正范围并减少无谓拦截；不是首次反证必要性。

我暂列它为备选的决定性理由是资源：已有唯一顶入口场景不产生替代路线反例，公开play是否包含合格案例尚未核实。若能获得少量有独立“全程未满足前提”证据的多路线执行，我愿把它升为优先方向。不是因为规划或导航已有思想就否定它。

## 可以自然讲给师姐听的一段话

师姐，我这轮最想做的是让Monitor从实际执行中学会“哪些准备现在还有效”。我觉得不用先给每一帧标进度，也不用每个状态都分两支重新执行：机器人后来真的通过一个入口，或者释放后把东西放稳，就能给对应条件提供一条局部证据。我们只在独立确认条件没变的范围内拿它纠正此前的判断，其他片段不乱贴标签；准备被撤掉和准备已经用完也要分开。这样机器人本身先不训练，少量人工负责审核证据和范围，让监督者逐渐适应。最需要比较的是，同样的人工时间，这种监督到底比直接纠正几个状态更划算不划算。它保留了我们原来关心的环境准备与撤销，但把真正难的地方放在可信反馈怎么变成监督，避免继续在旧prompt流程里找小补丁。
