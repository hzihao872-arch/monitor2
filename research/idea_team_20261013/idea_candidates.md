# 三角色质询后的候选取舍

构思角色草稿，2026-10-13。只读检查、文献与研究设计；没有实验、训练或新增评测。主提案以主 agent 的最终版本为准。

## 独立判断：主推有范围的后果监督，备选纠正过强的必要性

主推荐的日常直觉是：**机器人真的穿过一次入口、真的在一处放稳一次物体，就已经给监督者上了一堂物理课。我们让人审核这堂课能说明什么、在哪段时间有效，再让监督者以后在还没动手时认出同类条件。** 人不需要给每一帧打“进度分”，机器人也不需要为了打标签从每个状态再做一遍。

这不是大规模通用任务价值学习的廉价替代品。建议明确缩小问题：少量可核验局部后果，能否帮助只看目标与视频前缀的 Monitor，在新环境更可靠地识别尚需用到的环境条件？重点是第一份可信监督与部署后少反馈适应。未来帧只用于轨迹结束后的教师与更新，不能流入当次在线判断。

选择它作为主推荐，是因为已确认的接触、释放与稳定终局合同能给第一份监督提供独立锚点。第二候选的科学直觉更尖锐，但当前没有确认其最低需要的多路线反例数据；旧唯一入口场景明确不支持它。此排序是资源和监督真实性判断，不是已证明的效果或新颖性排序。

## 主推荐 B：从真实使用证据学习条件的适用范围

### 具体对象与机制

先保留极少数有清楚证据义务的条件。例如：同一物体尺度下，指定入口曾容纳过一条实际通行路径；同一载荷和指定落点下，某平台曾在独立释放后承载物体并满足约定稳定窗口。

这些是**局部、条件化的机会证据**。一次成功穿过不证明夹爪在任意姿态都可进入，一次放稳不证明任意落点或更重物体都能稳定。它们不等于下一技能成功概率，更不等于整项任务的进度价值。

一张监督证据至少记录：目标、查询对象与环境部件、证据事件和时刻、可支持的局部命题、限定载荷或路径上下文、可回溯区间、证据来源和审核者。后续独立事件确认命题，只能向前扩展到相关条件确实不变、查询上下文确实匹配的短区间。状态日志或人工审核负责区间；不能让待训练 Monitor 自己宣称“没有变化”后把该区间当真值。

学生读取目标、视频前缀与明确的条件查询，输出条件成立、条件不成立或信息不足，并区分“这个条件现在是否仍需满足”。基础视觉表征与机器人策略可以冻结，只更新小条件头；必要时再比较适配器。参数选择是实现，不是研究想法。

条件改变时，旧证据失去适用性，**这不自动证明条件变为不成立**。例如平台移动之后旧承载证据应停止传播；新平台仍可能有效。反过来，目标物已经放进盒内、原任务已完成，后来关盖不应解释为撤销放入进度。条件有效性、证据有效性、当前是否还需要此条件是三个不同问题。

### 第一份标签怎样来

现有 `fresh_prerequisite/contract.py` 中的终局合同要求至少半秒窗口，检查指定支撑接触、其他支撑、夹爪释放、运动与位移。`scenes.py` 从 SAPIEN 接触和状态取得这些值，部件本身部分由脚本驱动。它能证明这些受控场景的局部物理事实，不能证明有成熟冻结机器人策略。

第一份监督可选少数现有记录：先确认原始逐时状态与接触记录确实保存，合同独立审核一次成功释放稳定的锚点，再人工确认目标未完成前平台几何及查询对象没有改变的短区间。若只保存了终局汇总，就只能使用锚点，不能凭汇总补造早期区间。八个开发样本可以核查证书设计，不能成为新测试集，也不能被说成足够训练数据。

真实或公开执行记录中的证书仍需少量人工审核对象、事件与有效区间。CALVIN 的 `scene_obs` 有部件关节和物体位姿，可审核某些不变区间；它没有力/接触真值，不能直接生成真实承载证书。ConditionNET 的 544 条真实 teleoperation 记录含人工 pre/core/post/anomaly 分段，这不等于每个入口/载荷条件真值。应先核查是否有所需事件，不能把资源名称当成现成标签。

### 标签账本

| 信号 | 可支持什么 | 成本与限制 |
|---|---|---|
| 仿真接触、释放、稳定合同 | 指定载荷和落点的局部后果锚点 | 已有代码基础；先确认原始记录保存；受场景与物理模型限制 |
| 实际通过的独立事件证据 | 当次入口与物体/路径的匹配事实 | 需对象身份与真实通过核验；不证明全技能可行 |
| 外部状态日志 | 小范围环境条件不变 | 免费不是无条件；字段不含的摩擦、载荷、隐藏支撑不能假定 |
| 人工事件与区间审核 | 缺日志时少数短区间的可信范围 | 按分钟和独立证书计预算；可能比直接标几个状态更贵 |
| 明确封死入口、撤去唯一支撑或独立失稳见证 | 有明确适用范围的负例 | 不能把所有失败当负；失稳也需排除释放动作或其他原因 |
| 整项任务成功/失败 | 任务终局 | 不给所有前缀同一正负标签；没有局部证据时保持未知 |

一张证书扩展到多帧会增加训练视图，但这些帧高度相关，不是多份独立物理证据。不能用帧数掩盖独立场景与证书不足。也不能承诺“几十条就够”；少量审核是拟议预算，足够与否属于研究要回答的问题。

### 比最近工作的多一步应落在哪里

[ARS](https://arxiv.org/html/2609.34484v1) 已用后来证据回溯核验早先事件；[Aff-Grasp](https://arxiv.org/abs/2408.10123) 已从接触片段给更早的视觉帧产生 affordance 监督；[AffordTrajDP](https://arxiv.org/abs/2608.01603) 已用物体位姿传播 affordance；[Relational Preconditions](https://arxiv.org/abs/2012.01693) 已学物理关系与技能前提。因此“事后教事前”“稀疏事件传播”“学习前提”都不能单独当新贡献。

待验证的差异是：**后效到底允许反推哪项环境条件、传播到哪里必须停止、被建立的条件何时撤销或不再需要；在新环境部署中，同一反馈与人工预算能否改善未来仅见前缀的条件判断。** 它可能是一项好的标签效率和监督边界研究，也可能只是一套没有优于简单方案的标注工程；应让强对照决定。

### 最小路径和强简单对照

最小路径是一个条件头、两个清楚的证据类型、少量证书审核。先设计真实时间流：对新轨迹保留更新前的前缀判断，结果出现后才更新；下一轨迹检验适应。仿真能提供全状态标签时，直接用全几何/接触 oracle 是更简单的强监督教师，不应人为遮蔽它制造回溯需求。该教师同时可独立评价少量证书的正确率与覆盖。

必须比较同人工分钟直接挑状态纠错、只用证据事件帧的普通局部 SFT、证书帧最近邻或嵌入阈值、HiRE 式历史支持集、整成功轨迹广播、ARS 全轨迹教师与同样学生的蒸馏。只在独立证据数、人工时间和模型调用匹配时谈节省监督。

第一下游接口可在有动作对齐记录后筛选“在所需条件已成立且仍需它的阶段”动作片段；这是师姐喜欢的数据筛选，但不能用状态视频或 metadata 假装已经有动作。固定技能上的停止/继续接口需先确认技能与独立成功评价存在。若同预算直接纠错或证书检索同样好，放弃区间传播作为主方法。

## 备选 D：用成功反例纠正过强的“必须”

更尖锐的日常直觉是：**监督者说“必须把这个盖打开，否则任务做不成”，机器人却在盖始终关闭时从侧面放进去了。这一次成功就足以说明这个‘必须’说得太满，不需要把每一帧标成好，也不需要从同一状态做两种续行。**

学习对象是 Monitor 的否决理由适用范围：某条件属于当前路线、属于所有路线，还是只是有帮助。输入目标、前缀和明确的必要性声明；监督仅否证在该对象、目标和环境上下文中“任何成功执行都必先满足此条件”。它不证明当前拟执行动作安全，也不证明该条件永远无关。

最低证书是：起点目标尚未完成；同一任务和对象；被声称必须的条件在整段成功执行中确实未成立；终点由独立任务合同确认成功。absence 需要全区间状态日志或人工审核，遮挡与未观察不能当不成立。失败轨迹不能反过来证明条件必需。不能从成功轨迹随意生成“绿色杂物不必移动”等大量明显无关声明，必须保留与通道或支撑真正竞争的困难声明；真必要条件仍需要几何、任务规则或少量人工支持，避免模型学成永远不拦截。

经典 [Stern/Juba IJCAI 2017](https://www.ijcai.org/Proceedings/2017/0615.pdf) 已由成功轨迹删除过强 action preconditions；任务所有成功路径必须经过的条件也是 planning landmark 的经典概念。[Thomason/Kress-Gazit](https://arxiv.org/abs/2105.06537) 研究根据少量控制器观测修复符号与几何抽象。因此不能声称新发明了成功反证。潜在问题是视觉目标 Monitor 如何学习区分路线限制与全任务限制，从少量成功反馈减少不必要的拦截。

强对照是成功起始状态交集的 STRIPS 前提删除、成功证据检索、固定“可能有替代路线”提示、同预算直接必要性纠错。必须同时检查删除过强否决后是否出现错误放行；删除一个不成立的理由不等于当前动作已获许可。

暂列备选的决定因素是数据：当前唯一入口与唯一高台支撑专门排除了替代完成路径，不能直接给 D 的困难反例。CALVIN/其他 play 或 recovery 数据是否含真实多路线成功且有足够 absence 证据，本轮未确认；不能把这一难题藏在“挑几条视频”里。如果找到这样的现成数据，D 的直觉与监督逻辑足以使它升为主推荐。

## 已淘汰的首轮候选

自然失败—单条件修复—同技能重试的局部监督，与 [MAGMA-GEN](https://arxiv.org/abs/2609.20056) 的特权诊断、局部纠正和匹配重执行接近，且当前没有确认恢复技能和自然重试数据，因此不主推。

对同一真实轨迹按已达成原子目标重标，与 HER、[RoboReward](https://arxiv.org/abs/2601.00675) 的反事实 instruction/clipping 接近；“方块在盒内”谓词不会在开盖时改变，不能教我们关心的环境准备。若额外引入可通过、可承载谓词，仍需可信物理教师，不是重标免费得到的标签。

旧成对续行机会差值教师依赖匹配分支、冻结技能和多次尝试；本轮不把它作为默认主线。对局部证据已经够清楚的问题，先做大规模分支续行不是必要前提。
