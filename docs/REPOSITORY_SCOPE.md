## 保留在本地的内容

具体规则见根目录 `.gitignore`，主要包括：

| 内容 | 本地位置或匹配规则 | 说明 |
|---|---|---|
| Python 环境与运行时 | `.venv/`、`.venv-robometer/`、`.runtime/` | 不作为源代码上传 |
| 模型与缓存 | `.models/`、`.cache/`、检查点和权重文件 | 需要按各原型说明另行准备 |
| 视频和抽帧数据 | 视频文件、`frames/`、`sampled_frames/`、`model_input/` 中的图片 | 对应协议、输入清单及已有路径记录仍可保留 |
| 重复交付包 | ZIP、TAR、GZ 等压缩文件，以及 `packages/unpacked*/` | 原包、哈希和历史记录保留在本地；仓库不是这些交付包的完整镜像 |
| 数组与大体积数据格式 | NPY、NPZ、HDF5、Parquet、Arrow 等 | 需要原始数据才能完整复现相应历史流程 |
| 完整第三方仓库 | `.gitignore` 列出的 `research/sources/` 子目录 | 来源和可读取的提交信息见 `third_party_repositories.json` |
| 凭据和临时文件 | `.env*`、私钥文件、`tmp/`、各类缓存 | 示例环境文件可保留 |
| 独立的个人网盘盘点 | `reports/drive_cleanup_audit_20261007/` | 与 Monitor 研究无关，不纳入本仓库 |

所有排除均只影响 Git 上传范围，没有删除原工作区文件。部分历史 Markdown、HTML 或清单中的图片、视频、绝对路径可能指向这些本地材料，因此在 GitHub 上不会完整展示或直接运行。

`.gitattributes` 禁用自动换行转换，以保存纳入仓库文件的原始字节，便于保留已有哈希记录的意义。历史清单仍可能同时包含未上传的本地文件。

本次整理和上传不运行实验、不调用模型，也不改变历史研究结论。
