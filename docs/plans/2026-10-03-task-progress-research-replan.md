## 2. 将三种证据分开

1. **现象证据**：论文、官方案例及实验支持“某种问题存在”。可直接引用，不需要用户自行采集或独立标注。
2. **本项目诊断证据**：少量合法开发材料及可追溯标签，用来查输入可见性、强基线和误差原因。单人诊断须标暂定，不能说已有独立一致性或可靠效应。
3. **方法贡献证据**：满足协议的正反配对、独立复核、强基线开发与资源控制后，才能做 H1 先导。正式效应及外推还需阶段 8。

材料优先级：作者公开完整轨迹与既有标签 → 可追溯原始状态/任务文件 → 只对缺失字段做最小补标 → 若仍不可评则缩窄或停止该路线。用户提供数据是可选帮助，不是开始研究的条件。

不要求原始指令一定存成逐条聊天记录；官方任务定义与 episode 的可靠绑定也可以核验任务语义。需区分执行任务与事后生成的视频描述，记录修订存在与否的证据，不能因没有聊天日志就自动排除，也不能把任务识别 QA 当执行指令。

## 4. R-B：优先复用公开材料与标签（当前重点）

**第一轮有界筛查：**优先 Robometer 官方 OOD 数据及其发布/转换代码；再检查 RoboGraph 作者发布入口；仅当有具体新文件线索时回访 RoboFAC、DoReMi/CaM。RoboCasa/LIBERO 成功示范和既有 SafeManip/BotFails 排除结论继续保留，不反复下载同类不合格例。

**动作：**

1. 固定官方仓库 revision，读取数据卡、任务表、逐集索引、标签定义及转换程序；记录哈希、来源链接和许可层级。
2. 核查任务文本是执行输入还是事后描述；原始失败与合成逆序/冻结/打乱失败分开；源视频是否被抽帧、重定时或剪辑；区分原始秒与播放秒。
3. 先按任务和来源查是否同时有成功/失败或部分成功标签。此种配对仅是搜索入口，不能自动升级为“先达成后失效/仍有效”。
4. 只查看有明确任务映射的少量候选，保存所有纳排理由。文献案例、元数据候选、实物轨迹和独立核定事件分四级登记。检查过的具体记录不得进入保留测试。
5. 核查现有标签是否满足我们的某一个实际判断目标，而非强求每条轨迹都提供 H/C/P/G 全套。仿真状态可提供物理参考，但不能自动代替在线可见性与指令语义审查。
6. 先用小元数据/单样例，第一轮新增来源文件预算 25 MiB；单个视频仅在元数据通过后另行登记目的和大小。不上来下载整库或安装完整模拟环境。超预算不静默扩展，应记录有依据的下一批最小范围。

**产出：**`research/07_public_material_reuse_audit.md`、`research/sources/replan_r1/` 来源快照与哈希、追加 `experiments/data_manifest.json`。没有模型运行不伪造 run ledger 条目。

**验收与停止：**

- 可用：得到至少一组任务语义一致、时间/来源可追溯的候选，明确可以复用和仍缺的标签；再进入 R-C。
- 只有论文证据：保留研究动机结论，列具体材料缺口；不将其包装为 H1 集。
- 一轮筛查后无有效线索：停止同义检索，给“下一件具体源文件/公开映射”或“需要的最小外部材料”二选一的明确入口，不能让用户从头标整个库。

## 5. R-C：先检查强基线与剩余错误

**前提：**有合法材料、任务语义、可靠时间解释和可追溯的参考证据；未达成不运行模型凑结果。

**动作：**

1. 先审查最近工作的权限、已有解决范围和错误；优先采用原有标签可回答的对象。
2. 如需本地探索性诊断，使用现有冻结 Qwen 与固定 P0 包，先运行 S0 和具备合理滚动摘要的 S1；单人暂定标签仅用于逐例分析，不计算 H1 效应、BCY、显著性或正式样本量，不运行 C1 争胜。
3. 运行前声明样例选择、提示版本、预算和允许迭代次数；保留所有尝试及失败，追加 run ledger。模型输出不能反过来决定标签或筛样本。
4. 对每条错误区分：本来不可见、标签/指令歧义、感知失败、普通提示不足、历史信息使用或状态更新问题。只把经证据排除其他原因的错误作为机制依据。

**产出：**在 `research/08_pilot_report.md` 另立“探索性基线诊断”小节，或明确写未执行；逐例证据表与实际运行日志。

**验收：**存在可复核的剩余错误，且强 S1 的合理开发未消除；如果 S1 已够用或感知瓶颈主导，暂停 C1，不凭文献未报告声称前人无法解决。

## 6. R-D：由错误决定假说，并收尾最小评测材料

**动作：**

1. 对 R-C 的剩余错误选择一个可检验机制，可能保留 H1/C1，也可能删除或修改；不默认推进三候选。
2. 给出与最近工作实质差异、最便宜的反证实验、等资源强对照和删机制条件。避免仅由细粒度指标命名不同推导创新。
3. 做标签复用映射：原标签 → 本项目目标 → 证据/权限 → 缺失字段。只补原标签没有且影响判读的部分。
4. 若需要人工复核，先做可直接交付的少量事件包：任务与对象版本、完整参考、按时间解锁的 P0 前缀、事件锚点/区间、遮挡/修复/歧义、来源哈希。盲审包不含模型判断和首名标注者答案，参考层与在线层分开。
5. 已发表的独立人工标注只有在方法、覆盖对象和可追溯性匹配时才可提出复用，不自动等同于完成 S6-draft-4 的独立盲审。无人独立复核时停在交接包；不让同一执行者或另一遍自标冒充第二人。

**产出：**更新 06；必要时创建 `research/07_independent_review_handoff.md` 和机读标签草案。未取得实际可标轨迹时不创建空壳“已完成交接包”。

**验收：**最小正反开发材料、许可、时间语义、参考与在线可判性、独立复核和未泄漏划分到位。若需改变独立复核标准、P0、预算或指标，先显式升版并说明影响；本 R1 不修改 S6-draft-4 评分规则。
