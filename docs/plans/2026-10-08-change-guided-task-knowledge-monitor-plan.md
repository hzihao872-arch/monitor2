# 由已发生变化引导任务知识生成与视觉验证：实施计划

日期：2026-10-08（北京时间）  
状态：**方案与实验预注册草案；未实现新方法，未运行新模型实验，未证明新颖性或有效性。**  
范围：桌面单臂抓取、搬运、放入和稳定放置。本文承接[最新冻结方向](../../research/prerequisite_monitor/RESEARCH_IDEA_FREEZE_20261008_zh.md)；早期文档的训练优先建议不是当前主线。[架构方向备忘](2026-10-08-change-guided-architecture-design.md)进一步列出能力细节、替代方案及何时才应增加模块，仍不预选最终架构。

## 0. 研究合同与要回答的命题

给定最终目标文字 $g$、当前时刻及之前的单视角 RGB 帧 $o_{0:t}$、固定的通用机器人能力约定，monitor 评价**已经发生**的行为：可见环境变化对 $g$ 是帮助、无关、损害，还是撤销了先前进展；目标已完成和证据不足另报。每个时刻的输出只能由 $o_{0:t}$ 推得。即使整段离线视频已在磁盘，处理 $t$ 时也不得把 $t$ 后帧、终局标签或未来生成的文字摘要带入。场景真值、正确变化描述、事件时间、正确裁剪、仿真状态、续行结果与参考示范只在制样/评测侧使用。

主要待检验命题是：**先由已观察到的变化提出局部、目标相关且可反驳的条件，再独立回看视觉证据核验，比仅凭目标预先生成条件更容易正确评价环境准备与撤销。** 这是一条机制假说，不是已证实的论文创新。若同预算直接判断、目标先行生成或现有方法同样好，则采用更简单的方案，并相应收窄主张。第一轮不新增任务专用训练，也不把人工正确关系作为推理输入。

首轮目标物可保持不动，以隔离环境结构变化；后续必须包含目标物抓放和已完成控制。`目标完成`、`当前可直接执行目标物操作`、`若继续准备则仍有实现路径`、`剩余准备工作减少`是四个不同问题，不能压成一个二元进度位。monitor 不被要求先规划完整策略；若视觉信息不足以判定替代路线或稳定接触，就报告不确定。

## 2. 最小方法接口：先让变化被看见，再谈任务作用

以一个当前前缀为输入，**先从视频本身找实际发生的环境变化**：比较起点、动作前后及当前末点的稳定画面，剔除机械臂经过和短暂遮挡，不由目标文字反向枚举可能的前置物。当前固定机位、变化集中的场景可从始末帧差起步；对无显著变化可输出空变化集。找到变化后，才用目标物/目的地画面作关系判断的上下文；A 的核验须覆盖盒口、盖与落放空间，B 须覆盖板、轨道与目标足迹。检测到运动不等于判有用。时间点由视频前缀自动候选、再回看确定，不能从真值事件时刻读取。无法确认的物体绑定或端点状态保持未知。裁剪只可从前缀内生成，保存原图坐标与时间索引以备核查。

为每个**实际观察到**的候选变化保留最少三类内容：`可见事实`（对象/区域、前后状态、证据帧）、`局部任务命题`（这项变化可能建立、维持或破坏什么目标条件；只是待检验假设）、`验证结果`（重新取的视觉证据是否支持命题、是否存在可见替代或残余阻碍、哪里不足）。其中**LLM 任务关系推理器**明确位于变化提取之后、视觉核验之前：输入 `目标 + 自动提取的变化事实 + 变化区域的可见上下文 + 通用机器人能力`，只针对**已发生的这项变化**提出它与目标物/目的地的候选关系、预期证据和可能的反例，不从目标生成完整任务分解；核验后可再由同一 LLM 依据已核实事实判断任务作用。不提供 A/B 的正确关系、固定词表答案、准备清单或场景编号。命题至多保留少数候选，允许“变化与目标无关”。独立验证上下文重新取得相关原帧或裁剪，不直接继承生成阶段的视觉断言为事实；若修改命题，原先验证作废并重查。可借鉴 ARS 的证据约束，但当前前缀边界始终生效。

读出先使用可审计的**状态与事件**，暂不假装有可信的连续奖励值：`goal_done`、`direct_ready`、`partial_preparation`、`impact ∈ {beneficial, irrelevant, harmful, unknown}`、`reversal` 与对应证据。`goal_done=true` 单独优先读出；`direct_ready=true` 只表示在固定通用能力约定下，当前已具备直接目标物操作的可见条件，不等于目标完成；`partial_preparation=true` 可与 `direct_ready=false` 并存。R 中段帮助、末段撤销时，净端点影响可为 `irrelevant`，同时必须显式记录“曾帮助并被撤销”，不能只报无事发生。对当前无法排除其他路线、遮挡、物理稳定性不确定的情形输出 `unknown` 并计入覆盖率分母。数值进度或奖励映射只在后续校准后冻结；不得凭一种局部关系强行推断整任务的完成百分比。

旧提示 T1/P1/TP1 同时要求许多抽象字段，却没有可靠地把变化绑定到目标区域。新版的可区分点不是“再问一遍前置关系”，而是：①先从实际前后画面提议变化，目标区域是审查锚点；②只围绕该变化生成局部命题；③核验阶段重取视觉证据并可否决命题；④保存第一失败点（漏变化、状态错、命题错、验证错、读出错）。若这四步仍漏 B 板或 G 完成，直接如实判失败。

## 3. 标签合同与最小受控对照

**评测真值与模型输入分仓。** 制样侧利用仿真状态、接触和续行试验，配合至少两名不看模型输出的审读者判断画面是否足以支持标签；对分歧保留 `ambiguous`。固定通用技能集合与路线挑战清单，在状态对比中保持蓝块位置、相机、背景和未干预结构相同。`beneficial/harmful` 的强标签要求可见目标相关条件确实建立/破坏，且在已审定路线集合下改变直接执行就绪或可靠降低/增加剩余必要准备；不能仅凭动作发生或时间变晚。对替代路线无法排除的样本不写“严格必要”。部分开盖、部分推板单列 `partial_preparation`：即使它可能减少下一步工作，也不等于 `direct_ready`；剩余工作没有经续行验证时，其帮助程度保留待定。完成标签由场景成功谓词和可见画面共同审查；若物理真值可判但单视角不可判，归入视觉歧义分层。

先制一个新**双盒左右交叉**开发小表：左/右盒外观对称且目标物初态相同，只打开左或右盒；把每段同一视频分别配“放入左盒”和“放入右盒”的终态目标。由此得到四个 `视频×目标` 单元，同时满足“同一变化换目标”和“同一目标换变化”。每一单元另设相同初态的无动作锚点；先查 4 个核心单元的目标相关性和目标区域绑定，随后加入每侧的不充分打开、开放→关闭 H、关闭→开→关 R 和真实放入 G。控制机器人遮挡、动作长度、显著运动与左右位置；交换目标文字时不改变任何像素。蓝块在准备首组保持不动。微型表只判方向与机制是否可识别，**不估计总体效果**，也不作为未来未见集。

随后用已暴露 A/B 各九条件做开发回归，保持既有 P0 六对 `E>S, E>I_b, E>N_b, H<I_o, H<N_o, G>N_o`，并追加 R 的中段获得、末段回收、S 的部分准备记录、无动作漂移和 G 的绝对完成状态。保留 P0 指标原样供历史对照；新方法另外报告事件与状态指标，不用新的读出重算或覆盖 P0。

## 4. 能识别“变化条件化”贡献的比较

同一 VLM 版本、相同原始目标、同一可用前缀帧/裁剪权限、同一通用能力定义、统一输出协议、预先封存的提示和解析器，设三条核心臂：

| 臂 | 第一阶段 | 第二阶段与目的 |
| --- | --- | --- |
| D：直接判断 | 目标与视频直接给出事实、影响和证据 | 一调和同预算两调自检 D2 都保留，测“简单直接法是否足够”。 |
| K：目标先行 | 目标与当前**可见初态**先生成可能条件，不给正确事件；初态信息也公平供其他臂使用 | 同样回看前缀并验证，检验目标驱动知识是否已经足够。不能故意不给 K 初态画面。 |
| C：变化先行（主候选） | 从前缀提取变化，随后用 `目标 + 变化` 生成局部条件 | 与 K 使用同一验证器、同样帧和调用预算，隔离变化进入知识生成的增量。 |

主机制比较 K 对 C 要匹配**调用次数、最大视觉帧/像素、输出 token 上限和验证机会**；记录实际 token/时延而非只写“同预算”。D2 也有相同回看权利。若 C 使用额外变化发现调用，就给 K/D 同成本的视觉事实提取或另列三调成本层，不能把三调 C 与一调 D 的收益归因于信息流。冻结之后只可作预登记消融：去掉变化输入、只给变化而不生成命题、去掉独立视觉核验、打乱目标/变化配对，以及 oracle 正确变化描述或正确裁剪的**额外输入诊断上限**。Oracle 绝不进入主成绩。旧 T1/P1/TP1、P6 与 TOPReward/Robometer 作为真实历史或原生竞争者单列；ARS 若有可运行官方实现或忠实前缀适配，可列相应身份及完整成本。未运行模型不填零分。

在任何模型调用前固定小表的病例、目标文字、证据审读规则、提示 SHA、解码设置、帧预算、输出 schema、失败处理和分析脚本。先用模拟/小样本验证输入与解析，不根据揭盲方向修提示；若确需改版本，保留全部旧原答并重新做完整同条件比较。

## 5. 指标、统计与失败定位

主报告按**独立场景单元**成对列出 C−K 与 C−D2，而非只报 18 段总准确率。至少有：① E 的三对、H 的两对、G 阳性和 R 撤销成对胜/平/负/不可判；② 变化检出与对象/目标区域绑定准确率、初/中/末状态及引用帧可支持率；③ 局部命题的目标相关性、验证后仍错误接受的比例；④ `goal_done`、`direct_ready`、`partial_preparation` 分开测的精确率/召回率与混淆矩阵；⑤ impact 宏平均 F1 和分层覆盖率，其中解析失败、方向冲突、`unknown` 均留在总分母；⑥ R 中段正信号、末段撤销率与 N 静止漂移；⑦ 同视频换目标的错误信用率。不能以回答 `unknown` 提高已答精度却不报覆盖率。

原生连续评分另报其自身量纲的窗口差与预注册排序，不跨模型比较绝对值。若 C 未来产生连续进度，预先要求端点校准、单调假进度抑制、撤销和完成控制；不得用时间 Spearman 相关代替任务相关性。所有成对差以场景/seed 为聚类单位给 bootstrap 95% 区间，同时列逐案例原答和非参数胜负；四单元微型表只展示原始计数，不做显著性宣称。审读者分歧、视觉歧义、仿真续行路线分歧单独列，不把有争议样本悄悄删掉。

第一错误点诊断按 `未发现变化→实体/区域或端点错→局部命题无关/虚构→视觉核验错误→影响读出错误` 逐层归因。人工正确变化、正确裁剪、正确状态、正确局部命题可分别作为分层 oracle 输入，只在开发诊断运行，以估计每一层可挽回上界。若 B 承托板依然被漏掉，优先改目标区域覆盖与帧选择；若事实对、任务作用错，再研究续行/替代路线；若事实与作用都对但方向错，才改读出。任何阶段必须保护 G，尤其 A G 的绝对完成判断；不能只用相对 N 的胜出代替完成阳性。

## 6. 泛化与未见测试

开发资产包括现有 A/B、旧提示实验、`new_test_candidates` 和新双盒小表，全部显式标为已暴露。方法、阈值、帧策略与成本上限稳定后，另制作 G2，**制样和模型输入脱钩且在看新输出前冻结**：

1. 同机制迁移：入口、承托的全新几何、物体纹理、相机视角、光照、轨迹速度、遮挡程度与机器人起位；颜色替换仅算外观变化。
2. 新机制迁移：至少一个不同于入口/承托的目标相关结构，如解除夹具约束或移除放置区域障碍；再有一个新机制才适合讨论跨机制趋势。对每机制提供有效、无关、不充分、阻碍、撤销和完成，保留无动作漂移。
3. 组合与困难例：两个结构都变化但只有一个相关，先好后坏/先坏后好，以及目标物也移动的轨迹。只有单视角可审定者进主表，遮挡争议另分层。

每个 G2 场景先由评分侧做场景卡、成功谓词、固定多路线/多种子续行、物理反例搜索和独立可视审读；不能把“指定路线失败”写成普遍不可达。按场景族分层抽样，目标最低每族约 12 个独立初态作为可行性审计；正式比较的样本量和可检测效应由开发方差、配对相关性与可负担调用预算**事前计算并写入 G2 冻结**。若预算只够小样本，就按探索性外推报告，不作通用性断言。任何未见结果失败后保留原表，修订方法须新版本和新的未见批次，不在 G2 上就地调提示。

## 7. 计算与证据预算

本轮**不发起模型或策略训练运行**。先在本地完成规格、审读、数据与解析器的零/小调用检查；新远端租赁、权重下载和昂贵评估须另有明确资源决定。既有 5090 记录给出粗量级：v0.2 的 162 调耗模型时间 1,588 秒、输入 388,482 token、输出 54,785 token、峰值显存约 17.09 GiB，折合每调约 9.8 秒与 2.4k/338 token。新方法的多轮取证可能更贵，此数只作预算初值，不是时长承诺。以 18 个 A/B 开发例×三臂×两调为例，上限 108 调；按旧速约 18 分钟纯模型时间，计划阶段用 1.5–2 倍时间、额外封存/下载缓冲与峰值显存重新估算。双盒四核心单元×三臂×两调另约 24 调。实际先 pilot 2–4 例测视觉 token、延迟、显存、解析率，再决定是否运行整表；超出封存预算即停止扩样并保存失败。

下面仅按旧 5090 平均 **9.8 秒/调、约 2.4k 输入和 338 输出 token/调**作量级估计；两调 C/K 的真实消耗须以 pilot 替换。G2 数量是预算情景，尚非冻结样本量，且只算四个核心交叉单元，H/R/G 等控制会增加调用。

| 情景 | 计算式与纯模型时间 | 资源决定 |
| --- | --- | --- |
| 双盒四核心单元 | 4 单元×3 臂×2 调＝24 调，约 4 分钟；约 58k/8k 输入/输出 token | 先用它检验机制是否可识别。 |
| A/B 全九条件开发回归 | 18 单元×3 臂×2 调＝108 调，约 18 分钟；约 259k/37k token | 另加 1.5–2 倍运行余量及封存缓冲；不在本机 8 GiB 显存上承诺完成。 |
| G2 可行性情景 | 4 族×12 独立初态×4 核心单元×3 臂×2 调＝1,152 调，约 3.1 小时纯模型时间；加 H/R/G 和两倍余量后明显更高 | 先按 pilot 重算成本与样本量；超预算缩小论断范围，不能删控制只留 E。 |
| 下游轨迹标注情景 | 256 条轨迹×每条 4–8 个候选窗口×2 调＝2,048–4,096 调，按旧速约 5.6–11.2 小时纯模型时间 | 只在评价层达标且有可交互机构后核定；另列 TOPReward/Robometer 标注、策略训练 GPU 小时和费用，训练量依实际模型规模/吞吐实测，不虚报。 |

每次运行记录数据/视频 SHA、目标文字及 manifest、模型/权重/代码身份、提示与解析版本、帧和裁剪引用、生成设置、调用/视觉 token、时延、显存、原答、解析失败和人工审读；按病例和阶段编号封存，不覆盖 P0/P4/v0.2。远端运行必须预留下载和本地逐文件验封时间。G2 与策略学习预算须另表单独核算；不能把本地 8 GiB 设备视为旧 5090 的可替代配置。

## 8. 下游策略学习：只有评价可信后才启动

评价层达到门槛（C 对 K、同预算 D2 及强原生对照有可重复的关键 E/H/R 增益，G 不受损，证据链和覆盖率合格，并在 G2 至少保持方向）后，才构建真正可交互的桌面操作基准。现有 A/B 的运动学预设滑块适合评价视觉前置条件，不能单独支撑“策略学会主动开盖/推板”的结论；下游需有动力学或可靠可控机构、机器人真实动作与独立成功判据。先固定行为策略收集的混合质量离线轨迹，同轨迹同目标供所有监测器打分，测试轨迹与 monitor 开发数据按场景/资产/seed 隔离。

先做成本较低且因果清晰的动作块筛选/加权 BC：依据**前缀因果**的局部正进展保留块，对 `unknown` 不伪造正奖励；比较全数据 BC、成功轨迹 BC、随机且保留率匹配的 BC、TOPReward/Robometer、D2、K、C，若 ARS 前缀适配可用也加入。固定策略初始化、优化更新数、动作块长度、数据池、训练种子与测试回合；同时报告各法保留比例、按阶段/机制保留量、全任务成功率和必要环境结构操作率。参考 [ARS 的动作块进度差与共享训练协议](https://arxiv.org/html/2609.34484v1)，但本方案的离散状态不能未经校准假装是同一连续 $p_t$。若采用奖励学习，另先校准连续潜在量、检查循环/撤销和 reward hacking，再单独比较相同 RL 预算；不把它并入首个 BC 验证。

至少使用多个策略种子和配对评估初态，给成功率差的区间；检查收益是否只来自更多/更少样本或保留比例差异。若上游方向更准但策略无增益，分析块选择时机、信号密度和机构可控性，不提前宣称“更好机器人策略”。只有在同等训练预算下稳定提升完成率，才成立下游价值论断。

## 9. 执行顺序、交付物与继续/停止门

| 阶段 | 后续执行动作与落点 | 通过/转向条件 |
| --- | --- | --- |
| A 规格与审计 | 将本计划拆成 `research/prerequisite_monitor/change_guided/` 的输入合同、标签指南、基线矩阵和证据索引；复验现有 seal、原答/曲线/manifest/帧及新数据不泄漏检查。 | 能逐例追到原始视频、文字与失败；审读争议明确标记。 |
| B 零/小调用原型 | 实现前缀截断与禁止未来访问的自动检查、变化候选、最小命题 schema、证据重新读取和确定性读出；先做格式/索引/撤销/完成单元检验，再 2–4 例 smoke。 | G 完成优先、R 末端回收、错误字段不被静默修复；漏 B 板则先改定位，不叠加复杂 agent。 |
| C 受控开发 | 冻结 D/D2、K、C，同预算完成双盒交叉小表和 A/B 九条件回归，保存所有原答与成本；最多作有明确归因的一轮定位或读出修订。 | C 的收益必须出现在 E/H/R 的可核验证据与成对方向，而非只来自更多调用、`unknown` 或一般提示措辞；若 D2/K/Robometer 已够好则接受它们。 |
| D 方法冻结与 G2 | 冻结配置 SHA、样本量、主次指标、对照身份、停止规则；独立制样/审读，再一次性盲评未见场景。 | 未见同机制与新机制结果分别报告，不能用颜色变化代替机制泛化；失败后新版本另试。 |
