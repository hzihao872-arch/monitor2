## 图形合同

1. 主图要支持的结论：发布输出与发布标签在局部方向上相反；不证明内部归因机制。
2. 证据链：完整洋葱曲线 → 原始点数值 → 同时轴关键帧 → 正确区间和其他展示例 → 假说与竞争解释。
3. 图型：图像与数值对照；数据曲线只使用作者发布值，方法图明确属于拟议方案。
4. 沿用用户指定材料目录中的 Python 绘图流程；全部图形由 Python 生成。
5. 输出：PNG（300 dpi）、PDF、SVG（保留可编辑文字）；原始帧 640 × 480，不做生成式补全、去遮挡或物体重构。曲线数据 CSV 与原 JSON 随包提供；误差线和统计显著性不适用。
